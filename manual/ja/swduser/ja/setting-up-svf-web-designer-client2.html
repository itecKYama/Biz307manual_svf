                                                                                                                                                                                              2.1. SVF Web Designer Clientのセットアップ

                                                                                                                                                                                              SVF Web Designer ClientのインストーラーをSVF Web DesignerサーバーからローカルPCにダウンロードして、ローカルPCでインストールを実行します。ここでは、SVF Web Designer Clientをダウンロードしてインストールするまでの流れを説明します。複数のSVF Web Designerサーバーに接続する場合は、それぞれの接続先からインストーラーをダウンロードしてインストールする必要があります。

                                                                                                                                                                                              • インストーラーのダウンロード

                                                                                                                                                                                              • インストール

                                                                                                                                                                                              事前条件

                                                                                                                                                                                              • 管理者がSVF Web Designerサーバーをインストールし、サービスを開始していること

                                                                                                                                                                                              • インストールする環境に管理者権限を持つユーザーでログインしていること

                                                                                                                                                                                              インストーラーのダウンロード

                                                                                                                                                                                              1. Webブラウザーで以下のURLを指定します。

                                                                                                                                                                                                http://<SVF Web Designerサーバーのホスト名またはIPアドレス>:8833/webdesigner/login

                                                                                                                                                                                                SVF Web Designer Clientのインストーラーをダウンロードするための画面が表示されます。

                                                                                                                                                                                              2. ［EXE］または［ZIP］をクリックして、インストーラーをローカルPCに保存します。ZIP形式のインストーラーは任意のフォルダーに解凍してください。

                                                                                                                                                                                                • ［EXE］

                                                                                                                                                                                                  自己解凍ファイル形式の「svfwd-client.exe」をダウンロードします。

                                                                                                                                                                                                • ［ZIP］

                                                                                                                                                                                                  ZIP形式の「svfwd-client.zip」をダウンロードします。

                                                                                                                                                                                              インストール

                                                                                                                                                                                              1. インストーラーを起動します。

                                                                                                                                                                                                • ZIP形式のインストーラーの場合

                                                                                                                                                                                                  「svfwd-client.zip」を解凍したフォルダーにある「install.exe」をダブルクリックしてインストーラーを起動します。ユーザーアカウント制御の画面が表示された場合、「はい」をクリックしてください。

                                                                                                                                                                                                • 自己解凍ファイル形式のインストーラーの場合

                                                                                                                                                                                                  「svfwd-client.exe」をダブルクリックしてインストーラーを起動します。

                                                                                                                                                                                              2. 使用する言語、およびインストール先を選択し、画面の指示に従ってインストールしてください。

                                                                                                                                                                                                参考

                                                                                                                                                                                                インストール先には、デフォルトで以下のフォルダーが設定されます。

                                                                                                                                                                                                <システムドライブ>:\WingArc\SVFWebDesignerClient\<接続先ホスト名>\<接続先パス>
