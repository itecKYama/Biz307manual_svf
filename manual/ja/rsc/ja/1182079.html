                                                                                    2.4.5. RDSpoolサーバーのセットアップ（UNIX/Linux版）

                                                                                    RDSpoolサーバーのセットアップの流れは次のとおりです。

                                                                                    1. 環境変数を設定する

                                                                                    2. インストールする

                                                                                    3. アクティベーションする

                                                                                    4. プロセスを起動する

                                                                                    5. RDEサーバーとの接続を設定する

                                                                                    参考

                                                                                    インストール時に、Apache Tomcatも同時にインストールされます。

                                                                                    事前条件

                                                                                    • セットアップ前の準備作業が完了していること

                                                                                      詳細は「セットアップ前の準備（UNIX/Linux版）」を参照してください。

                                                                                    • セットアップ前の確認事項を確認済みであること

                                                                                      詳細は「セットアップ前の確認事項（UNIX/Linux版）」を参照してください。

                                                                                    • クライアントコンピューターにMicrosoft .NET Frameworkがインストールされていること

                                                                                      RDEサーバーとの接続設定で、SVF環境設定を起動する際に必要です。対応バージョンは製品の動作環境を確認してください。

                                                                                    手順

                                                                                    環境変数を設定する

                                                                                    インストールに必要な環境変数を次の手順で設定します。環境変数の設定は、シェルが起動したときに読み込まれる環境設定ファイル（shの場合は~/.profile、cshの場合は~/.cshrc、bashの場合は~/.bash_profileなど）で行ってください。

                                                                                    1. 展開先のディレクトリ下にあるprofile/svf.profileファイルを、viなどのエディターで開きます。

                                                                                      ## RD-Enterprise Environment Settings
## !!CHANGE TO YOUR INSTALL DIRECTORY!!
FIT_PRODUCTS_BASE=/usr/svf/SVFJP
export FIT_PRODUCTS_BASE
## !!CHANGE TO YOUR JAVA DIRECTORY!!
#necessary
JAVA_HOME=/opt/java
export JAVA_HOME
PATH=$JAVA_HOME/bin:$PATH
export PATH
# Tomcat Settings..
JAVA_OPTS=" -Xms512m -Xmx512m "
export JAVA_OPTS
CATALINA_PID=$FIT_PRODUCTS_BASE/var/run/tomcat.pid
export CATALINA_PID
# Database Settings..
## !!CHANGE TO YOUR INSTALL DIRECTORY!!
DB_INSTALL_DIR=$FIT_PRODUCTS_BASE/rdjava
POSTGRESQL_HOME=$DB_INSTALL_DIR/pgsql
export POSTGRESQL_HOME
...

                                                                                    2. svfユーザーのシェル環境に合わせて、赤字で表示された部分を編集します。

                                                                                      • FIT_PRODUCTS_BASE

                                                                                        インストール先のディレクトリを設定します。デフォルトは「/usr/svf/SVFJP」です。

                                                                                      • JAVA_HOME

                                                                                        JAVA_HOMEのディレクトリを設定します。デフォルトは「/opt/java」です。

                                                                                      • JAVA_OPTS

                                                                                        Apache Tomcatのヒープサイズを設定します。

                                                                                    3. 設定を変更した場合はファイルを保存し、内容を設定ファイルに追記します。

                                                                                      例: cat svf.profile >> $HOME/.profile

                                                                                    4. 次のいずれかの方法で変更を有効にします。

                                                                                      • 一度ログアウトして、再度ログインする

                                                                                      • 次のコマンドで環境変数の設定を有効にする

                                                                                        例: $ . $HOME/.profile

                                                                                    5. $FIT_PRODUCTS_BASEに設定した「インストール先ディレクトリ」を作成します。

                                                                                      例: $ mkdir /usr/svf/SVFJP

                                                                                      注意

                                                                                      • rootで作成する場合はディレクトリの所有者を「svf」にしてください。

                                                                                      • OSで生成されたprofileには、「set -u」コマンドがセットされていることがあります。未定義の変数への参照でエラーとなりますので、コメントアウトしてください。

                                                                                    インストールする

                                                                                    1. SVF実行部製品と同じユーザーで、RDEをインストールします。

                                                                                      製品メディアをドライブに挿入し、ソースメディア上のすべてのファイルを任意のディレクトリにコピーします。

                                                                                    2. ファイルをコピーしたディレクトリに移動し、実行ユーザーで次のシェルスクリプトを起動してください。

                                                                                      • install_x64.sh（Linuxの場合）

                                                                                      • install_other.sh（上記以外のUNIX系OSの場合）

                                                                                    3. インストールモードで「4. アプリケーションサーバー構成インストール」を選択します。

                                                                                    アクティベーションする

                                                                                    • コマンドを実行して、製品をアクティベーションします。

                                                                                      アクティベーションの概要や操作については、『RDEスプール管理ガイド』を参照してください。

                                                                                    プロセスを起動する

                                                                                    • 起動スクリプトを実行して、RDEのプロセスを起動します。

                                                                                      詳細は「プロセスの起動と終了（UNIX/Linux版）」を参照してください。

                                                                                    RDEサーバーとの接続を設定する

                                                                                    RDEサーバーとの接続を設定するために、SVF環境設定を起動します。SVF環境設定は、RDEをセットアップしたコンピューターではなく、クライアント側のWindows OS上で、WebブラウザーからRDSpoolサーバーに接続して起動します。

                                                                                    1. WebブラウザーのアドレスにRDSpoolサーバーのURLを入力し、「APPLICATION MENU」の［SVF］－［SVF 環境設定］をクリックします。

                                                                                      http://<ホスト名またはIPアドレス>:44090

                                                                                      ［SVF Java PRODUCTS Configuration Tool］画面（SVF環境設定）が表示されます。

                                                                                    2. ［プリンターツリー］で、スプール用プリンター「RDSpool」を選択し、スプール先となるRDEサーバーのサーバー名やポート番号などを設定します。

                                                                                      次の項目を設定してください。その他の項目は任意です。設定項目の詳細は『RDEスプール管理ガイド』の「RDSPOOL」機種プリンターの説明を参照してください。

                                                                                      • サーバー名

                                                                                        スプール先となるRDEサーバーのサーバー名、またはIPアドレスを入力します。

                                                                                      • ポート番号

                                                                                        スプール先として接続する、RDEサーバー上のRDバランサーのポート番号を入力します。デフォルトは「44093」（RDバランサーのデフォルトポート）です。

                                                                                      • サーバー名(セカンダリ)

                                                                                        ［サーバー名］で指定したRDEサーバーに接続できない場合の、代替のスプール先となるRDEサーバーのサーバー名、またはIPアドレスを入力します。

                                                                                      • ポート番号(セカンダリ)

                                                                                        ［サーバー名］で指定したRDEサーバーに接続できない場合の、代替のスプール先となるRDEサーバー上のRDバランサーのポート番号を入力します。RDバランサーのデフォルトポートは「44093」です。

                                                                                    3. 設定を保存します。
