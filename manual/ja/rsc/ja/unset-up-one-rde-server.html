                                                                                    5.3. RDEサーバー1台をアンセットアップする

                                                                                    ここでは、RDEをスケーラブル構成でセットアップ済みのシステムから、RDEサーバーを1台削除する手順を説明します。RDEサーバーを1台削除する流れは次のとおりです。

                                                                                    1. RDEサーバーをアンセットアップする

                                                                                    2. データベースサーバーで設定を変更する

                                                                                    3. RDSpoolサーバーで設定を変更する

                                                                                    4. 動作確認をする

                                                                                    事前条件

                                                                                    • 削除対象のRDEサーバーに所属しているプリンターがないこと

                                                                                      削除対象のRDEサーバーに所属しているプリンターがある場合、所属先サーバーを変更してください。

                                                                                    • 削除対象のRDEサーバーを通信先として指定しているPAサーバーがないこと

                                                                                      削除対象のRDEサーバーを通信先として指定しているPAサーバーがある場合、通信先サーバーを変更してください。

                                                                                    手順

                                                                                    RDEサーバーをアンセットアップする

                                                                                    1. システム内のいずれかのRDEサーバー上で次のコマンドを実行し、サーバー情報を削除します。

                                                                                      コマンドの書式や使用例については、『RDEスプール管理ガイド』のサーバー管理用コマンドの説明を参照してください。

                                                                                      • Windows版

                                                                                        %FIT_PRODUCTS_BASE%\rdjava\util\server\rdserverdel Kind Name

                                                                                      • UNIX/Linux版

                                                                                        $FIT_PRODUCTS_BASE/rdjava/util/server/rdserverdel.sh Kind Name

                                                                                      指定できるパラメーターは次のとおりです。

                                                                                      • Kind

                                                                                        値

                                                                                        説明

                                                                                        0

                                                                                        RDサーバーを削除します。

                                                                                        1

                                                                                        PAサーバーを削除します。

                                                                                        2

                                                                                        RDバランサーを削除します。

                                                                                      • Name

                                                                                        削除対象のサーバー名（ワイルドカード指定可）を指定します。

                                                                                    2. RDEサーバーからRDEをアンインストールします。

                                                                                      アンインストール手順については、Windows版の場合は「アンインストール（Windows版）」を、UNIX/Linux版の場合は「アンインストール（UNIX/Linux版）」を参照してください。

                                                                                    データベースサーバーで設定を変更する

                                                                                    1. データベースサーバーで、RDEサーバーとの接続設定を変更します。

                                                                                      pg_hba.confからアンセットアップしたRDEサーバーの情報を削除し、postgresql.confでデータベースへの同時接続数を更新した後、RDEのサービス（プロセス）を再起動してください。RDEサーバーとの接続設定については、Windows版の場合は「データベースサーバーのセットアップ（Windows版）」を、UNIX/Linux版の場合は「データベースサーバーのセットアップ（UNIX/Linux版）」を参照してください。

                                                                                    2. UNIX/Linux版の場合、必要に応じてデータベースサーバーのカーネルパラメーターを見直します。

                                                                                      アンセットアップ後のRDEサーバーの台数を基に、データベースへの同時接続数を算出した上で、カーネルパラメーターを見直してください。データベースへの同時接続数の算出方法およびカーネルパラメーターの設定については、「セットアップ前の準備（UNIX/Linux版）」を参照してください。

                                                                                    RDSpoolサーバーで設定を変更する

                                                                                    この手順は、アンセットアップするRDEサーバーをRDSpoolサーバーからの接続先として設定している場合に実施してください。

                                                                                    • クライアント側のWindowsOS上で、WebブラウザーからRDSpoolサーバーに接続してSVF環境設定を起動し、RDEサーバーとの接続設定を変更します。

                                                                                      アンセットアップするRDEサーバーから継続運用するRDEサーバーに、接続先を変更してください。RDEサーバーとの接続設定の手順については、Windows版の場合は「RDSpoolサーバーのセットアップ（Windows版）」を、UNIX/Linux版の場合は「RDSpoolサーバーのセットアップ（UNIX/Linux版）」を参照してください。

                                                                                    動作確認をする

                                                                                    • 稼働中のRDEサーバーに、意図どおり処理が振り分けられていることを確認します。

                                                                                      動作確認の手順については、「セットアップ後の動作確認と設定」を参照してください。

                                                                                      RDEサーバー1台のアンセットアップの場合、ユーザー登録など、動作確認に必要なサーバーの設定は不要です。次の作業を実施してください。

                                                                                      1. サーバーの起動

                                                                                      2. サンプルプログラムの実行

                                                                                      3. スプールと印刷の確認
