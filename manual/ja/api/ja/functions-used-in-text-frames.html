                                                3.12. テキストフレームで使用する関数とコマンド

                                                テキストフレームは長文のテキストに対して文章の折り返しや段落などを設定できるアイテムで、VrsOut関数を使用したフィールドとのデータ連携によって動的にテキストを変更できます。

                                                VrsOut関数の詳細は、「VrsOut / VrsOutn」を参照してください。ここでは動的テキストの作成方法とテキストフレームコマンドについて説明します。

                                                動的なテキストの作成方法

                                                1. テキストフレームに設定したテキスト内に、フィールドを参照する（フィールド連携）設定をしたXML様式ファイルを用意します。

                                                  テキストフレーム設定の詳細は、SVF設計部製品のマニュアルを参照してください。

                                                2. VrsOut関数を使用して、参照先フィールドにデータを出力します。

                                                  svf.VrsOut("参照先フィールド名","出力データ");

                                                3. テキストフレームでフィールド連携を設定した部分に、参照先フィールドに出力されたデータが展開されます。

                                                テキストフレームコマンド

                                                テキストフレームコマンドとは、XHTML形式で記述するテキストフレーム専用の出力指示言語です。

                                                テキストフレームコマンドを使用すると、テキストフレーム内のフィールド連携を設定した部分へ下記の出力が可能です。

                                                • 参照先フィールドへ出力するデータに専用のタグ（文字装飾用のタグ、改行タグ）を指定すると、文字装飾や改行を反映したテキストを出力できます。

                                                  テキストフレームコマンドのタグは、次の2つです。

                                                  タグ

                                                  内容

                                                  <br/>

                                                  文中の任意の位置で改行します。

                                                  <font>...</font>

                                                  指定範囲内の文字を装飾します。装飾内容は、タグに記述された属性によって判別されます。属性を記述しない場合は、設計時にテキストフレームで指定した文字装飾で出力されます。

                                                  使用できる属性については、「fontタグ属性で指定可能な値」を参照してください。

                                                • マークアップで使用する不等号（「<」や「>」）などの記号を出力には、参照先フィールドへ出力するデータ内で実態参照を指定する必要があります。

                                                  テキストフレームコマンドで必須となる実体参照は、次の6つです。

                                                  記号

                                                  指定子（実体参照）

                                                  <

                                                  &lt;

                                                  >

                                                  &gt;

                                                  "

                                                  &quot;

                                                  '

                                                  &apos;

                                                  &

                                                  &amp;

                                                  （半角スペース文字）

                                                  &nbsp;

                                                fontタグ属性で指定可能な値

                                                タグ名

                                                機能

                                                name-latin

                                                半角文字のフォントファミリーを指定します。

                                                name-asian

                                                全角文字のフォントファミリーを指定します。

                                                size

                                                文字のサイズを指定します。

                                                style

                                                文字の斜体を指定します。

                                                weight

                                                文字の太さを指定します。

                                                color

                                                文字色を指定します。

                                                background-color

                                                文字の背景色を指定します。

                                                underline-position

                                                下線、取り消し線の位置を指定します。

                                                underline-position-offset

                                                下線、取り消し線の位置の調整値を指定します。

                                                underline-type

                                                下線、取り消し線の線種を指定します。

                                                underline-width-type

                                                下線、取り消し線の線幅（種類）を指定します。

                                                underline-width

                                                下線、取り消し線の線幅（値）を指定します。

                                                underline-color

                                                下線、取り消し線の線色を指定します。

                                                name-latin

                                                説明

                                                半角文字のフォントファミリーを指定します。

                                                指定可能な値

                                                XML様式ファイルに登録されているフォント名

                                                指定例

                                                半角フォントに「クーリエ」を指定する場合

                                                name-latin="Courier New"

                                                備考

                                                XML様式ファイルに登録されていないフォント名を指定した場合は、設定は無視されます。

                                                name-asian

                                                説明

                                                全角文字のフォントファミリーを指定します。

                                                指定可能な値

                                                XML様式ファイルに登録されているフォント名

                                                指定例

                                                全角フォントに「ＭＳ 明朝」を指定する場合

                                                name-asian="ＭＳ 明朝"

                                                備考

                                                XML様式ファイルに登録されていないフォント名を指定した場合は、設定は無視されます。

                                                size

                                                説明

                                                文字のサイズを指定します。

                                                指定可能な値

                                                1pt以上

                                                指定例

                                                文字サイズを「20pt」にする場合

                                                size="20pt"

                                                備考

                                                単位「pt」の記述は必須です。

                                                1より小さい数値を指定した場合、設定は無視されます。

                                                style

                                                説明

                                                文字の斜体を指定します。

                                                指定可能な値

                                                「normal」または「italic」

                                                指定例

                                                フォントを斜体にする場合

                                                style="italic"

                                                備考

                                                「normal」、または「italic」以外を指定した場合は、設定は無視されます。

                                                weight

                                                説明

                                                文字の太さを指定します。

                                                指定可能な値

                                                「normal」または「bold」

                                                指定例

                                                フォントを太字にする場合

                                                weight="bold"

                                                備考

                                                「normal」、または「bold」以外を指定した場合は、設定は無視されます。

                                                color

                                                説明

                                                文字色を指定します。

                                                指定可能な値

                                                色のRGB値

                                                指定例

                                                文字色を「青色」にする場合

                                                color="#0000ff"

                                                備考

                                                • 値は「#RRGGBB」の書式に従う必要があります。

                                                • 指定する色はXML様式ファイルにパレットカラーとして登録されている必要があります。

                                                • RR/GG/BBは、それぞれ00からffまでの16進数で指定します。

                                                • 次の場合、設定は無視されます。

                                                  • 指定内容が「#RRGGBB」の書式に従っていない場合

                                                  • 指定色がXML様式ファイルに登録されているパレットカラーにない場合

                                                background-color

                                                説明

                                                文字の背景色を指定します。

                                                指定可能な値

                                                色のRGB値、またはtransparent（透明色）

                                                指定例

                                                • 背景色を「緑色」にする場合

                                                  background-color="#00ff00"

                                                • 背景色を「透明色」にする場合

                                                  background-color="transparent"

                                                備考

                                                • RGB値は「#RRGGBB」の書式に従う必要があります。

                                                • 指定する色はXML様式ファイルにパレットカラーとして登録されている必要があります。

                                                • RR/GG/BBは、それぞれ00からffまでの16進数で指定します。

                                                • 次の場合、設定は無視されます。

                                                  • 指定内容が「#RRGGBB」の書式に従っていない場合

                                                  • 指定色がXML様式ファイルに登録されているパレットカラーにない場合

                                                  • 指定内容が上記2点と合致し、かつ「transparent」とも一致しない場合

                                                underline-position

                                                説明

                                                下線、取り消し線の位置を指定します。

                                                指定可能な値

                                                • none（線なし）

                                                • top（上）

                                                • middle（中央）

                                                • baseline（ベースライン）

                                                • bottom（下）」

                                                指定例

                                                線の位置を「下」にする場合

                                                underline-position="bottom"

                                                備考

                                                上記以外の値が設定された場合または、設定がない場合、「none（線なし）」として扱われます。

                                                underline系の属性を指定する場合は、この属性の指定は必須です。

                                                underline-position-offset

                                                説明

                                                下線、取り消し線の位置の調整値を指定します。

                                                指定可能な値

                                                ポイント値

                                                指定例

                                                線位置調整を下方向に「10」ポイント調整する場合

                                                underline-position-offset="10"

                                                備考

                                                • 値の末尾に単位「pt」は付けません。

                                                • 正の値を指定した場合下方向に位置を調整し、負の値を指定した場合上方向に位置を調整します。

                                                underline-type

                                                説明

                                                下線、取り消し線の線種を指定します。

                                                指定可能な値

                                                • 0（直線）

                                                • 1（破線1）

                                                • 2（破線2）

                                                • 3（破線3）

                                                • 4（一点鎖線）

                                                • 5（二点鎖線）

                                                指定例

                                                線種を「一点鎖線」にする場合

                                                underline-type="4"

                                                備考

                                                上記以外の値が設定された場合、および設定がない場合、「0（直線）」として扱われます。

                                                underline-width-type

                                                説明

                                                下線、取り消し線の線幅（種類）を指定します。

                                                指定可能な値

                                                • 0（極細）

                                                • 1（細）

                                                • 2（中細）

                                                • 3（中）

                                                • 4（中太）

                                                • 5（太）

                                                • 6（自由）

                                                指定例

                                                線幅を「太」にする場合

                                                underline-width-type="5"

                                                備考

                                                上記以外の値が設定された場合、および設定がない場合は、「0（極細）」として扱われます。

                                                underline-width

                                                説明

                                                下線、取り消し線の線幅（値）を指定します。

                                                指定可能な値

                                                正の値（ポイント値）

                                                指定例

                                                線幅を2ポイントにする場合

                                                underline-width="2"

                                                備考

                                                • 線幅の種類が「6（自由）」の場合のみ有効です。

                                                • 値の末尾に単位「pt」は付けません。

                                                underline-color

                                                説明

                                                下線、取り消し線の線色を指定します。

                                                指定可能な値

                                                色のRGB値

                                                指定例

                                                線色を「赤色」にする場合

                                                underline-color="#ff0000"

                                                備考

                                                • 値は「#RRGGBB」の書式に従う必要があります。

                                                • 指定する色はXML様式ファイルにパレットカラーとして登録されている必要があります。

                                                • RR/GG/BBは、それぞれ00からffまでの16進数で指定します。

                                                • 次の場合、および設定がない場合は、「#000000」（黒）として扱われます。

                                                  • 指定内容が「#RRGGBB」の書式に従っていない場合

                                                  • 指定色がXML様式ファイルに登録されているパレットカラーにない場合
