                                                3.11. Report Director Enterprise使用時の関数

                                                Report Director Enterpriseで使用するAPI関数は、次のとおりです。一部を除き、1スプール文書（帳票）あたり一度実行します。

                                                関数名

                                                機能

                                                VrComout("/{SUCL xxx, xxx}/")

                                                RDE環境設定の［カラム設定］で追加したユーザー定義カラムにデータを登録します。

                                                VrComout("/{DATR Stop=n}/")

                                                スプール文書の印刷処理を停止します。

                                                VrComout("/{DATR CopiesCollate=n}/")

                                                Report Director Enterpriseから部単位での印刷を指定します。

                                                VrComout("/{DATR AutoPrintMode=n}/")

                                                スプールデータを受け取りながらSVF実行部製品を実行してデータを生成するか、スプールデータをすべて受け取り終えてからSVF実行部製品を実行してデータを生成するかを指定します。

                                                VrComout("/{DATR ValidDays=n}/")

                                                スプール時に文書の有効日数を指定します。

                                                VrComout("/{DATR ReprintForm=xxx}/")

                                                スプール時に文書ごとに再印刷様式名を指定します。再印刷とは、印刷完了ステータスの文書を再度印刷することを示します。

                                                VrComout("/{DATR EnablePrinterKind=xxx}/")

                                                印刷可能なプリンター機種を指定します。

                                                VrComout("/{DATR EnablePrintPageRange=n}/")

                                                印刷実行時、印刷ページ範囲指定により部分ページ指定が可能かどうかを設定します。

                                                VrComout("/{DATR EnableView=n}/")

                                                スプールされた文書がビュー可能かどうかを指定します。

                                                VrComout("/{PPRI priority}/")

                                                印刷文書ごとに優先順位を付けます。

                                                VrSetComputerName

                                                コンピューター名を指定します。

                                                VrSetOutputPrinter

                                                文書のスプール後、即時印刷する場合のプリンター名を指定します。

                                                VrSetOutputVPrinter

                                                文書のスプール後、即時印刷する場合のプリンターグループ名を指定します。

                                                VrSetOutputVPrinter2

                                                印刷先のプリンターグループ名を指定して文書をスプールし、印刷せずに停止します。

                                                VrAbortDoc

                                                Report Director Enterpriseへのスプール処理を中断します。

                                                VrComout("/{SUCL xxx, xxx}/")

                                                機能

                                                RDE環境設定の［カラム設定］で追加したユーザー定義カラムにデータを登録します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{SUCL ColumnName, ColumnValue}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{SUCL ColumnName, ColumnValue}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{SUCL ColumnName, ColumnValue}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{SUCL ColumnName, ColumnValue}/") As Integer

                                                引数

                                                • ColumnName

                                                  ユーザー定義カラム

                                                • ColumnValue

                                                  登録値

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコードSVF実行部製品

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                Report Director Enterpriseに文書をスプールした場合に、RDE環境設定の［カラム設定］で追加したユーザー定義カラムにデータを登録します。本関数は、1定義名（ユーザーカラム）あたり一度実行します。

                                                使用例

                                                ユーザー定義カラム「TEIGI1」に「配布先」を登録します。

                                                • Java/C#

                                                  svf.VrComout("/{SUCL TEIGI1, 配布先}/");

                                                • ASP/VB

                                                  svf.VrComout("/{SUCL TEIGI1, 配布先}/")

                                                • C

                                                  VrComout(svf, "/{SUCL TEIGI1, 配布先}/");

                                                • VB.NET

                                                  svf.VrComout("/{SUCL TEIGI1, 配布先}/")

                                                VrComout("/{DATR Stop=n}/")

                                                機能

                                                スプール文書の印刷処理を停止します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR Stop=n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR Stop=n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR Stop=n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR Stop=n}/") As Integer

                                                引数

                                                • 0

                                                  停止しない（デフォルト）

                                                • 1

                                                  停止する

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                スプール文書の印刷処理を停止します。自動印刷と併用時のみ有効な設定です。

                                                使用例

                                                スプール文書の印刷処理を停止します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR Stop=1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR Stop=1}/")

                                                • C

                                                  VrComout(svf, "/{DATR Stop=1}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR Stop=1}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, Stop=1}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter(...);
        :
svf.VrSetOutputPrinter(...);
svf.VrComout("/{DATR Stop=1}/");

                                                VrComout("/{DATR CopiesCollate=n}/")

                                                機能

                                                Report Director Enterpriseから部単位での印刷を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR CopiesCollate=n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR CopiesCollate=n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR CopiesCollate=n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR CopiesCollate=n}/") As Integer

                                                引数

                                                • 0

                                                  部単位で印刷しない（デフォルト）

                                                • 1

                                                  部単位で印刷する

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                Report Director Enterpriseから部単位での印刷を指定します。自動印刷と併用する場合のみ有効な設定です。

                                                VrComout("/{DATR AutoPrintMode=0}/")関数を指定している場合は、部単位では印刷されません。

                                                VrComout("/{DATR CopiesCollate=1}/")関数を指定している文書でも、RDEユーティリティ上で手動の印刷（再印刷）を実行した場合は、印刷時の設定に従います。

                                                使用例

                                                部単位での印刷を指定します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR CopiesCollate=1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR CopiesCollate=1}/")

                                                • C

                                                  VrComout(svf, "/{DATR CopiesCollate=1}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR CopiesCollate=1}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, CopiesCollate=1}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter(...);
        :
svf.VrSetOutputPrinter(...);
svf.VrComout("/{DATR CopiesCollate=1}/");

                                                VrComout("/{DATR AutoPrintMode=n}/")

                                                機能

                                                スプールデータを受け取りながらSVF実行部製品を実行してデータを生成するか、スプールデータをすべて受け取り終えてからSVF実行部製品を実行してデータを生成するかを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR AutoPrintMode=n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR AutoPrintMode=n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR AutoPrintMode=n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR AutoPrintMode=n}/") As Integer

                                                引数

                                                モードを指定します。

                                                • 0

                                                  スプールデータを受け取りながらSVF実行部製品を実行します。

                                                • 1

                                                  スプールデータを受け取り終えてからSVF実行部製品を実行します。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                スプールデータを受け取りながらSVF実行部製品を実行してデータを生成するか、スプールデータをすべて受け取り終えてからSVF実行部製品を実行してデータを生成するかを指定します。自動印刷と併用する場合のみ有効な設定です。Report Director Enterpriseから総ページ数の出力と部単位での印刷を行う場合は、スプールデータをすべて受け取り終えてから、SVF実行部製品を実行する必要があります。

                                                VrComout("/{DATR AutoPrintMode=0}/")関数を指定している文書でも、RDEユーティリティから手動で印刷（再印刷）すると「総ページ数」が出力されます。

                                                この関数を呼び出さない場合は、引数を「1」にして呼び出した場合と同じ動作になります。

                                                使用例

                                                スプールデータを受け取りながらSVF実行部製品を実行します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR AutoPrintMode=0}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR AutoPrintMode=0}/")

                                                • C

                                                  VrComout(svf, "/{DATR AutoPrintMode=0}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR AutoPrintMode=0}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, AutoPrintMode=0}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter(...);
        :
svf.VrSetOutputPrinter(...);
svf.VrComout("/{DATR AutoPrintMode=0}/");

                                                VrComout("/{DATR AutoPrintMode=n}/")関数を呼び出さない場合のデフォルト動作の変更

                                                この関数を呼び出さない場合のデフォルトの動作を変更する場合は、次のファイルにパラメーターと指定する値を追加記述してください。

                                                • 追加するファイル

                                                  FIT_PRODUCTS_BASEはインストール時に設定される、またはインストール前に定義した環境変数です。OSの環境変数を確認してください。

                                                  • Windowsの場合

                                                    %FIT_PRODUCTS_BASE%\rdjava\rdserver\rdserver.properties

                                                  • UNIX/Linuxの場合

                                                    $FIT_PRODUCTS_BASE/rdjava/rdserver/rdserver.properties

                                                • 追加するパラメーター

                                                  Default.AutoPrintMode=数値

                                                • 指定する値

                                                  • 0

                                                    スプールデータを受け取りながらSVF実行部製品を実行します。

                                                  • 1

                                                    スプールデータを受け取り終えてからSVF実行部製品を実行します（デフォルト）。

                                                • 記述例

                                                  デフォルト設定を「スプールデータを受け取りながらSVF実行部製品を実行します。」に変更する場合

                                                  Default.AutoPrintMode=0

                                                VrComout("/{DATR ValidDays=n}/")

                                                機能

                                                スプール時に文書の有効日数を指定します。定期処理による文書削除実行時、または管理コマンドによる文書削除実行時に、ここで指定した有効日数が経過した文書は削除の対象となります。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR ValidDays=n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR ValidDays=n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR ValidDays=n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR ValidDays=n}/") As Integer

                                                引数

                                                • -1

                                                  自動削除しません。手動での削除のみ対応します。

                                                • 0～

                                                  有効日数を指定します。ここで指定した日数が経過したスプール文書は自動的に削除されます。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                スプール時に指定した有効日数が経過したかどうかの判定は、定期処理またはコマンド実行時に行われます。

                                                削除の対象となる日付、およびステータスは、定期処理の自動削除と同様です。

                                                対象となる日付

                                                対象となるステータス

                                                未印刷文書の場合

                                                スプール終了日時

                                                状態不明、スプール完了、スプール失敗、印刷中断、異常終了

                                                印刷済み文書の場合

                                                印刷終了日時

                                                状態不明、スプール完了、スプール失敗、印刷中断、異常終了

                                                ゴミ箱内文書の場合

                                                最終更新日付（ゴミ箱に移動した日時）

                                                すべて

                                                使用例

                                                文書の有効日数を1日に指定します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR ValidDays=1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR ValidDays=1}/")

                                                • C

                                                  VrComout(svf, "/{DATR ValidDays=1}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR ValidDays=1}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, ValidDays=1}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter(...);
        :
svf.VrComout("/{DATR ValidDays=1}/");
        :
svf.VrQuit();

                                                VrComout("/{DATR ReprintForm=xxx}/")

                                                機能

                                                スプール時に文書ごとに「再印刷様式名」を指定します。再印刷とは、「印刷完了」ステータスの文書を再度印刷することを示します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR ReprintForm=xxx}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR ReprintForm=xxx}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR ReprintForm=xxx}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR ReprintForm=xxx}/") As Integer

                                                引数

                                                • 再印刷様式名（大文字/小文字を区別します）

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                再印刷用のXML様式ファイルは、様式（ビットマップを含む）の実体ファイルを指定のディレクトリに指定の拡張子で置き、RDE環境設定の［再印刷様式］で事前に登録する必要があります。

                                                文書に指定された再印刷様式が存在しない場合は、ステータスが「異常終了」になります。

                                                使用例

                                                再印刷様式名として「ReprintForm1」を指定します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR ReprintForm=ReprintForm1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR ReprintForm=ReprintForm1}/")

                                                • C

                                                  VrComout(svf, "/{DATR ReprintForm=ReprintForm1}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR ReprintForm=ReprintForm1}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, ReprintForm=ReprintForm1}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter(...);
        :
svf.VrComout("/{DATR ReprintForm=ReprintForm1}/");
        :
svf.VrQuit();

                                                VrComout("/{DATR EnablePrinterKind=xxx}/")

                                                機能

                                                印刷可能なプリンター機種を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DATR EnablePrinterKind=xxx}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR EnablePrinterKind=xxx}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{DATR EnablePrinterKind=xxx}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR EnablePrinterKind=xxx}/") As Integer

                                                引数

                                                • プリンター機種名

                                                  複数指定する場合は「|」（縦線）で区切ります。

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                Report Director Enterpriseにスプールする文書の印刷が可能なプリンター機種を指定します。

                                                指定可能なプリンター機種の詳細は、『RDEスプール管理ガイド』の「コマンドでプリンターをインポート／エクスポートする」を参照してください。

                                                使用例

                                                CANON LIPS4とRICOH RPCSを印刷可能なプリンター機種として指定します。

                                                • Java/C#

                                                  svf.VrComout("/{DATR EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DATR EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/")

                                                • C

                                                  VrComout(svf, "/{DATR EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/");

                                                • VB.NET

                                                  svf.VrComout("/{DATR EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/")

                                                参考

                                                他のDATRの項目とあわせて設定する場合はカンマ区切りで指定します。

                                                VrComout("/{DATR EnableView=1, EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/");

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "RDSpool");
      :
svf.VrSetOutputPrinter(...);
svf.VrComout("/{DATR EnablePrinterKind=LIPS4SECURITY|RPCSSECURITY}/");

                                                VrComout("/{DATR EnablePrintPageRange=n}/")

                                                機能

                                                • Java/C#

                                                • ASP/VB

                                                  Function instance.VrComout("/{DATR EnablePrintPageRange=n}/") As Long

                                                • C

                                                • VB.NET

                                                  Function instance.VrComout("/{DATR EnablePrintPageRange=n}/") As Integer

                                                • C

                                                  VrSetOutputVPrinter2(svf, "GROUP1");

                                                • VB.NET
