                                                3.8. SVF for PDF Client Editionのみで使用できる関数

                                                SVF for PDF Client Editionのみで使用できるAPI関数は、次のとおりです。

                                                関数名

                                                機能

                                                VrComout("/{ENABLEPREVIEW mode}/")

                                                EMF/EMFPLUSの出力時に、PAliteが印刷データを受信したタイミングで印刷イメージを画面に表示します。

                                                VrComout("/{ENABLEPREVIEW mode}/")

                                                機能

                                                EMF/EMFPLUSの出力時に、PAliteが印刷データを受信したタイミングで印刷イメージを画面に表示します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{ENABLEPREVIEW mode}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{ENABLEPREVIEW mode}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{ENABLEPREVIEW mode}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{ENABLEPREVIEW mode}/") As Integer

                                                引数

                                                • mode

                                                  プレビューモード

                                                  • 0

                                                    印刷イメージを表示しない

                                                  • 1

                                                    印刷イメージを表示する（印刷不可）

                                                  • 3

                                                    印刷イメージを表示する（印刷可）

                                                注意

                                                ビットのON/OFFにより動作を変更しているため、modeに「2」を指定すると印刷イメージは表示されません。

                                                戻り値

                                                • 0

                                                  固定（常に0が返ります）

                                                説明

                                                EMF/EMFPLUSの印刷イメージを制御するときに使用します。

                                                使用例

                                                印刷イメージを画面に表示した後、印刷します。

                                                • Java/C#

                                                  svf.VrComout("/{ENABLEPREVIEW 3}/");

                                                • ASP/VB

                                                  svf.VrComout("/{ENABLEPREVIEW 3}/")

                                                • C

                                                  VrComout(svf, "/{ENABLEPREVIEW 3}/");

                                                • VB.NET

                                                  svf.VrComout("/{ENABLEPREVIEW 3}/")

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "EMF");
svf.VrComout("/{ENABLEPREVIEW 3}/");
svf.VrSetForm("sample.xml", 4);
svf.VrsOut("F1", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();
