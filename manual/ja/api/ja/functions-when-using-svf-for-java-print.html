                                                3.2. 各社プリンター対応機種使用時の関数

                                                これらの印刷制御関数は、プリンター機種により使用できるものが異なります。使用するプリンター機種で使用可能なAPIを「機種別対応関数一覧」で確認した上で使用してください。また、デバイスにオプション機器を装着していないと使用できないものや、デバイスのファームウェアのバージョンによってはサポートしていないものがあるため、必ず事前に動作を検証してください。

                                                関数名

                                                機能

                                                VrSetTray

                                                出力時の給紙トレイを指定します。

                                                VrSetDuplex

                                                両面印刷を指定します。

                                                VrSetOutputBin

                                                排紙先を指定します。

                                                VrSetSort

                                                出力紙のソート条件を指定します。

                                                VrSetStaple

                                                ステープル機能を指定します。

                                                VrSetPunch

                                                パンチ機能を指定します。

                                                VrComout("/{PTYP n}/")

                                                文書の紙種を指定します。

                                                VrComout("/{PSOP デバイス名 n}/")

                                                使用するデバイス名と識別IDを指定します。

                                                VrComout("/{STID id,password}/")

                                                「部門別ID管理」の部門IDとパスワードを指定します。

                                                VrPaperEject

                                                デバイス内部に残っている用紙を排出します。

                                                VrComout("/{SPJL PCL5 variable=value}/")

                                                PCL5機種のPJLのSETコマンドを出力します。

                                                VrComout("/{SPJL PCL5 command variable=value}/")

                                                PCL5機種のPJLの任意コマンドを出力します。

                                                VrComout("/{SPJL RPCS variable=value}/")

                                                RPCS機種のPJLのSETコマンドを出力します。

                                                VrComout("/{SPJL RPCS command variable=value}/")

                                                RPCS機種のPJLの任意コマンドを出力します。

                                                参考

                                                各社プリンター対応機種使用時の関数には、このほかに、ICカード認証によるセキュリティプリント機能を使用する場合に使用する関数があります。詳細は、「ICカード認証によるセキュリティプリントの関数」を参照してください。

                                                VrSetTray

                                                機能

                                                出力時の給紙トレイを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetTray(int Tray);

                                                • ASP/VB

                                                  Function instance.VrSetTray(Tray As Long) As Long

                                                • C

                                                  int VrSetTray(HSVFRCLIENT instance, int Tray);

                                                • VB.NET

                                                  Function instance.VrSetTray(Tray As Integer) As Integer

                                                引数

                                                • Tray

                                                  トレイ番号

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                出力時の給紙トレイを指定します。このAPI関数の指定がない場合、XML様式ファイル設計時に指定されたトレイが選択されます。指定可能なトレイはプリンター機種により異なります。SVF環境設定の［トレイn］という定義の「n」を指定してください。対応プリンター機種の詳細は、『SVF帳票出力製品管理ガイド』の「プリンター機種別設定」を参照してください。

                                                使用例

                                                トレイ2を指定します。

                                                • Java/C#

                                                  svf.VrSetTray(2);

                                                • ASP/VB

                                                  svf.VrSetTray(2)

                                                • C

                                                  VrSetTray(svf, 2);

                                                • VB.NET

                                                  svf.VrSetTray(2)

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("sample.xml", 5); //これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrSetTray(2);       //VrSetForm関数の後に発行します。
svf.VrsOut("Field", "Data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                両面印刷を指定します。

                                                書式

                                                  int instance.VrSetDuplex(int Mode, int Margin);

                                                • ASP/VB

                                                • VB.NET

                                                  Function instance.VrSetDuplex(Mode As Integer, Margin As Integer) As Integer

                                                引数

                                                • Mode

                                                  綴じ方向

                                                  • 0

                                                    解除

                                                  • 1

                                                    上綴じ

                                                  • 2

                                                    左綴じ

                                                  • 3

                                                    右綴じ

                                                • Margin

                                                  綴じ代（0～50mm、ミリ単位）

                                                  参考

                                                  デバイスによっては、指定した量の綴じ代が反映されない場合があります。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                両面印刷を指定します。対応プリンター機種の詳細は、『SVF帳票出力製品管理ガイド』の「プリンター機種別設定」を参照してください。この関数はVrSetForm関数の後で指定します。

                                                使用例

                                                左綴じの両面印刷で綴じ代を10mmと指定します。

                                                • Java/C#

                                                  svf.VrSetDuplex(2, 10);

                                                • ASP/VB

                                                  svf.VrSetDuplex(2, 10)

                                                • C

                                                  VrSetDuplex(svf, 2, 10);

                                                • VB.NET

                                                  svf.VrSetDuplex(2, 10)

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("sample.xml", 4); //これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrSetDuplex(2, 10);
svf.VrsOut("Field", "Data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                引数

                                                • Bin

                                                  排紙先トレイ

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                出力時の排紙先トレイを指定します。このAPI関数の指定がない場合、デバイスで設定されている排紙先に出力されます。指定可能な排紙先番号はプリンター機種により異なります。SVF環境設定の［排紙ビンn］という定義の「n」を指定してください。対応プリンター機種の詳細は、『SVF帳票出力製品管理ガイド』の「プリンター機種別設定」を参照してください。

                                                参考

                                                ステープル機能を併用する場合には、必ずフィニッシャーシフトトレイを指定してください。プリンター機種ごとのフィニッシャーシフトトレイの排紙先番号は『SVF帳票出力製品管理ガイド』の「プリンター機種別設定」を参照してください。

                                                使用例

                                                排紙先1を指定します。

                                                • Java/C#

                                                  svf.VrSetOutputBin(1);

                                                • ASP/VB

                                                  svf.VrSetOutputBin(1)

                                                • C

                                                  VrSetOutputBin(svf, 1);

                                                • VB.NET

                                                  svf.VrSetOutputBin(1)

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("\\home\\svf\\sample.xml", 5);
svf.VrSetOutputBin(1);
svf.VrsOut("Field", "Data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                • VB.NET

                                                • VrSetFormの前に指定します。

                                                • SVF環境設定のLIPS4機種設定で、［周辺機器の制御方法］に、「CPCA-LBP」、「CPCA-iR」、または「CPCA2」を指定しておく必要があります。

                                                例 1. 関数使用順

                                                書式

                                                • ASP/VB

                                                  Function instance.VrPaperEject() As Long

                                                • C

                                                  int VrPaperEject(HSVFRCLIENT instance);

                                                • VB.NET

                                                  Function instance.VrPaperEject() As Integer

                                                引数

                                                なし

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                両面印刷実行時に、奇数ページで印刷が終了すると、デバイス内部に最終ページが残ります。印刷終了時にこの関数を実行すると、最終ページが自動的に排出されます。

                                                また、連写機能を使用したXML様式ファイルを実行する場合、1ページ内のすべての連写アイテムに満たない数で最終ページが終了した場合にも、VrPaperEject関数でページの排出が可能です。

                                                注意

                                                レポートライターモードでVrPaperEjectを使用する場合は、VrPaperEjectを実行する前にVrPrintを実行する必要があります。

                                                使用例

                                                使用例は、以下のとおりです。

                                                • Java/C#

                                                  svf.VrPaperEject();

                                                • ASP/VB

                                                  svf.VrPaperEject()

                                                • C

                                                  VrPaperEject(svf);

                                                • VB.NET

                                                  svf.VrPaperEject()

                                                参考

                                                両面印刷で片面印刷終了時の排出処理は、デバイスにより機能しない場合があります。
