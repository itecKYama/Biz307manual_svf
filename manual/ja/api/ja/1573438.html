                                                VrSetCalcMode

                                                機能

                                                最大37桁（整数部＋小数部）の十進演算ライブラリをサポートします。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetCalcMode(int Mode);

                                                • ASP/VB

                                                  Function instance.VrSetCalcMode(Mode As Long) As Long

                                                • C

                                                  int VrSetCalcMode(HSVFRCLIENT instance, int Mode);

                                                • VB.NET

                                                  Function instance.VrSetCalcMode(Mode As Integer) As Integer

                                                引数

                                                • Mode

                                                  演算動作指定

                                                  • 0

                                                    各言語のdouble型（倍精度浮動小数点）演算

                                                  • 1

                                                    多倍精度十進浮動小数点型演算

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                15桁以上の数値データを扱う場合に使用します。この関数の引数Modeを1にして呼び出すと、数値データを37桁（整数部＋小数部）まで出力できます。この関数による指定がない場合には、基本設定ファイルの設定に従います。

                                                参考

                                                • 演算結果が最大有効桁数を超えた場合は、最下位桁が切り捨てられます。

                                                  また演算途中で最大有効桁数を超えた場合も、その時点の結果の最下位桁が切り捨てられます。

                                                • 多倍精度十進浮動小数点型演算を使用する場合には、数値型フィールドに対して数値データを出力する関数としてVrsOut/VrsOutn関数を使用し、数値データを文字列データとして出力してください。

                                                • 基本設定ファイルの変更時には、弊社サポートセンターまでご連絡ください。

                                                  他の部分を変更するとSVFの動作が変わってしまう場合があります。そのような場合には、サポート対象外となる可能性もありますので、ご了承ください。

                                                使用例

                                                • Java/C#

                                                  svf.VrSetCalcMode(1);

                                                • ASP/VB

                                                  svf.VrSetCalcMode(1)

                                                • C

                                                  VrSetCalcMode(svf,1);

                                                • VB.NET

                                                  svf.VrSetCalcMode(1)

                                                関数使用順

                                                svf.VrInit();
svf.VrSetCalcMode(1);
svf.VrSetPrinter("", "printer");
svf.VrSetForm("sample.xml", 1); 　　//これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrsOut("Field", "Data");
svf.VrEndPage();
svf.VrQuit();

                                                VrOutputQuery

                                                機能

                                                VrSetQuery関数で指定したクエリーを実行した際にデータベースから取得されたデータを、指定したファイルにCSV形式で保存します。

                                                書式

                                                • Java/C#

                                                  int instance.VrOutputQuery(String FileName);

                                                • ASP/VB

                                                  Function instance.VrOutputQuery(FileName As String) As Long

                                                • C

                                                  int VrOutputQuery(HSVFRCLIENT instance, char *FileName);

                                                • VB.NET

                                                  Function instance.VrOutputQuery(FileName As String) As Integer

                                                引数

                                                • FileName

                                                  保存するCSVファイル名を指定します。

                                                戻り値

                                                • 正数

                                                  処理完了（出力したファイルサイズ（バイト数））

                                                • 0

                                                  処理完了（出力すべきデータがなかった）

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                VrSetQuery関数で実行するクエリー様式ファイルの内容に従ってデータベースから取得した内容を、CSV形式（カンマ区切り）のファイルとして出力します。

                                                参考

                                                VrOutputQuery関数は、データベースから取得したデータをCSVに出力する関数です。XML様式ファイル内に設定してある編集式や計算式は適用されません。編集式や計算式を反映した形でCSVファイルを出力したい場合は、CSV機種を使用してください。

                                                使用例

                                                • Java/C#

                                                  svf.VrOutputQuery("c:\\svf\\data.csv");

                                                • ASP/VB

                                                  svf.VrOutputQuery("c:\svf\data.csv")

                                                • C

                                                  VrOutputQuery(svf, "c:\\svf\\data.csv");

                                                • VB.NET

                                                  svf.VrOutputQuery("c:\svf\data.csv")

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("sample.xml", 5);
svf.VrSetQuery("UID=xxx;PWD=xxx", "sample.vrq", 0);
svf.VrOutputQuery("data.csv");
svf.VrExecQuery();
svf.VrPrint();
svf.VrQuit();

                                                VrGetManageNum

                                                機能

                                                スプールされた文書の文書管理番号を取得します。Report Director Enterpriseの文書管理番号の他に、SVFスプーラーに送信した場合のJOB番号を取得できます。

                                                書式

                                                • Java/C#

                                                  int instance.VrGetManageNum();

                                                • ASP/VB

                                                  Function instance.VrGetManageNum() As Long

                                                • C

                                                  int VrGetManageNum(HSVFRCLIENT instance);

                                                • VB.NET

                                                  Function instance.VrGetManageNum() As Integer

                                                引数

                                                なし

                                                戻り値

                                                • 1以上

                                                  正常（文書管理番号）

                                                • -1

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                スプールした文書の文書管理番号を取得します。

                                                Report Director Enterpriseでは、VrPrint関数実行後でVrQuit関数実行前に使用できます。

                                                SVFスプーラーに送信した文書はVrQuit関数後に実行することでJOB番号を取得できます。

                                                ただし、APIの呼び出しタイミングを間違えている場合や、SVFスプーラーに送信しない場合（ファイル出力やPAliteへ直接送信）はJOB番号を取得できず、-1が返ります。

                                                使用例

                                                スプールされた文書の文書管理番号を取得します。

                                                • Java/C#

                                                  nNum = svf.VrGetManageNum();

                                                • ASP/VB

                                                  nNum = svf.VrGetManageNum()

                                                • C

                                                  nNum = VrGetManageNum(svf);

                                                • VB.NET

                                                  nNum = svf.VrGetManageNum()

                                                関数使用順

                                                • SVFスプーラーのJOB番号を取得する場合

                                                  svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("HACHUSHO.xml", 4);
svf.VrsOut("商品名", "Report Director Enterprise");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();
nNum = svf.VrGetManageNum();

                                                • RDEの文書管理番号を取得する場合

                                                  svf.VrInit();
svf.VrSetPrinter("", "RDSpool");
svf.VrSetForm("HACHUSHO.xml", 4);
svf.VrsOut("商品名", "Report Director Enterprise");
svf.VrEndRecord();
svf.VrPrint();
nNum = svf.VrGetManageNum();
svf.VrQuit();

                                                VrComout("/{ALNK n}/")

                                                機能

                                                自動リンクフィールドの動作方式を設定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{ALNK n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{ALNK n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance,"/{ALNK n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{ALNK n}/") As Integer

                                                引数

                                                モードを指定します。

                                                • 0

                                                  拡張自動リンクモードを解除し、通常の自動リンク動作を設定します。自動リンクフィールドの改行による改ページ動作は行いません。改行は、サブフォーム領域を超えることがあります。

                                                • 1

                                                  拡張自動リンクモード1を設定します。改行先を含めたすべてがサブフォーム領域内に入らなければ改ページを行います。

                                                  このモードを設定しているにもかかわらず合計レコードまたは総計レコードが同一ページに出力されている場合は、SVF設計部製品の合計レコードまたは総計レコードの［サブフォーム内に入らない場合も、印刷する］がオフになっていることを確認してください。

                                                • 2

                                                  拡張自動リンクモード2を設定します。サブフォーム領域内に表示できない部分は改ページして表示します。ただし、ヘッダーレコード、合計レコードは改行先を含めたすべてがサブフォーム領域内に入らなければ改ページを行います。

                                                  このモードを設定しているにもかかわらず合計レコードが同一ページに出力されている場合は、SVF設計部製品の合計レコードの［サブフォーム内に入らない場合も、印刷する］がオフになっていることを確認してください。

                                                • 3

                                                  拡張自動リンクモード3を設定します。サブフォーム領域内に表示できない部分は改ページして表示します。ただし、ヘッダーレコードは改行先を含めたすべてがサブフォーム領域内に入らなければ改ページを行います。

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                自動リンクフィールドのある帳票を扱う場合に使用します。

                                                この関数が指定されていない場合は、既定値（0：通常の自動リンクモード）となります。

                                                使用例

                                                拡張自動リンクモード1を設定します。

                                                • Java/C#

                                                  svf.VrComout("/{ALNK 1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{ALNK 1}/")

                                                • C

                                                  VrComout(svf,"/{ALNK 1}/");

                                                • VB.NET

                                                  svf.VrComout("/{ALNK 1}/")

                                                VrComout("/{DBLG n}/")

                                                機能

                                                デバッグログのデバッグレベルを変更します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DBLG n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DBLG n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance,"/{DBLG n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DBLG n}/") As Integer

                                                引数

                                                デバッグレベルを指定します。

                                                • 0

                                                  呼び出し後、デバッグログは出力されません。

                                                • 0以外

                                                  呼び出し後、指定したデバッグレベルのログが出力されます。

                                                  VrInit関数以降に呼び出し、VrQuit関数または次にこの関数が呼ばれるまで有効です。

                                                  指定値「1539」でSVF環境設定上の［デバッグレベル］に「1」、「2」、「10」、「11」を指定した場合と同じ出力になります。それ以外のレベルは、トラブルシューティング時にサポートセンターから指示があった場合などに指定します。

                                                VrComout("/{DVUN n}/")

                                                機能

                                                ファイルを分割して出力する場合に、1ファイル分のページ数を指定します（Ver. 10.1で対応）。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DVUN n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DVUN n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance,"/{DVUN n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DVUN n}/") As Integer

                                                引数

                                                • n

                                                  1ファイル分のページ数

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                印刷データを分割してファイル出力する場合に、1ファイル分として出力するページ数を指定します。指定したページ数を超えると、別ファイルとして出力します。「0」を指定した場合、ファイルは分割されません。

                                                • C

                                                  VrComout(svf,"/{DVUN 10}/");

                                                • VB.NET

                                                  svf.VrComout("/{DVUN 10}/")

                                                VrComout("/{DVFX Postfix}/")

                                                機能

                                                ファイルを分割して出力する場合に、ファイル名の末尾（拡張子の直前）にどのように番号を付加するかを指定します（Ver. 10.1で対応）。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{DVFX Postfix}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{DVFX Postfix}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance,"/{DVFX Postfix}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{DVFX Postfix}/") As Integer

                                                引数

                                                • Postfix

                                                  ファイル名の末尾（拡張子の直前）にどのように番号を付加するか指定します。

                                                  • Z

                                                    出力ファイルの分割順に0から連番を付加

                                                  • C

                                                    出力ファイルの分割順に1から連番を付加

                                                  • P

                                                    分割した時点のページ数を付加

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                印刷データを分割してファイル出力する場合に、ファイル名が重複しないように、各ファイルのファイル名の末尾（拡張子の直前）に、どのように番号を付加するかを指定します。

                                                VrComout("/{DVFX Postfix}/")関数を指定しないでファイルを分割して出力した場合、自動的に引数で「Z」が指定された状態となり、最初に出力されるファイルのファイル名の末尾に「0」を付加します。以降に出力されるファイルのファイル名の末尾には「1」からの連番が付加されます。

                                                プリンター機種「Adobe PostScript」と「PDF」で使用できます。

                                                使用例

                                                test_1.pdf、test_2.pdfのように出力ファイルの分割順に1から番号を付加します。

                                                • Java/C#

                                                  svf.VrComout("/{DVFX <C>}/");

                                                • ASP/VB

                                                  svf.VrComout("/{DVFX <C>}/")

                                                • C

                                                  VrComout(svf,"/{DVFX <C>}/");

                                                • VB.NET

                                                  svf.VrComout("/{DVFX <C>}/")

                                                VrComout("/{BNFN FileName}/")

                                                機能

                                                ファイルを分割して出力する場合に使用する、バナー様式ファイルを指定します。（Ver. 10.1で対応）。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{BNFN FileName}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{BNFN FileName}/") As Long

                                                • C

                                                • VB.NET

                                                  Function instance.VrComout("/{BNFN FileName}/") As Integer

                                                引数

                                                  バナー様式ファイルを指定します。

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                印刷データを分割してファイル出力するときに、各ファイルの先頭ページにバナーを出力できます。バナーを出力する場合は、SVF設計部で別途作成したバナー様式ファイルを指定します。

                                                • VB.NET
