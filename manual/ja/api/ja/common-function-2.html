                                                VrCondition

                                                機能

                                                クエリーの抽出条件を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrCondition(String pic, int mode);

                                                • ASP/VB

                                                  Function instance.VrCondition(pic As String, mode As Long) As Long

                                                • C

                                                  int VrCondition(HSVFRCLIENT instance, char *pic, int mode);

                                                • VB.NET

                                                  Function instance.VrCondition(pic As String, mode As Integer) As Integer

                                                引数

                                                • pic

                                                  抽出条件を指定します。

                                                • mode

                                                  モード

                                                  • 0

                                                    条件式を設計時に指定した条件式と置き換えます。設計時の条件をクリアする場合には""を指定します。

                                                  • 1

                                                    条件式を設計時に指定した条件式にANDで追加します。

                                                  • 3

                                                    VrCondition関数で設定した条件をクリアし、設計時の条件式に戻します。

                                                  • 4

                                                    クエリーデザイナーで設定した変数に値を代入します。

                                                  • 5

                                                    VrCondition関数のモード4で指定した抽出条件をすべてクリアし、設計時の状態に戻します。

                                                  • 6

                                                    実行時のテーブル名を変更します。

                                                    　"［設計時のテーブル名］=［実行時のテーブル名］"

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                VrSetQuery関数以降、VrExecQuery関数以前にこの関数を発行する必要があります。

                                                参考

                                                • クエリー設計時に変数を使用している場合、VrCondition関数を使わずに実行するとエラーが発生します。変数を使用している場合には、必ずVrCondition関数のモード4を使用して値を代入してください。

                                                • 複数の抽出条件を指定したい場合、VrCondition関数を複数発行するのではなく、1回のVrCondition関数内で"AND"や"OR"の連結子を使用して実行してください。

                                                • モード6を使用する場合の注意点

                                                  • 同種のデータ構造を持つテーブルのみ指定可能です。

                                                    また、指定するテーブル名と、クエリー様式ファイル内の［DATABASE］セクションのDBnに記述されているテーブル名とが、完全に一致している必要があります。一致していない場合には、実行は受け付けられずエラーとなります。

                                                  • クエリー様式ファイル内では、接続DBドライバーが推奨する引用符をドライバーから取得するため、接続ドライバーによって、クエリー様式ファイル内で管理する引用符が異なります。

                                                    一度クエリー様式ファイルをテキストエディターで開き、［DATABASE］セクションのDBnに記述されているテーブルを確認してから指定してください。ただし、クエリー様式ファイル自体をテキストエディター上で修正し、実行することは、サポートの対象外の事項となります。クエリー様式ファイルをテキストエディターで開くことは、あくまでも確認する場合のみにしてください。

                                                  • クエリー様式ファイルがDB1="明細"となっている場合には、両端の二重引用符を取り除いた［'明細'］をテーブル名として指定します。

                                                使用例

                                                モード0を使用して設計時の条件をクリアします。

                                                • Java/C#

                                                  svf.VrCondition("", 0);

                                                • ASP/VB

                                                  svf.VrCondition("", 0)

                                                • C

                                                  VrCondition(svf, "", 0);

                                                • VB.NET

                                                  svf.VrCondition("", 0)

                                                関数使用順

                                                • 条件式を設計時に指定した条件式と置き換える場合

                                                  svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetSpoolFileName2("sample.pdf");
svf.VrSetForm("sample.xml", 4);
svf.VrSetQuery("UID=WingArc;PWD=WingArc", "sample.vrq", 0);
svf.VrCondition("［code］Between 001 AND 010", 0);
svf.VrExecQuery();
svf.VrPrint();
svf.VrQuit();

                                                • 設計している変数に値を代入する場合

                                                  //設計時に指定した条件式:BETWEEN ［9| start_code］ AND ［9| end_code］
svf.VrInit();
svf.VrSetPrinter("", "EMF");
svf.VrSetSpoolFileName2("sample.pdf");
svf.VrSetForm("sample.xml", 5);
svf.VrSetQuery("UID=WingArc;PWD=WingArc", "sample.vrq, 0");
svf.VrCondition("［9| start_code］ = 001", 4);
svf.VrCondition("［9| end_code］ = 010", 4);
svf.VrExecQuery();
svf.VrPrint();
svf.VrQuit();

                                                VrSetPageCount

                                                機能

                                                設計関数のPAGE関数の初期値と加算値を設定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetPageCount(int no, int add);

                                                • ASP/VB

                                                  Function instance.VrSetPageCount(no As Long, add As Long) As Long

                                                • C

                                                  int VrSetPageCount(HSVFRCLIENT instance, int no, int add);

                                                • VB.NET

                                                  Function instance.VrSetPageCount(no As Integer, add As Integer) As Integer

                                                引数

                                                • no

                                                  PAGEの初期値

                                                • add

                                                  PAGEの加算値

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                設計関数のPAGE関数は、VrSetPageCount関数で指定した値によって連番を取得します。VrSetPageCount関数を使用しない場合は、VrInit関数あるいはVrSetForm関数が実行されると、初期値、加算値がそれぞれ「1」にセットされます。

                                                参考

                                                VrSetPageCount関数はVrSetForm関数の次に発行するようにしてください。

                                                使用例

                                                PAGE関数に対して、ページ番号の初期値を「5」にし、加算値を「1」と指定します。

                                                • Java/C#

                                                  svf.VrSetPageCount(5, 1);

                                                • ASP/VB

                                                  svf.VrSetPageCount(5, 1)

                                                • C

                                                  VrSetPageCount(svf, 5, 1);

                                                • VB.NET

                                                  svf.VrSetPageCount(5, 1)

                                                参考

                                                VrGetAttribute関数を使用して総ページを取得するには、VrSetForm関数のモードが「4」か「5」である必要があります。詳細は、「VrGetAttribute」を参照してください。なお、クエリー、レコードを使用していない帳票でも、VrSetForm関数のモードを「4」か「5」で指定できます。その場合のAPIの流れは、レコードを使用している場合と同様です。

                                                関数使用順

                                                • 基本

                                                  svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetForm("sample.xml", 5);　//これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrSetPageCount(5, 1);
svf.VrsOut("field", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                • 応用（2つの帳票を使用し、ページを連番で取得する）

                                                  StringBuffer buf = new StringBuffer();
svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetForm("sample1.xml", 5);svf.VrsOut("field", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrGetAttribute("", "TotalPageCount", buf);  //1つめの帳票の総ページを取得
String page_no1 = buf.toString();
int page_cnt1 = Integer.valueOf(page_no1).intValue();
page_cnt1++;  //次の帳票の初期値指定のために取得したページ数に+1
svf.VrSetForm("sample2.xml", 5);
svf.VrSetPageCount(page_cnt1, 1);  //+1した値を初期値として指定
svf.VrsOut("field", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                VrCopy

                                                機能

                                                印刷部数を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrCopy(int n);

                                                • ASP/VB

                                                  Function instance.VrCopy(n As Long) As Long

                                                • C

                                                  int VrCopy(HSVFRCLIENT instance, int n);

                                                • VB.NET

                                                  Function instance.VrCopy(n As Integer) As Integer

                                                引数

                                                • n

                                                  部数

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                同一ページを指定した部数出力します。新たにVrCopy関数を呼び出して部数をセットするか、または、新たにXML様式ファイルを指定するまで、指定した部数を出力します。この関数を使用しない場合は、設計時に指定した部数に従って出力されます。

                                                設計時に指定した部数と、VrCopy関数を使用して指定した部数が異なる場合には、VrCopy関数で指定した部数が有効です。

                                                使用例

                                                印刷部数を「3」に指定します。

                                                • Java/C#

                                                  svf.VrCopy(3);

                                                • ASP/VB

                                                  svf.VrCopy(3)

                                                • C

                                                  VrCopy(svf, 3);

                                                • VB.NET

                                                  svf.VrCopy(3)

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "printer");
svf.VrSetForm("sample.xml", 1);　　//これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrSetPageCount(1, 1);
svf.VrCopy(3);
svf.VrsOut("field", "data");
svf.VrEndPage();
svf.VrQuit();

                                                注意

                                                VrCopy関数はVrSetForm関数とVrEndPage関数の間で実行します。

                                                VrSetDocName2

                                                機能

                                                1. Report Director Enterpriseへスプールする文書名を指定します。

                                                2. PDFで作成されたPDF文書のプロパティでのタイトルを指定します。

                                                3. SVFスプーラーで表示する文書名を指定します。

                                                4. SVGファイルをhtml形式に出力する場合、htmlの<title>要素内のタイトルを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetDocName2(String DocName);

                                                • ASP/VB

                                                  Function instance.VrSetDocName2(DocName As String) As Long

                                                • C

                                                  int VrSetDocName2(HSVFRCLIENT instance, char *DocName);

                                                • VB.NET

                                                  Function instance.VrSetDocName2(DocName As String) As Integer

                                                引数

                                                • DocName

                                                  文書名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                1. Report Director Enterpriseにスプールする際の文書名を指定します。

                                                  このAPI関数を使用し文書名を指定しておくと、RDEユーティリティに文書名として表示されます。

                                                2. PDF機種で作成されたPDF文書のプロパティでのタイトルを指定します。

                                                3. SVFスプーラーで表示する文書名を指定します。

                                                4. SVGファイルをhtml形式に出力する場合、<title>要素内のタイトルを指定します。

                                                使用例

                                                スプールする際の文書名を指定します。

                                                • Java/C#

                                                • ASP/VB

                                                  svf.VrSetDocName2("仕訳日記帳")

                                                • C

                                                  VrSetDocName2(svf,"仕訳日記帳");

                                                • VB.NET

                                                  svf.VrSetDocName2("仕訳日記帳")

                                                VrSetSpoolFileName2

                                                機能

                                                ファイルを出力する際のファイル名とその出力場所を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetSpoolFileName2(String FileName);

                                                • ASP/VB

                                                  Function instance.VrSetSpoolFileName2(FileName As String) As Long

                                                • C

                                                  int VrSetSpoolFileName2(HSVFRCLIENT instance, char *FileName);

                                                • VB.NET

                                                  Function instance.VrSetSpoolFileName2(FileName As String) As Integer

                                                引数

                                                • FileName

                                                  ファイル名（最大255バイト）

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                作成するファイル名とその作成場所を指定します。VrSetPrinter関数で複数の出力先を指定した場合は、セパレーター「|」で区切って出力先の指定と同じ順番で、ファイル名とその作成場所を指定します。また、デバイスへの出力が指定されている場合は、空文字列（""）を指定します。VrSetSpoolFileName2関数を使用しない場合は、SVF環境設定の［出力ディレクトリ］欄で指定されているパスへファイルが作成されます。

                                                参考

                                                • 作成するファイルがすでに存在している場合は上書きされます。ただし、既存のファイルがオープンされている場合や、何らかの理由により使用されている場合には上書きできません。

                                                  ファイル名に日付や時間等を入れて保存すると、上書きなどの処理が発生する可能性が低くなります。

                                                • コネクト製品から実行する場合は、作成されたファイルを呼び出し元であるクライアントに戻します。このため、ファイルの保存先は、クライアント側からのパスを指定する必要があります。

                                                  このとき、XML様式ファイル名やクエリー様式ファイル名の指定は、ファイルを生成するSVFがインストールされているサーバー側から見たパスを指定してください。

                                                使用例

                                                • /home/svf/に「sample.pdf」を作成する場合

                                                  • Java/C#

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf");

                                                  • ASP/VB

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf")

                                                  • C

                                                    VrSetSpoolFileName2(svf, "/home/svf/sample.pdf");

                                                  • VB.NET

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf")

                                                • VrSetPrinter関数の第2引数に複数の出力先を指定し、1つ目の出力先が「PDF」、2つ目の出力先がデバイスの場合

                                                  • Java/C#

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf|"); 

                                                  • ASP/VB

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf"|")

                                                  • C

                                                    VrSetSpoolFileName2(svf, "/home/svf/sample.pdf"|");

                                                  • VB.NET

                                                    svf.VrSetSpoolFileName2("/home/svf/sample.pdf"|")

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "PDF|printer");
svf.VrSetSpoolFileName2("/home/svf/sample.pdf|"); 
svf.VrSetForm("sample.xml", 5);　　//これ以降は「第2章　基本的なプログラムの流れ」を参照してください。
svf.VrsOut("Field", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                VrAdjustd / VrAdjustm

                                                機能

                                                印字位置を調整し、調整後の印字位置をXML様式ファイルに保存します。

                                                書式

                                                • Java/C#

                                                  int instance.VrAdjustd(String Form, int x, int y);
int instance.VrAdjustm(String Form, int x, int y);

                                                • ASP/VB

                                                  Function instance.VrAdjustd(Form As String, x As Long, y As Long) As Long
Function instance.VrAdjustm(Form As String, x As Long, y As Long) As Long

                                                • C

                                                  int VrAdjustd(char *Form, HSVFRCLIENT instance, int x, int y);
int VrAdjustm(char *Form, HSVFRCLIENT instance, int x, int y);

                                                • VB.NET

                                                  Function instance.VrAdjustd(Form As String, x As Integer, y As Integer) As Integer
Function instance.VrAdjustm(Form As String, x As Integer, y As Integer) As Integer

                                                引数

                                                • Form

                                                  XML様式ファイル名

                                                • x

                                                  左右調整値（正=右方向、負=左方向）

                                                • y

                                                  上下調整値（正=下方向、負=上方向）

                                                  調整値の単位はコマンドにより次のように異なります。

                                                  • VrAdjustd関数の場合

                                                    1ドット（1ドット=1/400インチ、約0.06ミリ）

                                                  • VrAdjustm関数の場合

                                                    1/10ミリ

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                ドット、またはミリ単位でXML様式ファイルの印字位置を移動します。この関数で指定した調整値はXML様式ファイルに保存され、以降の印刷はこの調整値で調整した位置に出力されます。

                                                参考

                                                • この関数を一度使用すると、XML様式ファイル内に情報が書き込まれます。一時的に印字位置を変更する場合には、VrAdjustd2/VrAdjustm2関数を使用してください。

                                                • 印字位置の調整は、VrSetPrinter関数で指定したプリンターのSVF環境設定の印字位置調整量と、XML様式ファイルに設定した印字位置調整値に加算されます。

                                                使用例

                                                • sample.xmlの印字位置を左に40ドット、下に20ドット移動

                                                  • Java/C#

                                                    svf.VrAdjustd("sample.xml", -40, 20);

                                                  • ASP/VB

                                                    svf.VrAdjustd("sample.xml", -40, 20)

                                                  • C

                                                    VrAdjustd("sample.xml" , svf, -40, 20);

                                                  • VB.NET

                                                    svf.VrAdjustd("sample.xml", -40, 20)

                                                • sample.xmlの印字位置を左に4ミリ、下に2ミリ移動

                                                  • Java/C#

                                                    svf.VrAdjustm("sample.xml", -40, 20);

                                                  • ASP/VB

                                                    svf.VrAdjustm("sample.xml", -40, 20)

                                                  • C

                                                    VrAdjustm("sample.xml", svf, -40, 20);

                                                  • VB.NET

                                                    svf.VrAdjustm("sample.xml", -40, 20)

                                                VrAdjustd2 / VrAdjustm2

                                                機能

                                                印字位置を一時的に調整します。

                                                書式

                                                • Java/C#

                                                  int instance.VrAdjustd2(int x, int y);
int instance.VrAdjustm2(int x, int y);

                                                • ASP/VB

                                                  Function instance.VrAdjustd2(x As Long, y As Long) As Long
Function instance.VrAdjustdm2(x As Long, y As Long) As Long

                                                • C

                                                  int VrAdjustd2(HSVFRCLIENT instance, int x, int y);
int VrAdjustm2(HSVFRCLIENT instance, int x, int y);

                                                • VB.NET

                                                  Function instance.VrAdjustd2(x As Integer, y As Integer) As Integer
Function instance.VrAdjustdm2(x As Integer, y As Integer) As Integer

                                                引数

                                                • x

                                                  左右調整値（正=右方向、負=左方向）

                                                • y

                                                  上下調整値（正=下方向、負=上方向）

                                                  調整値の単位はコマンドにより次のように異なります。

                                                  • VrAdjustd2の場合

                                                    1ドット（1ドット=1/400インチ、約0.06ミリ）

                                                  • VrAdjustm2の場合

                                                    1/10ミリ

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                • ASP言語を使用している場合、ASP上で定義する変数に明確な型が存在しないため、型変換が行えません。このため、VrGetAttribute関数は使用できません。

                                                • "X""Y"ではフィールドの座標を取得することは可能ですが、サブフォームやレコードなどのアイテムの座標を取得することはできません。

                                                  • 出力処理が正常に実行されている

                                                  • VrQuitが実行された後に呼び出している

                                                フィールドの属性を取得する場合には、静的な状態で情報を取得してください。印刷データを生成中に属性値を取得した場合の動作は保証していません。

                                                0001    002
0003

                                                と出力します。

                                                綴りページをページごとに印字するかどうかを指定したい場合に使用します。VrPage関数が発行されない場合には、すべての綴りページが出力されます。一度、印字対象ページを指定し、次に異なるページを指定したい場合には、VrSetFormのモードにより考慮が必要です。

                                                綴りページ数が「5」の際に、綴りページの1、2、5ページを印字し、3、4ページは印字しません。

                                                • C

                                                • VB.NET

                                                  svf.VrPage("11001")

                                                関数使用順

                                                • ランダムモードの場合

                                                  VrPage関数を実行し、次に実行されるVrEndPage関数が実行されたページから指定が有効になります。

                                                  svf.VrInit();
svf.VrSetPrinter("","printer");
svf.VrSetForm("sample.xml", 1);
svf.VrPage("11001");
svf.VrsOut("Field", "Data1");
svf.VrEndPage();
svf.VrPage("00110");
svf.VrsOut("Field", "Data2");
svf.VrEndPage();  // このページから「VrPage("00110")」の指定が有効になります。
svf.VrQuit();

                                                • レポートライターモードの場合

                                                  綴りページを切り替えるには、必ずVrSetFormを実行します。

                                                  svf.VrInit();
svf.VrSetPrinter("","printer");
svf.VrSetForm("sample.xml", 4);
svf.VrPage("11001");
svf.VrsOut("Field", "Data1");
svf.VrEndRecord();
svf.VrSetForm("sample.xml", 4); //このVrSetForm以後の「VrPage("00110")」の指定が有効になります。
svf.VrPage("00110");
svf.VrsOut("Field", "Data2");
svf.VrEndRecord
svf.VrQuit();
