                                                1. API関数の呼び出し方法

                                                SVFが提供するAPI関数を呼び出す方法には次の3つがあります。

                                                1. Javaを使用する

                                                  Javaプログラムから直接、またはSVF Connect for Java APIを使用して呼び出します。

                                                2. C言語、ASP、Visual Basic言語を使用する

                                                  SVF Connect for ASP/COM APIを使用して呼び出します。

                                                3. .NETを使用する

                                                  SVF Connect for .NET Framework APIを使用して呼び出します。

                                                参考

                                                • SVF Ver. 6.3から、全APIの文字列パラメーターに対するNullチェック機能が追加されました。これにより、Java、.NETではnull、C言語ではNULLを指定したときに自動的に空文字列（""）に変換します。

                                                  Nullチェック機能は、デフォルトでは「false」に設定されているため、nullまたはNULLがあった場合でも、空文字列に変換されません。そのため、「-4971」エラーが発生します。

                                                  Nullチェック機能を有効にするには、基本設定ファイルを変更する必要があります。変更する場合は、弊社サポートセンターまでお問い合わせください。

                                                • お問い合わせをいただいた部分以外を変更すると、SVFの動作が変わってしまう場合があります。そのような場合は、サポート対象外となる可能性もありますので、ご了承ください。
