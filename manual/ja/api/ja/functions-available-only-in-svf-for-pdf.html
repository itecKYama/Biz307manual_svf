                                                3.5. PDF機種のみで使用できる関数

                                                PDF機種で使用できるAPI関数は、PDFファイル作成方法の指定、およびPDF生成時にのみ使用可能な関数です。

                                                関数名

                                                機能

                                                VrSetSpoolFileStream

                                                ファイル生成時に、ディスク上のファイルにではなくメモリに出力します。

                                                VrComout("/{SECU n}/")

                                                PDFのセキュリティ機能の有無を指定します。

                                                VrComout("/{PSWD Password}/")

                                                PDFファイルオープン時のパスワードを指定します。

                                                VrComout("/{SECUPSWD Password}/")

                                                PDFのセキュリティパスワードを指定します。

                                                VrComout("/{PERM n}/")

                                                禁止項目を指定します。

                                                VrComout("/{PRESET プリセット名=n ...}/")

                                                PDFに印刷プリセットを付与します。

                                                VrComout("/{SPJL PDF variable=value}/")

                                                PJLのSETコマンドを出力します。

                                                VrComout("/{SPJL PDF command variable=value}/")

                                                PJLの任意コマンドを出力します。

                                                VrComout("/{SFNG n}/")

                                                検索フィールドが設計されているXML様式ファイルを使用した出力において、検索フィールドとして設計されていないアイテムに検索フィールドを付加します。

                                                VrComout("/{SFVC n}/")

                                                検索フィールドが設計されていないXML様式ファイルを使用した出力において、アイテムに検索フィールドを付加します。

                                                VrComout("/{SFSD n}/")

                                                検索フィールドとして設計されていないアイテムに検索フィールドを付加する際の、検索フィールド名の設定方法を指定します。

                                                VrComout("/{SFXN name}/")

                                                アイテムに検索フィールドを付加する際の検索フィールド名を「固定名+連番」とした場合の固定名を指定します。

                                                VrSetSpoolFileStream

                                                機能

                                                ファイル生成時に、ディスク上のファイルにではなくメモリに出力します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetSpoolFileStream(OutputStream os);

                                                • ASP/VB

                                                  使用できません。

                                                • C

                                                  使用できません。

                                                • VB.NET

                                                  Function instance.VrSetSpoolFileStream(ms As MemoryStream) As Integer

                                                引数

                                                • os

                                                  出力先ストリームオブジェクト

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                VrSetSpoolFileName2関数で出力先PDFファイル名を指定する代わりに、この関数を使用すると、出力ファイルを物理ファイルとして生成するのではなく、メモリ上にStream出力できます。

                                                この機能を使用することで、ServletなどからクライアントにPDFファイルをURLから戻す際に、URLからのPDFファイルの実参照を防ぐことが可能です。

                                                VrQuit関数実行時に戻り値としてStream出力を行ったPDFのサイズが返されます。

                                                参考

                                                • Java、.NETのStream機能を使用しているため、SVF Connect for ASP/COM APIを使用している場合には、本関数を使用することはできません。

                                                • 本関数を実行する際には、J2EEのAPIであるsetContentType関数、およびsetContentLength関数を使用し、コンテンツの形式と長さを設定する必要があります。これらの関数を使用していない場合は、PDFをWebブラウザーに表示できないことがあるので、必ず使用してください。設定例は、次の関数使用順を参照してください。

                                                関数使用順

                                                public void doPost(HttpServletRequest req, HttpServletResponse res) {
        res.setContentType("application/pdf");
        OutputStream os = res.getOutputStream();
        Vrw32 svf = new Vrw32();
 
        int ret;
        svf.VrInit();
        svf.VrSetPrinter("", "PDF");
        svf.VrSetSpoolFileStream(os);
        svf.VrSetForm("sample.xml", 5);
        svf.VrsOut("Field", "Data");
        svf.VrEndRecord();
        svf.VrPrint();
        ret = svf.VrQuit();
        res.setContentLength(ret);
        os.close();
}

                                                VrComout("/{SECU n}/")

                                                機能

                                                PDFのセキュリティ機能の有無を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{SECU n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{SECU n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{SECU n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{SECU n}/") As Integer

                                                引数

                                                • n

                                                  モードを指定します（0～5）。

                                                  値

                                                  説明

                                                  0

                                                  プリンター設定［セキュリティ］の設定内容を参照します。

                                                  1

                                                  40bit RC4暗号化を行う（Acrobat 3.x,4.x）

                                                  2

                                                  128bit RC4暗号化を行う（Acrobat 5.x）

                                                  3

                                                  128bit RC4暗号化を行う（Acrobat 6.x）

                                                  4

                                                  128bit AES暗号化を行う（Acrobat 7.x）

                                                  5

                                                  256bit AES暗号化を行う（Acrobat 9.x）

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                作成するPDFファイルに対してセキュリティ機能を使用する場合に使用します。この関数が指定されていない場合は、SVF環境設定の指定に従います。

                                                セキュリティ機能の詳細は、『SVF帳票出力製品管理ガイド』を参照してください。

                                                使用例

                                                セキュリティ機能を使用します。

                                                • Java/C#

                                                  svf.VrComout("/{SECU 1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{SECU 1}/")

                                                • C

                                                  VrComout(svf, "/{SECU 1}/");

                                                • VB.NET

                                                  svf.VrComout("/{SECU 1}/")

                                                参考

                                                VrComout("/{SECU n}/")関数で暗号化を指定した場合、必ずVrComout("/{PERM n}/")関数で権限を設定する必要があります。

                                                VrComout("/{PSWD Password}/")

                                                機能

                                                PDFファイルを開くときのパスワードを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{PSWD password}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{PSWD password}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{PSWD password}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{PSWD password}/") As Integer

                                                引数

                                                • password

                                                  ユーザーパスワード

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                PDFファイルを開くときにパスワード入力を求めるダイアログが表示されます。この指定により、PDFファイルの閲覧を許可する/しないなどの制限（セキュリティ）をかけることができます。

                                                パスワードには、32バイトまでの半角文字列を使用してください。2バイト文字などはAcrobat/Adobe Readerの仕様上、使用できません。

                                                参考

                                                • セキュリティパスワードと併用する場合には、必ず異なる文字列を指定してください。同じ文字列が指定された場合は、セキュリティパスワードは設定されません。

                                                • セキュリティ上の観点から、PDF作成時にはVrComout("/{PSWD Password}/")関数でオープン時のパスワードを設定することを推奨します。

                                                使用例

                                                PDFオープン時のパスワードとして「userlock」と指定します。

                                                • Java/C#

                                                  svf.VrComout("/{PSWD userlock}/");

                                                • ASP/VB

                                                  svf.VrComout("/{PSWD userlock}/")

                                                • C

                                                  VrComout(svf, "/{PSWD userlock}/");

                                                • VB.NET

                                                  svf.VrComout("/{PSWD userlock}/")

                                                VrComout("/{SECUPSWD Password}/")

                                                機能

                                                PDFのセキュリティパスワードを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{SECUPSWD password}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{SECUPSWD password}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{SECUPSWD password}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{SECUPSWD password}/") As Integer

                                                引数

                                                • password

                                                  セキュリティパスワード

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                Acrobat/Adobe Reader使用時に設定できる各種セキュリティを変更するためのパスワードを設定します。この指定により、PDFのセキュリティ変更保護を行うことが可能です。

                                                パスワードには、32バイトまでの半角文字列を使用してください。2バイト文字などはAcrobat/Adobe Readerの仕様上、使用できません。

                                                参考

                                                • PDFファイルを開くときのパスワードと併用する場合は、必ず異なるパスワードを指定してください。同じ文字列を指定すると、セキュリティパスワードは設定されません。

                                                • セキュリティ上の観点から、PDF作成時にはVrComout("/{SECUPSWD Password}/")関数でセキュリティパスワードを設定することを推奨します。

                                                使用例

                                                PDFセキュリティ変更のためのパスワードとして「seculock」と指定します。

                                                • Java/C#

                                                  svf.VrComout("/{SECUPSWD seculock}/");

                                                • ASP/VB

                                                  svf.VrComout("/{SECUPSWD seculock}/")

                                                • C

                                                  VrComout(svf, "/{SECUPSWD seculock}/");

                                                • VB.NET

                                                  svf.VrComout("/{SECUPSWD seculock}/")

                                                VrComout("/{PERM n}/")

                                                機能

                                                禁止項目を指定します。指定できる項目は次のとおりです。

                                                • 印刷

                                                • 文書の変更

                                                • テキストとグラフィックス選択

                                                • 注釈とフォームフィールドの追加

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{PERM n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{PERM n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{PERM n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{PERM n}/") As Integer

                                                引数

                                                引数の値はSVF環境設定のPDF暗号化計算機で計算します。

                                                ［オプション］メニューから［PDF暗号化計算機］を選択し、［PDF Permission Calculator］ダイアログで［暗号化レベル］を指定します。指定する［暗号化レベル］によって、設定できるセキュリティ項目が異なります。

                                                暗号化レベル

                                                設定できるセキュリティ項目

                                                40bit RC4(Acrobat 3.x,4.x)

                                                • 印刷を許可しない

                                                • 文書の変更を許可しない

                                                • 内容のコピーを許可しない、アクセシビリティを無効にする

                                                • 注釈とフォームフィールドの追加や変更を許可しない

                                                128bit RC4 or AES, 256bit AES(Acrobat 5,6,7,9 or later)

                                                • 印刷を許可

                                                  • 許可しない

                                                  • 低解像度(150dpi)

                                                  • 高解像度

                                                • 変更を許可

                                                  • 許可しない

                                                  • ページの挿入、削除、回転

                                                  • フォームフィールドの入力と署名

                                                  • 注釈作成、フォームフィールドの入力と署名

                                                  • ページの抽出を除くすべての操作

                                                • テキスト、画像、およびその他の内容のコピーを有効にする

                                                • スクリーンリーダーデバイスのテキストアクセスを有効にする

                                                運用に合わせて、各セキュリティ項目のチェックをオンにしたり、ドロップダウンリストから選択したりします。設定内容に応じた値が［現在のパーミッション値］に表示されるので、その値を引数とします。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                PDFファイル生成時にセキュリティの禁止項目を指定します。禁止項目の設定は、項目の組み合わせにより該当するパラメーターを指定することで可能となります。なお、本APIで禁止項目を設定してもセキュリティパスワードを指定しないと禁止項目の指定は有効になりません。必ずセキュリティパスワードを指定してください。

                                                参考

                                                • SVF環境設定とVrComout関数の両方で禁止項目を設定した場合は、VrComout関数による設定が有効です。

                                                • PDFを暗号化する場合、必ずVrComout("/{PERM n}/")関数で権限を設定する必要があります。

                                                使用例

                                                作成するPDFに40bit RC4暗号化の「印刷禁止」を指定します。

                                                • Java/C#

                                                  svf.VrComout("/{PERM -8}/");

                                                • ASP/VB

                                                  svf.VrComout("/{PERM -8}/")

                                                • C

                                                  VrComout(svf, "/{PERM -8}/");

                                                • VB.NET

                                                  svf.VrComout("/{PERM -8}/")

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetSpoolFileName2("sample.pdf");
svf.VrSetForm("sample.xml", 5);
svf.VrComout("/{SECU 1}/");     // （1）暗号化レベルを40bit RC4に設定
svf.VrComout("/{PERM -64}/");   // （2）禁止項目の指定
svf.VrComout("/{PSWD userlock}/");      // （3）ユーザーパスワードの指定
svf.VrComout("/{SECUPSWD seculock}/");  // （4）セキュリティパスワードの指定
svf.VrsOut("F1", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                VrComout("/{PRESET プリセット名=n ...}/")

                                                機能

                                                PDFに印刷プリセットを付与します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{PRESET プリセット名=n プリセット名=n ...}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{PRESET プリセット名=n プリセット名=n ...}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{PRESET プリセット名=n プリセット名=n ...}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{PRESET プリセット名=n プリセット名=n ...}/") As Integer

                                                引数

                                                プリセット名を指定します。

                                                プリセット名

                                                説明

                                                Scaling

                                                ページの拡大/縮小

                                                • 0

                                                  「デフォルト」を指定*1

                                                • 1

                                                  「なし」を指定

                                                Duplex

                                                両面印刷モード

                                                • 0

                                                  「片面」を指定

                                                • 1

                                                  「両面（上下に開く）」を指定

                                                • 2

                                                  「両面（左右に開く）」を指定

                                                • -2

                                                  XML様式ファイルの両面印刷モード設定に従い指定

                                                  参考

                                                  両面印刷モードによる綴じ方向はAcrobatの仕様に依存します。

                                                PickTrayByPDFSize

                                                ページサイズに合わせて用紙を選択

                                                • 0

                                                  無効にする

                                                • 1

                                                  有効にする

                                                PrintRange

                                                ページ指定*2

                                                ページ番号（数値）を指定する。半角カンマ区切り、または半角ハイフン「-」で数値を指定

                                                • 設定例

                                                  1,2,4-10,15

                                                  （上記設定例の印刷範囲は、1、2、4、5、6、7、8、9、10、15ページです）

                                                NumCopies

                                                部数*3

                                                部数（数値）を指定します。

                                                • 設定例

                                                  • 5（5部を指定）

                                                  • 指定なし（「デフォルト」を指定）

                                                  • -2（XML様式ファイルの部数を指定）*3

                                                1. ［Scaling］に「デフォルト」を指定した場合、印刷ダイアログの［ページの拡大/縮小］で選択される値は、使用するビューアーによって異なります。

                                                2. ［PrintRange］に半角ハイフンと半角数字以外の値が指定された場合、［PrintRange］の指定は無効です。また、数字の後にスペースを指定した場合、スペース以降の数字は有効になりません。

                                                3. ［NumCopies］に半角数字以外の値が指定された場合、VrComout関数が無効となります。また、Adobe Acrobat/Readerを使用する場合、Adobe Acrobat/Readerの仕様により、2～5の範囲だけが有効となります。6以上の数値はデフォルト扱いになります。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                PDF文書に対して、印刷プリセット情報を付与します。Adobe Readerを使用する場合、Ver. 8.0以降で使用可能な機能です。

                                                使用例

                                                両面印刷を左綴じに、部数を5部に設定します。

                                                • Java/C#

                                                  svf.VrComout("/{PRESET Duplex=2 NumCopies=5}/");

                                                • ASP/VB

                                                  svf.VrComout("/{PRESET Duplex=2 NumCopies=5}/")

                                                • C

                                                  VrComout(svf, "/{PRESET Duplex=2 NumCopies=5}/");

                                                • VB.NET

                                                  svf.VrComout("/{PRESET Duplex=2 NumCopies=5}/")

                                                関数使用順

                                                svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetSpoolFileName2("sample.pdf");
svf.VrSetForm("sample.xml", 5);
svf.VrComout("/{PRESET Duplex=2 NumCopies=5}/");

        :

svf.VrQuit();
