                                                3.9. SVFコネクト製品使用時のみの関数

                                                SVFコネクト製品（Universal Connect/X、SVF Connect for Java API、SVF Connect for ASP/COM API、SVF Connect for .NET Framework API）のみで使用できるAPI関数は、次のとおりです。使用できるコネクト製品には「○」を記しています。

                                                関数名

                                                使用できるコネクト製品

                                                機能

                                                UCX（*1）

                                                Java（*2）

                                                ASP（*3）

                                                .NET（*4）

                                                VrComout("/{CSMD n}/")

                                                ○

                                                ○

                                                ○

                                                ○

                                                PDFファイル、およびCSVファイルの出力時に、ファイルの保存先を切り替えます。

                                                VrLocalPrint

                                                ○

                                                ○

                                                ○

                                                クライアントコンピューター上に登録されたプリンター機器へ出力する場合に、スプールファイルをスプーラーに転送します。

                                                VrDataOut

                                                ○

                                                DataSet内のテーブルデータを一括で出力します。

                                                close

                                                ○

                                                ○

                                                ○

                                                SVFとの接続を切断します。

                                                *1 Universal Connect/Xです。

                                                *2 SVF Connect for Java APIです。

                                                *3 SVF Connect for ASP/COM APIです。

                                                *4 SVF Connect for .NET Framework APIです。

                                                VrComout("/{CSMD n}/")

                                                機能

                                                PDFファイル、およびCSVファイルの出力時、ファイルの保存先を次の2つのいずれかに切り替えます。

                                                • サーバー（SVF製品がインストールされたサーバー）

                                                • クライアント（アプリケーションが動作しているコンピューター）

                                                書式

                                                各言語による書式は次のとおりです。

                                                • Java/C#

                                                  int instance.VrComout("/{CSMD n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{CSMD n}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{CSMD n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{CSMD n}/") As Integer

                                                引数

                                                • n

                                                  保存先の指定（0、1）

                                                  • 0

                                                    クライアント

                                                  • 1

                                                    サーバー

                                                戻り値

                                                • 0

                                                  固定

                                                説明

                                                PDFファイル、CSVファイルの保存先コンピューターを指定します。この関数を発行しない場合は、デフォルトでクライアントコンピューターに保存されます。

                                                各コンピューター上でファイルが保存されるパスは、PDFファイルの場合は「VrSetSpoolFileName2」、CSVファイルの場合は 「VrSetCSVFileName」を使用して指定します。

                                                使用例

                                                サーバーにファイルを保存します。

                                                • Java/C#

                                                  svf.VrComout("/{CSMD 1}/");

                                                • ASP/VB

                                                  svf.VrComout("/{CSMD 1}/")

                                                • C

                                                  VrComout(svf, "/{CSMD 1}/");

                                                • VB.NET

                                                  svf.VrComout("/{CSMD 1}/")

                                                関数使用順

                                                svf.VrInit();
svf.VrComout("/{CSMD 1}/");    // VrInit()の直後に呼び出す
svf.VrSetPrinter("", "PDF");   // これ以降は「第2章　基本的なプログラムの流れ」を参照してください
svf.VrSetSpoolFileName2("sample.pdf");
svf.VrSetForm("sample.xml", 4);
svf.VrsOut("F1", "data");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();

                                                VrLocalPrint

                                                機能

                                                クライアントコンピューター上に登録されたプリンター機器へ出力する場合に、スプールファイルをスプーラーに転送します。

                                                書式

                                                各言語による書式は次のとおりです。

                                                • Java/C#

                                                  int instance.VrLocalPrint(String spoolerType, String spoolFile);

                                                • ASP/VB

                                                  Function instance.VrLocalPrint(spoolerType As String, spoolFile As String) As Long

                                                • C

                                                  int VrLocalPrint(HSVFRCLIENT instance, char *spoolerType, char *spoolFile);

                                                • VB.NET

                                                  Function instance.VrLocalPrint(spoolerType As String, spoolFile As String) As Integer

                                                引数

                                                • spoolerType

                                                  スプーラーの設定名

                                                • spoolFile

                                                  スプールファイル名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                クライアントコンピューター上に登録されたプリンター機器へ出力する場合に、クライアントコンピューターとプリンター機器の間に位置するスプーラーに対してスプールファイルを転送します。

                                                スプールファイルの作成にはVrSetSpoolFileName2関数を使用します。

                                                使用例

                                                スプールファイル「sample.spl」を「Spooler1」設定でスプーラーに転送します。

                                                • Java/C#

                                                  svf.VrLocalPrint("Spooler1", "sample.spl");

                                                • ASP/VB

                                                  svf.VrLocalPrint("Spooler1", "sample.spl")

                                                • C

                                                  VrLocalPrint(svf, "Spooler1", "sample.spl");

                                                • VB.NET

                                                  svf.VrLocalPrint("Spooler1", "sample.spl")

                                                VrDataOut

                                                機能

                                                DataSet内のテーブルデータを一括で出力します。

                                                書式

                                                各言語による書式は次のとおりです。

                                                • C#

                                                  int instance.VrDataOut(System.Data.DataTable source);
int instance.VrDataOut(System.Data.DataView source);

                                                • VB.NET

                                                  Function instance.VrDataOut(source As System.Data.DataTable) As Integer
Function instance.VrDataOut(source As System.Data.DataView) As Integer

                                                引数

                                                • source

                                                  テーブル

                                                戻り値

                                                • 0

                                                  正常終了

                                                • -544

                                                  データ（行）が1行もありませんでした。

                                                • -555

                                                  印刷フィールド名と一致するデータ（列）名が存在しませんでした。

                                                • -4971

                                                  処理中に例外が発生しました。

                                                説明

                                                • 一回の帳票フォーム処理中に引き渡せるテーブル数は1つです。

                                                • DataSetのテーブルのカラム名と、XML様式ファイル内のフィールド名が一致している必要があります。

                                                使用例

                                                • C#

                                                  DataTable table = new DataTable();
:
svf.VrDataOut(table);
                                                  DataView view = new DataView();
:
svf.VrDataOut(view);

                                                • VB.NET

                                                  Dim table As New DataTable
:
svf.VrDataOut(table)
                                                  Dim view As New DataView
:
svf.VrDataOut(view);

                                                close

                                                機能

                                                SVFとの接続を切断します。

                                                書式

                                                • Java/C#

                                                  void instance.close();

                                                • ASP/VB

                                                  Sub instance.close()

                                                • C

                                                  void close(HSVFRCLIENT instance);

                                                • VB.NET

                                                  Sub instance.close()

                                                引数

                                                なし

                                                説明

                                                処理終了後は、close関数を呼び出して、SVFとの接続を切断してください。

                                                注意

                                                • SVFコネクト製品から実行する場合、close関数は必須です。

                                                • SVFコネクト製品ではインスタンスの再利用はできません。

                                                使用例

                                                • Java/C#

                                                  svf.close();

                                                • ASP/VB

                                                  svf.close()

                                                • C

                                                  close(svf);

                                                • VB.NET

                                                  svf.close()
