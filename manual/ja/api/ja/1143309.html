                                                3.7.3. 出力方式に関係なく使用できるAPI

                                                関数名

                                                機能

                                                VrComout("/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/")

                                                シート保護や書き込みパスワードを設定します。

                                                VrComout("/{XSPA 印刷範囲}/")

                                                ワークシートの印刷範囲を設定します。

                                                VrComout("/{XSRT <NO=n1またはNAME=n2> RANGE=n3}/")

                                                印刷タイトルを指定します。Ver. 10.1以降で対応しています。

                                                VrComout("/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/")

                                                機能

                                                シート保護や書き込みパスワードを設定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSSE WRITEPROTECTPWD=n1 WRITEPROTECTUSER=n2 PROTECTSHEETPWD=n3}/") As Integer

                                                引数

                                                • WRITEPROTECTPWD

                                                  Excelファイルを編集する際のパスワード（書き込みパスワード）を指定します。パラメーターは省略可能です。

                                                  • n1

                                                    パスワードを15バイトまでの半角文字列で指定します。

                                                    書き込みパスワードを設定すると、Excelファイルの上書き保存をするためにパスワードが必要になります。

                                                • WRITEPROTECTUSER

                                                  書き込みユーザー名を指定します。パラメーターは省略可能です。

                                                  • n2

                                                    書き込みユーザー名を109バイトまでの半角文字列で指定します。

                                                    書き込みユーザー名は書き込みパスワードが設定されたExcelファイルを開く際のパスワード画面上に表示されるユーザー名です。指定が省略された場合は、システムログインユーザー名が設定されます。

                                                • PROTECTSHEETPWD

                                                  パスワード付きでワークシートを保護します。パラメーターは省略可能です。

                                                  • n3

                                                    パスワードを255バイトまでの半角文字列で指定します。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                Excelファイルに書き込みパスワードを設定します。また、パスワード付きでワークシートの保護を設定します。

                                                注意事項

                                                • 書き込みパスワードの指定は、XLS形式のファイルの場合のみ有効です。XLSX形式には対応していません。

                                                • 読み取りパスワードには対応していません。

                                                • 書き込みパスワードを設定した場合、Excelファイルの「読み取り専用を推奨する」がオンに設定されます。

                                                • パスワードに指定できる文字は、空白文字を除く半角英数字記号の範囲（0x21 - 0x7E）です。

                                                使用例

                                                Excelファイルにユーザー名「test」、書き込みパスワード「1234」を設定し、ワークシートにパスワード「1234」で保護をかけます。

                                                • Java/C#

                                                  svf.VrComout("/{XSSE WRITEPROTECTPWD=1234 WRITEPROTECTUSER=test PROTECTSHEETPWD=1234}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSSE WRITEPROTECTPWD=1234 WRITEPROTECTUSER=test PROTECTSHEETPWD=1234}/")

                                                • C

                                                  VrComout(svf, "/{XSSE WRITEPROTECTPWD=1234 WRITEPROTECTUSER=test PROTECTSHEETPWD=1234}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSSE WRITEPROTECTPWD=1234 WRITEPROTECTUSER=test PROTECTSHEETPWD=1234}/")

                                                VrComout("/{XSPA 印刷範囲}/")

                                                機能

                                                ワークシートの印刷範囲を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSPA 印刷範囲}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSPA 印刷範囲}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSPA 印刷範囲}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSPA 印刷範囲}/") As Integer

                                                引数

                                                • 印刷範囲

                                                  ワークシートの印刷範囲を次の書式で指定します。

                                                  印刷範囲の左上セル（グリッド）:印刷範囲の右下セル（グリッド）

                                                  テンプレート出力方式の場合は出力対象ワークシート（テンプレート）上の行/列番号で、直接出力方式の場合は様式ファイルのグリッドの行/列番号で指定します。列番号はアルファベット表記で指定します。

                                                  たとえば、シート（様式ファイル）の1列目の1行目から2列目2行目までを印刷範囲とする場合は「A1:B2」のように指定します。

                                                  また、次のような指定もできます。

                                                  • 出力ページの最終行となる行番号までを印刷範囲として指定したい場合は、「A1:B0」のように右下セルの行番号に0を指定します。たとえば、出力ページの最終行がB52の場合、Excelファイルの印刷範囲には「B1:G52」が設定されます。

                                                  • 複数の印刷範囲を指定する場合は、「A1:B2,A3:B10」のように印刷範囲をカンマ（,）で区切ります。

                                                    注意

                                                    印刷範囲の複数指定は、Excelブック形式のみ有効になります。Excel97-2003形式では使用しないでください。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                APIの有効範囲は文書全体です。 様式ファイルごとに印刷範囲を変更する場合は、様式ファイルの切り替えごとにAPIを指定してください。

                                                使用例

                                                ワークシートの印刷範囲を「A1:AK58」とします。

                                                • Java/C#

                                                  svf.VrComout("/{XSPA A1:AK58}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSPA A1:AK58}/")

                                                • C

                                                  VrComout(svf, "/{XSPA A1:AK58}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSPA A1:AK58}/")

                                                VrComout("/{XSRT <NO=n1またはNAME=n2> RANGE=n3}/")

                                                機能

                                                印刷タイトルを設定します。Ver.10.1以降で対応しています。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSRT <NO=n1> RANGE=n3}/");
int instance.VrComout("/{XSRT <NAME=n2> RANGE=n3}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSRT <NO=n1> RANGE=n3}/") As Long
Function instance.VrComout("/{XSRT <NAME=n2> RANGE=n3}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSRT <NO=n1> RANGE=n3}/");
int VrComout(HSVFRCLIENT instance, "/{XSRT <NAME=n2> RANGE=n3}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSRT <NO=n1> RANGE=n3}/") As Integer
Function instance.VrComout("/{XSRT <NAME=n2> RANGE=n3}/") As Integer

                                                引数

                                                • NO

                                                  印刷タイトルを設定するワークシートを、先頭のワークシートを「1」としたワークシート番号で指定します。テンプレート出力方式ではデータの出力対象のワークシートを指定し、直接出力方式ではページ出力時に生成されるワークシートを指定します。省略可能です。NOとNAMEの両方を省略した場合、文書全体に印刷タイトルが設定されます。

                                                  • n1

                                                    ワークシート番号

                                                • NAME

                                                  印刷タイトルを設定するワークシートを、ワークシート名で指定します。テンプレート出力方式ではデータの出力対象のワークシートを指定し、直接出力方式ではページ出力時に生成されるワークシートを指定します。省略可能です。NOとNAMEの両方を省略した場合、文書全体に印刷タイトルが設定されます。

                                                  テンプレート出力方式でワークシートの自動作成を行っている場合や、直接出力方式でページごとにシートを生成している場合は、自動で生成されたワークシート名を指定する必要があります。生成されるシート名については、『オプション機種管理ガイド』を参照してください。

                                                  • n2

                                                    ワークシート名

                                                    たとえば、直接出力方式でデフォルトワークシート名を設定せずに、2枚目のワークシートを指定する場合は、「Sheet2」と指定します。

                                                • RANGE

                                                  印刷タイトルとする行、列、または、行と列を指定します。

                                                  行または列の指定は、テンプレート出力方式の場合は出力対象ワークシート（テンプレート）上の行/列番号で、直接出力方式の場合は様式ファイルのグリッドの行/列番号で指定します。列番号はアルファベット表記で指定します。

                                                  行の場合、次の書式で指定します。

                                                  行番号:行番号

                                                  たとえば、1行目を印刷タイトルとする場合は「1:1」、1行目と2行目の場合は「1:2」と指定します。

                                                  列の場合、次の書式で指定します。

                                                  列番号:列番号

                                                  たとえば、1列目を印刷タイトルとする場合は「A:A」、1列目と2列目の場合は「A:B」と指定します。

                                                  行と列を指定する場合、対象の行と列が交わる（重なる）領域を次の書式で指定します。

                                                  行と列が重なる領域の左上セル（グリッド）:行と列が重なる領域の右下セル（グリッド）

                                                  たとえば、2行目と3行目および、3列目から7列目を印刷タイトルとしたい場合、「C2:H3」と指定します。

                                                  • n3

                                                    印刷タイトルとする行、列、または行と列

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                • 印刷タイトルを設定します。

                                                • APIの有効範囲は文書全体（出力されるExcelファイルの全ワークシート）です。NOまたはNAMEを指定することで、有効範囲をワークシート単位とすることができます。

                                                  ワークシートごとにRANGEの値を変えたい場合や、文書の中に印刷タイトルが不要なワークシートがある場合は、NOまたはNAMEを指定してAPIを発行します。この場合、印刷タイトルを設定するワークシートの枚数分、APIを発行します。

                                                • 直接出力方式で、様式ファイルにサブフォームとレコードが設計されており、自動改ページ機能を利用して自動的にワークシートを作成する設定を行っている場合、アプリケーションプログラム作成時に出力されることが確定していないワークシートをNOまたはNAMEに指定することはできません。

                                                • 本APIはすべてのデータが出力されてから実行されるため、呼び出すタイミングの指定はありません。

                                                使用例

                                                ワークシート「Sheet2」の2行目と3行目を印刷タイトルとします。

                                                • Java/C#

                                                  svf.VrComout("/{XSRT NAME=Sheet2 RANGE=2:3}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSRT NAME=Sheet2 RANGE=2:3}/")

                                                • C

                                                  VrComout(svf, "/{XSRT NAME=Sheet2 RANGE=2:3}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSRT NAME=Sheet2 RANGE=2:3}/")
