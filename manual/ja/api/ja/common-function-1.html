                                                3.1.1. 共通関数（1）

                                                VrInit / VrInitEx

                                                機能

                                                SVFの動作環境を初期化します。

                                                書式

                                                • Java/C#

                                                  int instance.VrInit();
int instance.VrInit(String Encode);

                                                • ASP/VB

                                                  Function instance.VrInit() As Long
Function instance.VrInitEx(Encode As String)As Long

                                                • C

                                                  int VrInit(HSVFRCLIENT instance);
int VrInitEx(HSVFRCLIENT instance, char *Encode);

                                                • VB.NET

                                                  Function instance.VrInit() As Integer
Function instance.VrInit(Encode As String) As Integer

                                                引数

                                                • Encode

                                                  Javaのエンコーディング名を指定します。大文字/小文字は区別されます。

                                                  VrInit関数で指定できるエンコーディング名は、VrSetLocale関数で指定するロケールにより異なります。

                                                  VrSetLocale関数で指定するロケール

                                                  VrInit関数で指定できるエンコーディング名

                                                  ja

                                                  SJIS、MS932、Cp942、Cp942C、Cp943、Cp943C、UTF-16

                                                  en

                                                  Cp1251、Cp1252、Cp1253、Cp1254、Cp1258

                                                  fr_FR

                                                  Cp1252

                                                  cs_CZ

                                                  Cp1250

                                                  zh_CN

                                                  MS936

                                                  zh_TW

                                                  MS950

                                                  ko

                                                  MS949

                                                  th_TH

                                                  MS874

                                                  。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                印刷処理の実行を開始する際には、必ずVrInit関数を実行します。

                                                引数には、使用する文字コード（体系）を指定することが可能です。

                                                文字コードを特に指定する必要がない場合は、引数には何も指定しないでください。指定がない場合は、OS上のEncodeを元にデータを処理します。

                                                使用例

                                                • Java/C#

                                                  svf.VrInit();
svf.VrInit("MS932");

                                                • ASP/VB

                                                  svf.VrInit()
svf.VrInitEx("Cp943C")

                                                • C

                                                  VrInit(svf);
VrInitEx(svf,"SJIS");

                                                • VB.NET

                                                  svf.VrInit()
svf.VrInit("MS932")

                                                VrInit / VrInitEx関数で引数指定するエンコーディング名についての注意事項

                                                • Java言語のエンコーディング名「SJIS」は、IBM拡張文字などの特殊文字には対応していません。

                                                  特殊文字の領域は、次のとおりです。これらの特殊文字を使用したい場合、「MS932」や「Cp943C」などを使用してください。

                                                  • NEC選定IBM拡張文字（ED40-EFFC）

                                                  • 外字（F040-F9FC）

                                                  • IBM拡張文字（FA40-FC4B）

                                                • UTF-16は使用可能なプリンター機種やフォントに制限があり、設定を変更する必要がありますので弊社までご相談ください。

                                                • 各エンコーディング名で対応している文字コードについては、Java言語の仕様などで公開されています。ホームページなどで確認してください。

                                                VrQuit

                                                機能

                                                印刷処理を完了し、使用していたリソースを解放します。

                                                書式

                                                • Java/C#

                                                  int instance.VrQuit();

                                                • ASP/VB

                                                  Function instance.VrQuit() As Long

                                                • C

                                                  int VrQuit(HSVFRCLIENT instance);

                                                • VB.NET

                                                  Function instance.VrQuit() As Integer

                                                引数

                                                なし

                                                戻り値

                                                • ファイル出力時

                                                  • 正数

                                                    処理完了（VrSetPrinter関数の第2引数「Printer」で、1つ目に指定したプリンターが出力したファイルサイズ（バイト数））

                                                  • 0

                                                    処理完了（出力すべきデータがなかった）

                                                  • 負数

                                                    エラーコード

                                                • 印刷時

                                                  • 0

                                                    処理完了

                                                  • 負数

                                                    エラーコード

                                                    エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                印刷処理の正常/異常にかかわらず、印刷処理を完了するときには必ずVrQuit関数を実行します。

                                                参考

                                                • 他のSVF関数の戻り値が負数だった場合、VrQuit関数を発行することでジョブを終了するための処理を行います。ただし、アクセス違反などJavaのExceptionが発生した場合、その時点で強制終了されることがあるため、エラーハンドリングができないことがあります。その場合、スレッド、またはプロセスが残ってしまうことがあります。

                                                • Java Connect、SVF Connect for Java API、ASP/COM Connect、SVF Connect for ASP/COM APIのいずれかを使用する場合は、必ず実行しているプログラムの最後でセッションを切断してください。セッションが残り、増えつづけることがあると、使用しているWebアプリケーションサーバー側で予期せぬエラーが発生することがあります。

                                                使用例

                                                • Java/C#

                                                  svf.VrQuit();

                                                • ASP/VB

                                                  svf.VrQuit()

                                                • C

                                                  VrQuit(svf);

                                                • VB.NET

                                                  svf.VrQuit()

                                                VrSetLocale

                                                機能

                                                SVF既定のロケール（地域情報）を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetLocale(String Locale);

                                                • ASP/VB

                                                  Function instance.VrSetLocale(Locale As String) As Long

                                                • C

                                                  int VrSetLocale(HSVFRCLIENT instance, char *Locale);

                                                • VB.NET

                                                  Function instance.VrSetLocale(Locale As String) As Integer

                                                引数

                                                • Locale

                                                  次のロケールのいずれかを選択します。大文字/小文字は区別されます。

                                                  • ja

                                                  • cs_CZ

                                                  • en

                                                  • fr_FR

                                                  • ko

                                                  • zh_CN

                                                  • zh_TW

                                                  • th_TH

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                SVF規定のロケールを明示的に指定します。VrInit関数より前にVrSetLocale関数を発行し、SVFが動作する上での言語と地域情報を指定します。VrSetLocale関数を呼び出さない場合は、OSのロケールを自動的に使用します。

                                                参考

                                                印刷の実行時にデバッグログが出力されなかったり、VrSetPrinter関数でエラーコード「-32」が発生したりする場合などは、システムが取得するロケールと不整合が発生している可能性があります。プロパティファイルが正常に読み込めていない場合、VrSetLocale関数で明示的にロケールを指定する必要があります。

                                                使用例

                                                • Java/C#

                                                  svf.VrSetLocale("ja");

                                                • ASP/VB

                                                  svf.VrSetLocale("ja")

                                                • C

                                                  VrSetLocale(svf, "ja");

                                                • VB.NET

                                                  svf.VrSetLocale("ja")

                                                VrSetForm

                                                機能

                                                印刷に用いるXML様式ファイルと出力のモードを指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetForm(String FormName, int Mode);

                                                • ASP/VB

                                                  Function instance.VrSetForm(FormName As String, Mode As Integer) As Long

                                                • C

                                                  int VrSetForm(HSVFRCLIENT instance, char *FormName, int Mode);

                                                • VB.NET

                                                  Function instance.VrSetForm(FormName As String, Mode As Integer) As Integer

                                                引数

                                                • FormName

                                                  XML様式ファイル名

                                                • Mode

                                                  出力モード

                                                  • 0

                                                    シーケンシャルモード

                                                  • 1

                                                    ランダムモード

                                                  • 4

                                                    レポートライターモード（ソートなし）

                                                  • 5

                                                    レポートライターモード（ソートあり）

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                SVFで使用する関数のほとんどは、VrSetForm関数で指定されたXML様式ファイルに対して機能します。一度VrSetForm関数でXML様式ファイルを指定すると、次にXML様式ファイルを指定するまで有効です。XML様式ファイルは、基本的にフルパスで指定します。

                                                指定可能な4種類のモードにより、データ出力時の使用関数が変わります。どのモードを使用するかは「基本的なプログラムの流れ」を参照してください。

                                                • 0

                                                  シーケンシャルモード

                                                  フィールド名を指定せず、設計したフィールド位置の順（左上から右下）に関数（VrSeqOut）を使用してデータを出力します。扱えるデータは文字列データに限定されます。基本はSVF内部で保有するバッファ順に格納されます。上から順に繰り返し内のフィールドであっても優先されません。

                                                  たとえば、

                                                  4XXX　　3XX
4RRR

                                                  とXML様式ファイルで設計した場合、

                                                  VrSeqOut("0001");
VrSeqOut("002");
VrSeqOut("0003");

                                                  の順に出力すると

                                                  0001　002
0003

                                                  と出力されます。

                                                • 1

                                                  ランダムモード

                                                  フィールド名とそのフィールドに印字するデータを、関数（VrsOut等）を使用して出力します。このモードを使用すると、フィールドの設計位置にかかわらずランダムにデータを出力できます。各XML様式ファイルのフィールド名を統一して作成しておくと、XML様式ファイル名を変更するだけで、1本のプログラムで多数のXML様式ファイルに対応することが可能です。

                                                  扱えるデータは文字列、整数、実数ですが、使用するデータ型により使用するAPIが異なります。

                                                • 4

                                                  レポートライターモード（ソートなし）

                                                  クエリー様式ファイルを実行する場合と、レポートライター機能で作成されているXML様式ファイルを使用する場合に設定します。

                                                • 5

                                                  レポートライターモード（ソートあり）

                                                  クエリー様式ファイルを実行する場合と、レポートライター機能で作成されているXML様式ファイルを使用する場合に設定します。このモードを使用したときには、XML様式ファイル上で指定したフィールドのキー順に従ってSVFが内部的にデータをソートします。

                                                使用例

                                                • XML様式ファイル「sample.xml」を使用して、モード5で出力する場合

                                                  • Java/C#

                                                    svf.VrSetForm("sample.xml", 5);

                                                  • ASP/VB

                                                    svf.VrSetForm("sample.xml", 5)

                                                  • C

                                                    VrSetForm(svf, "sample.xml", 5);

                                                  • VB.NET

                                                    svf.VrSetForm("sample.xml", 5)

                                                • 関数使用例

                                                  一度の印刷処理実行で複数のXML様式ファイルを使用して出力します（Javaでの実行で1つのPDFファイルに複数のXML様式ファイルを使用する）。

                                                  svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetSpoolFileName2("c:\\pdf\\sample.pdf");
svf.VrSetForm("C:\\xml\\sample1.xml", 1); //1つめのXML様式ファイルをランダムモードで指定
svf.VrsOut("name", "Hiroyuki Kobayashi");
svf.VrEndPage(); // （注）
svf.VrSetForm("C:\\xml\\sample2.xml", 1); //2つめのXML様式ファイルをランダムモードで指定
svf.VrsOut("shohin_name", "SVF for Web / PDF JavaEdition");
svf.VrlOut("su", 1);
svf.VrEndPage(); // （注）
svf.VrSetForm("C:\\xml\\sample3.xml", 1); //3つめのXML様式ファイルをランダムモードで指定
svf.VrsOut("end", "data-end");
svf.VrEndPage(); // （注）
svf.VrQuit();

                                                  （注）ランダムモードとシーケンシャルモードの場合には、改ページ時、およびすべてのデータ出力終了時に、この関数を呼び出す必要があります。

                                                VrsOut / VrsOutn

                                                機能

                                                文字型データ、またはイメージファイル名を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrsOut(String Field_Name, String data);
int instance.VrsOutn(String Field_Name, int line, String data);

                                                • ASP/VB

                                                  Function instance.VrsOut(Field_Name As String, data As String) As Long
Function instance.VrsOutn(Field_Name As String, line As Long, data As String) As Long

                                                • C

                                                  int VrsOut(HSVFRCLIENT instance, char *Field_Name, char *data);
int VrsOutn(HSVFRCLIENT instance, char *Field_Name, int line, char *data);

                                                • VB.NET

                                                  Function instance.VrsOut(Field_Name As String, data As String) As Integer
Function instance.VrsOutn(Field_Name As String, line As Integer, data As String) As Integer

                                                引数

                                                • Field_Name

                                                  アイテム名

                                                • line

                                                  繰り返しアイテムの行番号

                                                • data

                                                  文字列型データ、または、イメージファイル名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                文字型データをフィールド、バーコードに渡します。また、イメージアイテムに画像データファイルを渡します。

                                                XML様式ファイル設計時に「繰り返し」機能を使用して作成したフィールドには、VrsOutn関数を使用して、何行目の繰り返しフィールドに対してデータを渡すかを行番号で指定します。繰り返しフィールドの最初のフィールドは、行番号を「1」と指定します。この場合、繰り返し数以上のデータを渡す場合には、XML様式ファイル設計時に用紙のプロパティの［自動改ページ］をオンにすると、SVF内部で自動的にあふれた行を次ページに渡します。

                                                末尾がスペース（半角/全角問わず）のデータを指定すると、スペースが削除されて出力されます。

                                                使用例

                                                • 「会社名」フィールドに「ウイングアーク株式会社」というデータを出力する場合

                                                  • Java/C#

                                                    svf.VrsOut("会社名", "ウイングアーク株式会社");

                                                  • ASP/VB

                                                    svf.VrsOut("会社名", "ウイングアーク株式会社")

                                                  • C

                                                    VrsOut(svf, "会社名", "ウイングアーク株式会社");

                                                  • VB.NET

                                                    svf.VrsOut("会社名", "ウイングアーク株式会社")

                                                • 「品名」繰り返しフィールドの1行目に「SVF for Java Print」というデータを渡す場合

                                                  • Java/C#

                                                    svf.VrsOutn("品名", 1, "SVF for Java Print");

                                                  • ASP/VB

                                                    svf.VrsOutn("品名", 1, "SVF for Java Print")

                                                  • C

                                                    VrsOutn(svf, "品名", 1, "SVF for Java Print");

                                                  • VB.NET

                                                    svf.VrsOutn("品名", 1, "SVF for Java Print")

                                                • 「画像ロゴ」イメージに「WingArc.bmp」を出力する場合

                                                  • Java/C#

                                                    svf.VrsOut("画像ロゴ", "WingArc.bmp");

                                                  • ASP/VB

                                                    svf.VrsOut("画像ロゴ", "WingArc.bmp")

                                                  • C

                                                    VrsOut(svf, "画像ロゴ", "WingArc.bmp");

                                                  • VB.NET

                                                    svf.VrsOut("画像ロゴ", "WingArc.bmp")

                                                参考

                                                SVFでは、出力するプリンター機種により使用可能な画像ファイルの種類が異なります。各プリンター機種で対応している画像ファイルの詳細は、各製品のマニュアルを参照してください。

                                                VrsOut関数でのグローバル変数の設定について

                                                SVF設計部製品で作成するXML様式ファイル内にはグローバル変数を設定できます。グローバル変数は、VrInit関数からVrQuit関数までの間で、有効な文字型データのパラメーター値として定義できる変数です。グローバル変数を定義することで、上位アプリケーションから出力されたデータを、複数のXML様式ファイル間で共通して使用できます。たとえば、自社名や自社住所などを帳票上に印刷するために、XML様式ファイル設計時に固定文字として直接値を定義している場合、自社名が変更になると、固定文字で自社名を出力している帳票は、すべて個別に変更しなければなりません。しかし、固定文字の代わりに、自社名を表すグローバル変数を用いたフィールドを設定しておけば、上位アプリケーション側からグローバル変数に与える変数値を変更するだけで、すべての出力データが変更され、XML様式ファイルの修正は一切行う必要がなくなります。

                                                グローバル変数を使用するには、XML様式ファイルのフィールドに対し、計算式、または編集式、属性式でグローバル変数の定義設定を行う必要があります。

                                                複数の異なるXML様式ファイルを、1つの帳票として印刷する例をあげます。

                                                この帳票において、共通項目となる自社名、自社住所をグローバル変数定義されているフィールドに対しデータを出力する場合、下記のようにデータを出力する例です。

                                                • 自社名："COMPANY"

                                                • 自社住所："ADDRESS"

                                                例 1. 複数の異なる様式ファイルを1つの帳票として印刷する例
                                                svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetForm("FORM1.xml",4);

svf.VrsOut("$COMPANY$", "ウイングアーク"); // グローバル変数に値をセット
svf.VrsOut("$ADDRESS$", "東京都渋谷区丸山"); // グローバル変数に値をセット

svf.VrsOut("KINGAKU", "1000");
svf.VrEndRecord();
svf.VrPrint();

svf.VrSetForm("FORM2.xml", 4); // 別XML様式
//svf.VrsOut("$COMPANY$", "ウイングアーク"); ...上記関数が一度発行されているため不要
//svf.VrsOut("$ADDRESS$", "東京都渋谷区丸山"); ...上記関数が一度発行されているため不要
svf.VrsOut("KUNGAKU", "1000");
svf.VrEndRecord();
svf.VrPrint();

svf.VrSetForm("FORM1.xml", 4); // 別XML様式
//svf.VrsOut("$COMPANY$", "ウイングアーク"); ...上記関数が一度発行されているため不要
//svf.VrsOut("$ADDRESS$", "東京都渋谷区丸山"); ...上記関数が一度発行されているため不要
svf.VrsOut("KUNGAKU", "1000");
svf.VrEndRecord();
svf.VrPrint();
svf.VrQuit();


                                                注意

                                                グローバル変数には、設計時に［データ］と［初期値なし］を設定できます。

                                                VrSetForm関数以前にグローバル変数に値が設定されていた場合は、［初期値なし］の設定によってVrSetForm関数時に設定されるグローバル変数の値が次のように異なります。

                                                • ［初期値なし］をオンにした場合

                                                VrSetQuery関数使用時の注意

                                                • SVFには、ODBCドライバーやJDBCドライバーは含まれていません。

                                                • JDBCドライバーを使用する場合は、Javaの環境変数（CLASSPATH指定）、または起動オプション（-cp）を設定し、そのドライバーをロードできるようにする必要があります。設定方法はWebアプリケーションサーバーにより異なります。使用するWebアプリケーションサーバーのマニュアルを参照してください。

                                                • SVFX-Designer Ver.1.0以降で作成したクエリー様式ファイルを使用する場合

                                                  • クエリー様式ファイル作成時にJDBCドライバーを使用した接続設定が可能です。通常はそのJDBC接続情報が保存されたクエリー様式ファイルを使用して、使用例にある方法で接続できます。なお、出力実行時に、クエリー様式ファイル内に設定された接続情報と異なる接続方法にする場合は、$KINDパラメーターで接続方法を変更します。次の「補足説明」を参照してください。

                                                • 補足説明

                                                  • Oracle使用時にSIDを使用し、Thin接続を行う方法

                                                    VrSetQuery関数の呼び出しを、次のように変更します。

                                                    svf.VrSetQuery("$KIND=ORCL.THIN;DBQ=xxx;UID=xxx;PWD=xxx;SID=xxx", "xxx.vrq", 0);

                                                    各パラメーターは次のとおりです。

                                                    • $KIND

                                                      ORACLEDBへの接続情報を指定します。

                                                    • DBQ

                                                      DBサーバーのホスト名またはIPアドレスを指定します。

                                                    • UID

                                                      ユーザーIDを指定します。

                                                    • PWD

                                                      パスワードを指定します。

                                                    • SID

                                                      コネクト文字列（サービス名）を指定します。

                                                  • Oracle使用時にサービス名を使用し、Thin接続を行う方法

                                                    VrSetQuery関数の呼び出しを、次のように変更します。

                                                    svf.VrSetQuery("$KIND=ORCL.THIN.SERVICE;HOST=xxx;UID=xxx;PWD=xxx;SERVICE_NAME=xxx", "xxx.vrq", 0);

                                                    各パラメーターは次のとおりです。

                                                    • $KIND

                                                      ORACLEDBへの接続情報を指定します。

                                                    • HOST

                                                      DBサーバーのホスト名またはIPアドレスを指定します。

                                                    • UID

                                                      ユーザーIDを指定します。

                                                    • PWD

                                                      パスワードを指定します。

                                                    • SERVICE_NAME

                                                      サービス名を指定します。

                                                  • DB2使用時にJDBC経由でクエリー接続する方法

                                                    VrSetQuery関数の呼び出しを、次のように変更します。

                                                    svf.VrSetQuery("$KIND=DB2.JCC;UID=xxx;PWD=xxx", "xxx.vrq", 0);

                                                    各パラメーターは次のとおりです。

                                                    • $KIND

                                                      DB2への接続情報を指定します。

                                                    • UID

                                                      ユーザーIDを指定します。

                                                    • PWD

                                                      パスワードを指定します。

                                                  • WebSphere Application Server6.1、7.0でコネクションプールを使用してクエリー接続する方法

                                                    VrSetQuery関数の呼び出しを、次のように変更します。

                                                    svf.VrSetQuery("$KIND=WAS4;DBALIAS=xxx;UID=xxx;PWD=xxx","xxx.vrq",0);

                                                    各パラメーターは次のとおりです。

                                                    • $KIND

                                                      WebSphere Application Serverの接続情報を指定します。

                                                    • DBALIAS

                                                      データソース名を指定します。

                                                    • UID

                                                      ユーザーIDを指定します。

                                                    • PWD

                                                      パスワードを指定します。

  // 第1パラメーター java.sql.Connection すでに接続済みのConnectionを渡します
  // 第2パラメーター DBの種別 vfreport.properties.ja の中にあるQuery.Driverに
  // あるDBの種別を指定します。 実際には接続文字列は
  // 使用されませんが、DBの種類の違いによるSQLの文法
  // の差異があるため、Oracleの場合はORCL.THINを指定
  // する必要があります
  // 第3パラメーター クエリー様式ファイル名
  // 第4パラメーター 常に0を指定します
  
  svf.VrSetQueryEx(conn, "$KIND=ORCL.THIN", "vrq1.vrq", 0);
  svf.VrExecQuery();
  svf.VrPrint();
  out.println("VrQuit():" + svf.VrQuit() + "<BR>");
            

 } catch (Exception e) {
  e.printStackTrace();
 } finally{
  // Connectionのクローズは必ず行ってください
  if (conn != null){
   conn.close();
  }
 }

                                                VrSetPrinter

                                                機能

                                                出力先を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrSetPrinter(String PDL, String Printer);

                                                • ASP/VB

                                                  Function instance.VrSetPrinter(PDL As String, Printer As String) As Long

                                                • C

                                                  int VrSetPrinter(HSVFRCLIENT instance, char *PDL, char *Printer);

                                                • VB.NET

                                                  Function instance.VrSetPrinter(PDL As String, Printer As String) As Integer

                                                引数

                                                • PDL

                                                  プリンター機種

                                                • Printer

                                                  プリンター名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                出力先を指定します。第2引数「Printer」で指定されるプリンター内部でPDL（ページ記述言語）を持っているため、第1引数「PDL」は特に明示的に指定する必要はありません。第2引数「Printer」は、SVF環境設定であらかじめ作成されているプリンター名を指定します。複数の出力先を指定する場合は、セパレーター「|」で区切ってプリンター名を指定します。プリンター名は3つまで指定できます。プリンターの作成方法は、SVF実行部製品のマニュアルを参照してください。

                                                コネクト製品からの実行で、クライアント側にファイルを出力する（クライアントプリンターへの印刷含む）「Printer」は複数指定できません。

                                                参考

                                                • VrSetPrinter関数はVrInit関数の直後に使用してください。そのほかの関数を使用した後に実行すると、VrInit関数とVrSetPrinter関数の間に呼び出された関数はクリアされます。

                                                • 第2引数「Printer」で複数のプリンター名を指定した場合に、1つでも出力に失敗したプリンターがあると、すべてのプリンターへの出力が失敗します。

                                                • 第2引数「Printer」で複数のプリンター名を指定した場合、周辺機器を操作する以下の関数は、プリンターごとに異なった指定はできません。以下の関数を指定すると、すべてのプリンターに対して同じ処理が実行されます。

                                                  VrSetTray、VrSetDuplex、VrSetOutputBin、VrSetSort、VrSetStaple、VrSetPunch、VrComout("/{PTYP n}/")、VrPaperEject

                                                使用例

                                                • 「PDF」という名前のプリンターに出力する場合

                                                  • Java/C#

                                                    svf.VrSetPrinter("", "PDF");

                                                  • ASP/VB

                                                    svf.VrSetPrinter("", "PDF")

                                                  • C

                                                    VrSetPrinter(svf, "", "PDF");

                                                  • VB.NET

                                                    svf.VrSetPrinter("", "PDF")

                                                • 「PDF」と「LIPS4」という名前の2つのプリンターに出力する場合

                                                  • Java/C#

                                                    svf.VrSetPrinter("", "PDF|LIPS4");

                                                  • ASP/VB

                                                    svf.VrSetPrinter("", "PDF|LIPS4")

                                                  • C

                                                    VrSetPrinter(svf, "", "PDF|LIPS4");

                                                  • VB.NET

                                                    svf.VrSetPrinter("", "PDF|LIPS4")
