                                                3.3. ラベルプリンター対応機種で使用できる関数

                                                ラベルプリンター対応機種のみで使用可能な関数を説明します。

                                                関数

                                                説明

                                                VrComout("/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/")

                                                RFIDタグへの書き込みを行います。本関数は、Ver.10.1以降のTEC機種のみで利用できます。

                                                VrComout("/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/")

                                                機能

                                                RFIDタグへの書き込みを行います。

                                                書式

                                                各言語による書式は次のとおりです。

                                                • Java/C#

                                                  int instance.VrComout("/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{RFID FeedDir=n1 Feed=n2 FeedOffset=n3 TagType=n4 DataType=n5 EpcType=n6 EpcData=n7 UsrData=n8}/") As Integer

                                                引数

                                                • FeedDir

                                                  RFIDタグ書き込み前のフィードの方向を指定します。「Feed」とセットで使用してください。省略時または+-以外を指定した場合、フィードしません。

                                                  • n1

                                                    値

                                                    説明

                                                    -

                                                    正転フィード

                                                    +

                                                    逆転フィード

                                                • Feed

                                                  RFIDタグ書き込み前の正転または逆転フィードの量を指定します。「FeedDir」とセットで使用してください。RFIDタグへ書き込み後、フィード前の位置に戻ります。省略時は、フィードしません。

                                                  • n2

                                                    フィード量を4桁の文字列で指定します。

                                                    0030～9999（0.1mm単位）

                                                • FeedOffset

                                                  オフセット印字動作を指定します。省略時は、「オフセット印字動作無効」になります。

                                                  • n3

                                                    値

                                                    説明

                                                    0

                                                    オフセット印字動作無効

                                                    1

                                                    オフセット印字動作有効（1枚目バックフィードなし）

                                                    2

                                                    オフセット印字動作有効（1枚目バックフィードあり）

                                                • TagType

                                                  RFIDタグの種類を指定します。省略時は、プリンター機器本体のシステム設定値が適用されます。

                                                  • n4

                                                    値

                                                    説明

                                                    24

                                                    EPC Class1 Generation2

                                                • DataType

                                                  「EpcData」、「UsrData」に指定するデータのフォーマットを指定します。省略時は、「ASCII」となります。

                                                  • n5

                                                    値

                                                    説明

                                                    0

                                                    ASCIIで指定

                                                    たとえば、UsrData=ABCDと指定した場合、Userメモリに0x41、0x42、0x43、0x44が書き込まれます。

                                                    2

                                                    HEXで指定

                                                    たとえば、UsrData=41424344と指定した場合、Userメモリに0x41、0x42、0x43、0x44が書き込まれます。

                                                • EpcType

                                                  EPCメモリに書き込むデータの種類を指定します。省略時は、「EPCのみを書き込む」となります。なお、「1」または「2」を指定した場合、DataTypeは「2」（HEXで指定）を指定する必要があります。

                                                  • n6

                                                    値

                                                    説明

                                                    0

                                                    EPCのみを書き込む

                                                    1

                                                    PC+EPCを書き込む

                                                    PCで示されるEPCデータのサイズと実際のEPCデータのサイズが同じでない場合、書き込みは保証されません。

                                                    2

                                                    PC+EPCを書き込む

                                                    PCで示されるEPCデータのサイズと実際のEPCデータのサイズが異なる場合でも書き込みます。

                                                • EpcData

                                                  EPCメモリに書き込むデータを指定します。省略時は、EPCメモリへの書き込みを行いません。「EpcData」、「UsrData」のいずれか、または両方を必ず指定してください。

                                                  • n7

                                                    以下のいずれかで指定します。どちらも、書き込める量は使用するタグにより異なります。

                                                    • フィールド参照

                                                      書き込むデータが格納されるフィールドのフィールド名を指定します。繰り返しフィールドを指定した場合は、最初のフィールドの値が書き込まれます。サブフォーム、レコード上のフィールドを指定した場合は、最後のフィールドの値が書き込まれます。

                                                      ページごとに異なる値を書き込みたい場合は、フィールド参照で指定してください。

                                                    • 直接指定

                                                      EPCメモリに書き込むデータを「DataType」で指定したフォーマットで記述します。指定可能な文字は、英数字と記号のみです。実行時に指定する様式ファイルに配置されているフィールドのフィールド名と同じ文字列は指定できません。

                                                      直接指定の場合、ページごとに異なる値を書き込みできません。

                                                • UsrData

                                                  USERメモリに書き込むデータを指定します。省略時は、USERメモリへの書き込みを行いません。「EpcData」、「UsrData」のいずれか、または両方を必ず指定してください。

                                                  • n8

                                                    以下のいずれかで指定します。書き込める量は使用するタグにより異なります。

                                                    • フィールド参照

                                                      書き込むデータが格納されるフィールドのフィールド名を指定します。繰り返しフィールドを指定した場合は、最初のフィールドの値が書き込まれます。サブフォーム、レコード上のフィールドを指定した場合は、最後のフィールドの値が書き込まれます。

                                                      ページごとに異なる値を書き込みたい場合は、フィールド参照で指定してください。

                                                    • 直接指定

                                                      EPCメモリに書き込むデータを「DataType」で指定したフォーマットで記述します。指定可能な文字は、英数字と記号のみです。実行時に指定する様式ファイルで指定されているフィールドのフィールド名と同じ文字列は指定できません。

                                                      直接指定の場合、ページごとに異なる値を書き込みできません。

                                                戻り値

                                                • 0

                                                  正常

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                RFIDタグへの書き込みを行います。この関数は、VrSetForm関数の後に呼び出します。1度指定すれば、改ページしても、各ページのRFIDタグにデータが書き込まれます。この関数の指定がない場合には、RFIDタグへの書き込みは行いません。

                                                本関数は、Ver.10.1以降のTEC機種のみで利用できます。

                                                使用例

                                                EPCメモリに「ABCDEFGH」を、USERメモリに「12345678」を書き込みます。

                                                • Java/C#

                                                  svf.VrComout("/{RFID EpcData=ABCDEFGH UsrData=12345678}/");

                                                • ASP/VB

                                                  svf.VrComout("/{RFID EpcData=ABCDEFGH UsrData=12345678}/")

                                                • C

                                                  VrComout(svf,"/{RFID EpcData=ABCDEFGH UsrData=12345678}/");

                                                • VB.NET

                                                  svf.VrComout("/{RFID EpcData=ABCDEFGH UsrData=12345678}/")

                                                関数使用順

                                                Vrw32 svf = new Vrw32();
svf.VrInit();
svf.VrSetPrinter(...);
svf.VrSetForm(...);
svf.VrComout("/{RFID 設定名=設定値}/");
     :
svf.VrQuit();
