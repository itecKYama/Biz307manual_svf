                                                3.2.2. ICカード認証によるセキュリティプリントの関数

                                                ここでは、印刷を制御する関数のうち、ICカード認証によるセキュリティプリント機能を使用する場合に使用するAPIを説明します。

                                                ICカード認証によるセキュリティプリントへの対応

                                                SVFではプリンター機種ごとに、次のICカード認証によるセキュリティプリントに対応しています。

                                                • LIPS4（*1）

                                                  • Anyplace Print for MEAP ADVANCE / Anyplace Print for MEAP / Anyplace Print for MEAP-Lite

                                                  • Personal ListPrint for MEAP ADVANCE / Personal ListPrint for MEAP

                                                • ART4（*2）

                                                  • PrintXchange オンデマンドプリント

                                                  • プライベートプリント

                                                  • ApeosWare Print Management

                                                • RPCS

                                                  • IPSiO 個人認証キット

                                                  • imagio 個人認証キット

                                                  • 個人認証システムAE

                                                  • 個人認証システムAE2

                                                  • 簡単私書箱プリントAE2

                                                1. 各社プリンター対応機種またはReport Director Enterpriseに登録したプリンターの詳細設定で、［周辺機器の制御方法］の設定値を「CPCA-iR」、「CPCA-LBP」、「CPCA2」のいずれかに設定する必要があります。

                                                2. 各社プリンター対応機種またはReport Director Enterpriseに登録したプリンターの詳細設定で、［周辺機器の制御方法］の設定値を「XPJL」に設定する必要があります。

                                                参考

                                                SVFプリンターの［周辺機器の制御方法］の設定については、『SVF帳票出力製品管理ガイド』または『RDEスプール管理ガイド』を参照してください。

                                                ICカード認証によるセキュリティプリントの関数

                                                ICカード認証によるセキュリティプリントで使用するAPI関数は、次のとおりです。

                                                関数名

                                                機能

                                                VrComout("/{SECP}/")

                                                ICカード認証によるセキュリティプリント機能を使用する場合に指定します。

                                                VrComout("/{BOXN n}/")

                                                ボックス番号を指定します。

                                                VrSetUserName

                                                ユーザー名を指定します。

                                                VrSetDocName2

                                                ドキュメント名を指定します。

                                                VrComout("/{SECP}/")

                                                機能

                                                ICカード認証によるセキュリティプリント機能を使用する場合に指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{SECP}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{SECP}/") As Long

                                                • C

                                                  int VrComout("/{SECP}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{SECP}/") As Integer

                                                引数

                                                なし

                                                戻り値

                                                • 0

                                                  成功

                                                • -40

                                                  エラー

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                ICカード認証によるセキュリティプリント機能を使用する場合に実行します。ユーザー名とドキュメント名は別途、VrSetUserName関数とVrSetDocName2関数で指定する必要があります。

                                                関数使用順

                                                本関数は、VrSetPrinterの後に指定します。

                                                svf.VrInit();
svf.VrSetPrinter("", "LIPS4");
svf.VrComout("/{SECP}/");
svf.VrComout("/{BOXN 3}/");
svf.VrSetUserName("user_name");
svf.VrSetDocName2("document_name");
svf.VrSetForm("sample.xml", 4);
：
svf.VrQuit();

                                                VrComout("/{BOXN n}/")

                                                機能

                                                ボックス番号を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{BOXN n}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{BOXN n}/") As Long

                                                • C

                                                  int VrComout("/{BOXN n}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{BOXN n}/") As Integer

                                                引数

                                                • n

                                                  ボックス番号

                                                  1～99の整数を指定します。

                                                戻り値

                                                • 0

                                                  成功

                                                • -40

                                                  エラー

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                プリンター機種LIPS4を使用し、「Personal ListPrint for MEAP」、「Personal ListPrint for MEAP ADVANCE」と連携する場合、ジョブを蓄積するBOX番号を指定します。

                                                この関数はVrComout("/{SECP}/")関数の後に呼び出します。

                                                使用例

                                                ボックス番号に3を指定します。

                                                • Java/C#

                                                  svf.VrComout("/{BOXN 3}/");

                                                • ASP/VB

                                                  svf.VrComout("/{BOXN 3}/")

                                                • C

                                                  VrComout(svf, "/{BOXN 3}/");

                                                • VB.NET

                                                  svf.VrComout("/{BOXN 3}/")

                                                VrSetUserName

                                                VrComout("/{SECP}/")関数を使用した場合、ユーザー名の指定には、共通関数のVrSetUserNameを使用します。

                                                VrSetUserNameの詳細については、「共通関数（3）」の「VrSetUserName」を参照してください。

                                                参考

                                                VrComout("/{SECP}/")を実行した場合、または、プリンターの設定で［セキュリティプリント機能］が「使用する」に指定されている場合、VrSetUserNameでの指定有無によって、使用されるユーザー名が異なります。

                                                • VrSetUserNameを実行した場合

                                                  VrSetUserNameで指定した値が使用されます。

                                                • VrSetUserNameを実行しない場合

                                                  ログインユーザーネーム（Javaのシステムプロパティ「user.name」の値）が使用されます。

                                                VrSetDocName2

                                                VrComout("/{SECP}/")関数を使用した場合、ドキュメント名を指定には、共通関数のVrSetDocName2を使用します。

                                                VrSetDocName2の詳細については、「共通関数（2）」の「VrSetDocName2」を参照してください。

                                                参考

                                                VrComout("/{SECP}/")を実行した場合、または、プリンターの設定で［セキュリティプリント機能］が「使用する」に指定されている場合、VrSetDocName2での指定有無によって、使用されるドキュメント名が異なります。

                                                • VrSetDocName2を実行した場合

                                                  VrSetDocName2で指定した値が使用されます。

                                                • VrSetDocName2を実行しない場合

                                                  固定文字列「SVF for Java Print」が使用されます。

                                                RDEユーティリティを使用した場合の制限と対応

                                                RDEユーティリティを使用した場合、ICカード認証によるセキュリティプリントを指定した文書であってもセキュリティが効かないケースがあります。その場合、次のような対応を行います。

                                                • ページ指定での印刷で、1ページ目を除く印刷を行うと、プリンター側で認証ができません。

                                                  VrComout("/{DATR EnablePrintPageRange=1}/")を使用して、部分ページ指定を不可に設定します。

                                                  API関数の詳細については、「Report Director Enterprise使用時の関数」の「VrComout("/{DATR EnablePrintPageRange=n}/")」を参照してください。

                                                  また、RDE環境設定のユーザーグループの権限設定で「［ページ指定］を有効にする」のチェックをオフにすることでも対応可能です。

                                                • 別の（セキュリティの仕組みがない）プリンターへの印刷が可能です。

                                                  VrComout("/{DATR EnablePrinterKind=xxx}/")を使用して、当該文書が印刷可能なプリンター機種名を限定します。

                                                  API関数の詳細については、「Report Director Enterprise使用時の関数」の「VrComout("/{DATR EnablePrinterKind=xxx}/")」を参照してください。

                                                  また、RDE環境設定のユーザーグループの権限設定で使用できるプリンターを限定することでも対応可能です。

                                                • プレビューが可能です。

                                                  VrComout("/{DATR EnableView=1}/")を使用して、当該文書のプレビューを不可に設定します。

                                                  API関数の詳細については、「Report Director Enterprise使用時の関数」の「VrComout("/{DATR EnableView=n}/")」を参照してください。

                                                  また、RDE環境設定のユーザーグループの権限設定で「［ビューアー］を有効にする」のチェックをオフにすることでも対応可能です。

                                                RDE環境設定でのユーザーグループの権限設定については、『RDEスプール管理ガイド』の「管理者とユーザーの管理」を参照してください。
