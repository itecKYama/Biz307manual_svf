                                                3. API関数

                                                SVFでは、製品によって使用できる関数が異なります。

                                                ここでは、すべての製品で使用できる関数を「共通関数」としてまとめて記載します。製品ごとに使用できる関数は、製品ごとに記載します。また、書式や設定例などは、使用する言語に応じて次のように表記します。

                                                共通関数

                                                関数名

                                                機能

                                                VrInit / VrInitEx

                                                SVFの動作環境を初期化します。

                                                VrQuit

                                                印刷処理を完了し、使用していたリソースを解放します。

                                                VrSetLocale

                                                SVF既定のロケール（地域情報）を指定します。

                                                VrSetForm

                                                印刷に用いるXML様式ファイルと出力のモードを指定します。

                                                VrsOut / VrsOutn

                                                文字型データ、またはイメージファイル名を指定します。

                                                VriOut / VriOutn

                                                32ビット型整数のデータを出力します。

                                                VrlOut / VrlOutn

                                                64ビット型整数のデータを出力します。

                                                VrrOut / VrrOutn

                                                実数のデータを出力します。

                                                VrEndPage

                                                1ページ分のデータ出力が終了したら印刷します。

                                                VrSetQuery

                                                クエリー様式ファイルを指定します。

                                                VrSetQueryEx

                                                java.sql.Connectionを指定できるVrSetQuery関数です。

                                                VrReport

                                                クエリーを実行します。

                                                VrExecQuery

                                                クエリーを実行します。

                                                VrEndRecord

                                                明細データ1行分を出力し終えたことをSVFに指示します。

                                                VrPrint

                                                レポートライターモード下の出力において、データ出力の完了をSVFに指示します。

                                                VrSetPrinter

                                                出力先を指定します。

                                                VrCondition

                                                クエリーの抽出条件を指定します。

                                                VrSetPageCount

                                                設計関数のPAGE関数の初期値と加算値を設定します。

                                                VrCopy

                                                印刷部数を指定します。

                                                VrSetDocName2

                                                1. Report Director Enterpriseへスプールする文書名を指定します。

                                                2. PDF機種で作成されたPDFファイルのプロパティでのタイトルを指定します。

                                                3. SVFスプーラーで表示する文書名を指定します。

                                                4. SVGファイルをHTML形式に出力する場合、<title>要素内のタイトルを指定します。

                                                VrSetSpoolFileName2

                                                ファイル出力を行う場合に、作成するファイル名とその作成場所を指定します。

                                                VrAdjustd / VrAdjustm

                                                印字位置を調整し、調整後の印字位置をXML様式ファイルに保存します。

                                                VrAdjustd2 / VrAdjustm2

                                                印字位置を一時的に調整します。

                                                VrGetAttribute

                                                フィールド属性や、出力結果に関する情報を取得します。

                                                VrTest

                                                テスト印刷を実行します。

                                                VrSeqOut

                                                シーケンシャルモードでの文字列を出力します。

                                                VrPage

                                                綴りが複数ページで構成されているXML様式ファイルの印字対象ページを指定します。

                                                VrSetCalcMode

                                                最大37桁（整数部＋小数部）の十進演算ライブラリをサポートします。

                                                VrGetStatus

                                                ステータスを取得します。

                                                VrOutputQuery

                                                VrSetQuery関数で指定したクエリーを実行した際にデータベースから取得されたデータを、指定したファイルにCSV形式で保存します。

                                                VrComout("/{FOUT n}/")

                                                フィールドが存在しない帳票を出力するかどうかを指定します。

                                                VrComout("/{DATE DateData}/")

                                                設計関数のDATE()、TIME()が返す値が指定の日付、時刻になるように設定します。

                                                VrSetUserName

                                                文書ユーザー名を指定します。

                                                VrGetManageNum

                                                スプールされた文書の文書管理番号を取得します。Report Director Enterpriseの文書管理番号の他に、SVFスプーラーに送信した場合のJOB番号を取得できます。

                                                VrComout("/{ALNK n}/")

                                                自動リンクフィールドの動作方式を設定します。

                                                VrComout("/{REDU n}/")

                                                拡大縮小モードを指定します。

                                                VrComout("/{DBLG n}/")

                                                デバッグログのデバッグレベルを変更します。

                                                VrComout("/{PROP Image.Alignment n}/")

                                                ファイル名を実行時に設定するイメージ（画像データの出力エリア）において画像の表示位置を指定します。

                                                VrComout("/{DVUN n}/")

                                                （Ver. 10.1で対応）

                                                ファイルを分割して出力する場合に、1ファイル分のページ数を指定します。

                                                VrComout("/{DVFX Postfix}/")

                                                （Ver. 10.1で対応）

                                                ファイルを分割して出力する場合に、ファイル名の末尾（拡張子の直前）にどのように番号を付加するかを指定します。

                                                VrComout("/{BNFN FileName}/")

                                                （Ver. 10.1で対応）

                                                ファイルを分割して出力する場合に使用する、バナー様式ファイルを指定します。

                                                VrComout("/{BNFN FileName}/")

                                                （Ver. 10.1で対応）

                                                インスタンスを再利用する場合に、使用していたリソースを解放します。

                                                機能

                                                PDF機種のみで使用できる関数

                                                関数名

                                                機能

                                                VrSetSpoolFileStream

                                                ファイル生成時に、ディスク上のファイルにではなくメモリに出力します。

                                                VrComout("/{SECU n}/")

                                                PDFのセキュリティ機能の有無を指定します。

                                                VrComout("/{PSWD Password}/")

                                                PDFオープン時のパスワードを指定します。

                                                VrComout("/{SECUPSWD Password}/")

                                                PDFのセキュリティパスワードを指定します。

                                                VrComout("/{PERM n}/")

                                                禁止項目を指定します。

                                                VrComout("/{PRESET プリセット名=n ...}/")

                                                PDFに印刷プリセットを付与します。

                                                VrComout("/{SPJL PDF variable=value}/")

                                                PJLのSETコマンドを出力します。

                                                VrComout("/{SPJL PDF command variable=value}/")

                                                PJLの任意コマンドを出力します。

                                                VrComout("/{SFNG n}/")

                                                （Ver. 10.3で対応）

                                                検索フィールドが設計されているXML様式ファイルを使用した出力において、検索フィールドとして設計されていないアイテムに検索フィールドを付加します。

                                                VrComout("/{SFVC n}/")

                                                （Ver. 10.3で対応）

                                                検索フィールドが設計されていないXML様式ファイルを使用した出力において、アイテムに検索フィールドを付加します。

                                                VrComout("/{SFSD n}/")

                                                （Ver. 10.3で対応）

                                                検索フィールドとして設計されていないアイテムに検索フィールドを付加する際の、検索フィールド名の設定方法を指定します。

                                                VrComout("/{SFXN name}/")

                                                （Ver. 10.3で対応）

                                                検索フィールドとして設計されていないアイテムに検索フィールドを付加する際の検索フィールド名を「固定名+連番」とした場合の固定名を指定します。

                                                CSV機種のみで使用できる関数

                                                関数名

                                                機能

                                                VrSetCSVFileName

                                                XML様式ファイルの設計に従って、出力結果をCSV形式のファイルに出力します。

                                                Excel機種のみで使用できる関数

                                                テンプレート出力方式のAPI

                                                関数名

                                                機能

                                                VrComout("/{XSFN ファイルパス}/")

                                                テンプレートExcelファイルを指定します。

                                                VrComout("/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/")

                                                セルの書式を設定します。

                                                VrComout("/{XSCC FIELD=n1 CELLOUT=n2}/")

                                                出力先セルを変更します。

                                                VrComout("/{XSSA <NO=n1またはNAME=n2>}/")

                                                処理対象ワークシートを指定します。ワークシート番号またはワークシート名を指定します。

                                                VrComout("/{XSSC <NO=n1またはNAME=n2> <CHANGE=n3>}/")

                                                ワークシートをコピーします。ワークシート番号またはワークシート名を指定します。

                                                VrComout("/{XSSD <NO=n1またはNAME=n2>}/")

                                                ワークシートを削除します。ワークシート番号またはワークシート名を指定します。

                                                VrComout("/{XSSM <NO=n1またはNAME=n2> WHICH=n3}/")

                                                ワークシートの位置を移動します。ワークシート番号またはワークシート名を指定します。

                                                直接出力方式のAPI

                                                関数名

                                                機能

                                                VrComout("/{XSCN デフォルトワークシート名}/")

                                                VrComout("/{XSHD ヘッダー情報}/")

                                                ワークシートのヘッダーを設定します。

                                                VrComout("/{XSFT フッター情報}/")

                                                ワークシートのフッターを設定します。

                                                出力方式に関係なく使用できるAPI

                                                VrComout("/{XSPA 印刷範囲}/")

                                                VrComout("/{XSRT <NO=n1またはNAME=n2> RANGE=n3}/")

                                                SVF コネクト製品のみで使用できる関数

                                                関数名

                                                機能

                                                VrComout("/{CSMD n}/")

                                                PDFファイル、およびCSVファイルの出力時に、ファイルの保存先を切り替えます。

                                                VrLocalPrint

                                                クライアントコンピューター上に登録されたプリンター機器へ出力する場合に、スプールファイルをスプーラーに転送します。

                                                VrDataOut

                                                DataSet内のテーブルデータを一括で出力します。SVF Connect for .NET Framework APIでのみ使用できます。

                                                SVF for Web/Client使用時の関数

                                                関数名

                                                機能

                                                VrComout("/{SPLM n}/")

                                                出力データファイルの出力方法を指定します。

                                                Report Director Enterprise使用時の関数

                                                関数名

                                                機能

                                                VrComout("/{SUCL xxx, xxx}/")

                                                RDE環境設定の［カラム設定］で追加したユーザー定義カラムにデータを登録します。

                                                VrComout("/{DATR Stop=n}/")

                                                スプール文書の印刷処理を停止します。

                                                VrComout("/{DATR CopiesCollate=n}/")

                                                Report Director Enterpriseから部単位での印刷を指定します。

                                                VrComout("/{DATR AutoPrintMode=n}/")

                                                スプールデータを受け取りながらSVF実行部製品を実行してデータを生成するか、スプールデータをすべて受け取り終えてからSVF実行部製品を実行してデータを生成するかを指定します。

                                                VrComout("/{DATR ValidDays=n}/")

                                                スプール時に文書の有効日数を指定します。

                                                VrComout("/{DATR ReprintForm=xxx}/")

                                                スプール時に文書ごとに［再印刷様式名］を指定します。再印刷とは、「印刷完了」ステータスの文書を再度印刷することを示します。

                                                VrComout("/{PPRI priority}/")

                                                印刷文書ごとに優先順位を付けます。

                                                VrSetComputerName

                                                コンピューター名を指定します。

                                                VrSetOutputPrinter

                                                文書のスプール後、即時印刷する場合のプリンター名を指定します。

                                                VrSetOutputVPrinter

                                                文書のスプール後、即時印刷する場合のプリンターグループ名を指定します。

                                                VrSetOutputVPrinter2

                                                印刷先のプリンターグループ名を指定して文書をスプールし、印刷せずに停止します。

                                                VrAbortDoc

                                                Report Director Enterpriseへのスプール処理を中断します。

                                                VrComout("/{DATR EnablePrinterKind=xxx}/")

                                                印刷可能なプリンター機種を指定します。

                                                VrComout("/{DATR EnablePrintPageRange=n}/")

                                                印刷実行時、印刷ページ範囲指定により部分ページ指定が可能かどうかを設定します。

                                                VrComout("/{DATR EnableView=n}/")

                                                スプールされた文書がビュー可能かどうかを指定します。
