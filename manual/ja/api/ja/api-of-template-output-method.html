                                                VrComout("/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/")

                                                機能

                                                セルの書式を設定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSCL FONTCOLOR=n1 BOLD=n2 ITALIC=n3 LOC=n4 SHEETNO=n5}/") As Integer

                                                引数

                                                • FONTCOLOR

                                                  フォント色をパレット番号で指定します（1～56）。パラメーターは省略可能です。

                                                  • n1

                                                    パレット番号を指定します。指定可能なパレットカラー番号については、「指定可能なパレットカラー番号」を参照してください。

                                                • BOLD

                                                  ボールド属性指定（0～1）。パラメーターは省略可能です。

                                                  • n2

                                                    値

                                                    説明

                                                    0

                                                    セルの書式設定からボールド属性を解除します。

                                                    1

                                                    セルの書式設定へボールド属性を付与します。

                                                • ITALIC

                                                  イタリック属性指定（0～1）。パラメーターは省略可能です。

                                                  • n3

                                                    値

                                                    説明

                                                    0

                                                    セルの書式設定からイタリック属性を解除します。

                                                    1

                                                    セルの書式設定へイタリック属性を付与します。

                                                • LOC

                                                  書式を変更するセルの位置を指定します。

                                                • SHEETNO

                                                  書式を変更するセルが属するシートを指定します（1～）。

                                                  綴りページのある様式の場合に、SHEETNOを省略すると、すべてのシートで指定セルの書式が変更されます。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                セルの書式を設定します。フォント色（FONTCOLOR）、ボールド属性（BOLD）、イタリック属性（ITALIC）が指定可能です。FONTCOLOR、BOLD、ITALICのうち1つ以上を指定します。

                                                注意事項

                                                • SHEETNOは、綴りページのあるXML様式ファイルの場合に指定してください。綴りページのあるXML様式ファイルを使用し、SHEETNOを省略した場合、すべての綴りページ（文書全体）に対して書式設定が有効です。

                                                • 綴りページのないXML様式ファイルを使用した場合、有効範囲はページ単位です。

                                                • SVF環境設定の［セルの書式設定反映の仕方］が「様式ファイルも含めて反映」に設定されている場合、XML様式ファイルのフィールド属性がセルの書式設定に反映されますが、本APIを指定した場合には、APIでの書式設定の方が優先されます。

                                                使用例

                                                シート2ページ目のセル「A2」に対して、フォント色を赤、ボールド、イタリックを指定します。

                                                • Java/C#

                                                  svf.VrComout("/{XSCL FONTCOLOR=3 BOLD=1 ITALIC=1 LOC=A2 SHEETNO=2}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSCL FONTCOLOR=3 BOLD=1 ITALIC=1 LOC=A2 SHEETNO=2}/")

                                                • C

                                                  VrComout(svf, "/{XSCL FONTCOLOR=3 BOLD=1 ITALIC=1 LOC=A2 SHEETNO=2}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSCL FONTCOLOR=3 BOLD=1 ITALIC=1 LOC=A2 SHEETNO=2}/")

                                                  XML様式ファイル上のフィールド名を指定します。

                                                  • n1

                                                    フィールド名

                                                VrComout("/{XSSA <NO=n1またはNAME=n2>}/")

                                                機能

                                                処理対象ワークシートを指定します。ワークシート番号またはワークシート名を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSSA NO=n1}/");
int instance.VrComout("/{XSSA NAME=n2}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSSA NO=n1}/") As Long
Function instance.VrComout("/{XSSA NAME=n2}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSSA NO=n1}/");
int VrComout(HSVFRCLIENT instance, "/{XSSA NAME=n2}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSSA NO=n1}/") As Integer
Function instance.VrComout("/{XSSA NAME=n2}/") As Integer

                                                引数

                                                • NO

                                                  ワークシート番号を指定します。

                                                  • n1

                                                    ワークシート番号

                                                • NAME

                                                  ワークシート名を指定します。

                                                  • n2

                                                    ワークシート名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                処理対象ワークシートをワークシート番号またはワークシート名で指定します。

                                                綴りページを使用しないXML様式ファイルで、テンプレートExcelファイル内に複数のワークシートが存在する場合に、出力対象となるワークシートを指定します。また、複数のXML様式ファイルを使用する場合にも、VrSetFormごとに本APIで処理対象ワークシートとの関連付けを行います。

                                                注意事項

                                                • APIの有効範囲はページ単位です。

                                                • 綴りページありのXML様式ファイルを使用する場合、本APIは使用できません。

                                                使用例

                                                処理対象ワークシートに「Sheet2」を指定します。

                                                • Java/C#

                                                  svf.VrComout("/{XSSA NAME=Sheet2}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSSA NAME=Sheet2}/")

                                                • C

                                                  VrComout(svf, "/{XSSA NAME=Sheet2}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSSA NAME=Sheet2}/")

                                                VrComout("/{XSSC <NO=n1またはNAME=n2> <CHANGE=n3>}/")

                                                機能

                                                ワークシートをコピーします。ワークシート番号またはワークシート名を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSSC NO=n1 CHANGE=n3}/");
int instance.VrComout("/{XSSC NAME=n2 CHANGE=n3}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSSC NO=n1 CHANGE=n3}/") As Long
Function instance.VrComout("/{XSSC NAME=n2 CHANGE=n3}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSSC NO=n1 CHANGE=n3}/");
int VrComout(HSVFRCLIENT instance, "/{XSSC NAME=n2 CHANGE=n3}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSSC NO=n1 CHANGE=n3}/") As Integer
Function instance.VrComout("/{XSSC NAME=n2 CHANGE=n3}/") As Integer

                                                引数

                                                • NO

                                                  コピーするワークシートをワークシート番号で指定します。

                                                  • n1

                                                    ワークシート番号

                                                • NAME

                                                  コピーするワークシートをワークシート名で指定します。

                                                  • n2

                                                    ワークシート名

                                                • CHANGE

                                                  コピー後のワークシート名を指定します。省略可能です。

                                                  • n3

                                                    ワークシート名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                ワークシート番号またはワークシート名を指定して、ワークシートをコピーします。

                                                CHANGEを省略した場合、自動的に名前が付与されます（「Sheet1」をコピーした場合、「Sheet1(2)」）。

                                                注意事項

                                                • APIの有効範囲はページ単位です。

                                                • 綴りページありのXML様式ファイルを使用する場合、本APIは使用できません。

                                                • 処理対象のシートはコピー後のワークシートに設定されます。XSSAで処理対象のワークシートを変更することも可能です。

                                                • SVF環境設定の［シート自動作成］を「する」に設定した場合、本APIでコピーしたワークシートがさらに自動作成されることはありません。

                                                • コピー元のワークシートをワークシート番号で指定した場合、処理時点のワークブックのシート番号を参照するため、ワークシートのコピーやワークシートの移動を複数回実行するときなどは注意が必要です。ワークシート名を指定してAPIを使用することを推奨します。

                                                • Excelのグラフオブジェクトを含んでいるワークシートの場合、Apache POIの問題によりコピーできません。

                                                使用例

                                                ワークシート「Sheet2」をコピーします。

                                                • Java/C#

                                                  svf.VrComout("/{XSSC NAME=Sheet2}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSSC NAME=Sheet2}/")

                                                • C

                                                  VrComout(svf, "/{XSSC NAME=Sheet2}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSSC NAME=Sheet2}/")

                                                VrComout("/{XSSD <NO=n1またはNAME=n2>}/")

                                                機能

                                                ワークシートを削除します。ワークシート番号またはワークシート名を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSSD NO=n1}/");
int instance.VrComout("/{XSSD NAME=n2}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSSD NO=n1}/") As Long
Function instance.VrComout("/{XSSD NAME=n2}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSSD NO=n1}/");
int VrComout(HSVFRCLIENT instance, "/{XSSD NAME=n2}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSSD NO=n1}/") As Integer
Function instance.VrComout("/{XSSD NAME=n2}/") As Integer

                                                引数

                                                • NO

                                                  削除するワークシートをワークシート番号で指定します。先頭のワークシート番号は「1」です。

                                                  • n1

                                                    ワークシート番号

                                                • NAME

                                                  削除するワークシートをワークシート名で指定します。

                                                  • n2

                                                    ワークシート名

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                • ワークシート番号またはワークシート名のいずれかを指定して、ワークシートを削除します。

                                                • 複数のシートを削除したい場合、削除したいシート分のXSSDコマンドを発行してください。

                                                • シートは、出力処理の最後に削除されます。

                                                • 存在しないシートが指定された場合は、例外を発行し、異常終了します。

                                                使用例

                                                ワークシート名「Sheet2」を削除します。

                                                • Java/C#

                                                  svf.VrComout("/{XSSD NAME=Sheet2}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSSD NAME=Sheet2}/")

                                                • C

                                                  VrComout(svf, "/{XSSD NAME=Sheet2}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSSD NAME=Sheet2}/")

                                                VrComout("/{XSSM <NO=n1またはNAME=n2> WHICH=n3}/")

                                                機能

                                                ワークシートの位置を移動します。ワークシート番号またはワークシート名を指定します。

                                                書式

                                                • Java/C#

                                                  int instance.VrComout("/{XSSM NO=n1 WHICH=n3}/");
int instance.VrComout("/{XSSM NAME=n2 WHICH=n3}/");

                                                • ASP/VB

                                                  Function instance.VrComout("/{XSSM NO=n1 WHICH=n3}/") As Long
Function instance.VrComout("/{XSSM NAME=n2 WHICH=n3}/") As Long

                                                • C

                                                  int VrComout(HSVFRCLIENT instance, "/{XSSM NO=n1 WHICH=n3}/");
int VrComout(HSVFRCLIENT instance, "/{XSSM NAME=n2 WHICH=n3}/");

                                                • VB.NET

                                                  Function instance.VrComout("/{XSSM NO=n1 WHICH=n3}/") As Integer
Function instance.VrComout("/{XSSM NAME=n2 WHICH=n3}/") As Integer

                                                引数

                                                • NO

                                                  移動の基点となるワークシートをワークシート番号で指定します。

                                                  • n1

                                                    ワークシート番号

                                                • NAME

                                                  移動の基点となるワークシートをワークシート名で指定します。

                                                  • n2

                                                    ワークシート名

                                                • WHICH

                                                  ワークシートの位置を指定します。

                                                  • n3

                                                    値

                                                    意味

                                                    0

                                                    処理対象のワークシートを基点となるワークシートの前に移動します。

                                                    1

                                                    処理対象のワークシートを基点となるワークシートの後に移動します。

                                                戻り値

                                                • 0

                                                  成功

                                                • 負数

                                                  エラーコード

                                                  エラーコードについては、『SVF製品エラーコード一覧』の「SVF実行部製品」を参照してください。

                                                説明

                                                移動の基点となるワークシートをワークシート番号またはワークシート名で指定し、処理対象のワークシートの位置を移動します。必ずXSSAを使用して、処理対象ワークシートを指定してから使用します。

                                                注意事項

                                                • APIの有効範囲はページ単位です。

                                                • 綴りページありのXML様式ファイルを使用する場合、本APIは使用できません。

                                                • 移動元のワークシートをワークシート番号で指定した場合、処理時点のワークブックのシート番号を参照するため、ワークシートのコピーやワークシートの移動を複数回実行するときなどは注意が必要です。ワークシート名を指定して使用することを推奨します。

                                                使用例

                                                処理対象ワークシートの位置を「Sheet2」の前へ移動します。

                                                • Java/C#

                                                  svf.VrComout("/{XSSM NAME=Sheet2 WHICH=0}/");

                                                • ASP/VB

                                                  svf.VrComout("/{XSSM NAME=Sheet2 WHICH=0}/")

                                                • C

                                                  VrComout(svf, "/{XSSM NAME=Sheet2 WHICH=0}/");

                                                • VB.NET

                                                  svf.VrComout("/{XSSM NAME=Sheet2 WHICH=0}/")
