                                                                5.2. Excel様式ファイル使用時の関数

                                                                Excel様式ファイル使用時に指定できるAPI関数、およびその指定方法について説明します。

                                                                • VrComout("/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/")

                                                                • VrComout("/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/")

                                                                • VrComout("/{EX_COPY COUNT=n SORT=1}/")

                                                                • VrComout("/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT＝n7}/")

                                                                • VrComout("/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n5 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/")

                                                                VrComout("/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/")

                                                                機能

                                                                セルに値を指定します。

                                                                書式

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/");

                                                                • ASP/VB

                                                                  Function instance.VrComout("/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/") As Long

                                                                • C

                                                                  int VrComout(HSVFRCLIENT instance, "/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/");

                                                                • VB.NET

                                                                  Function instance.VrComout("/{EX_CELLVALUE NAME=n1 NO=n2 CELL=n3 VAL=n4}/") As Integer

                                                                引数

                                                                • NAME

                                                                  データ出力先のシート名を指定します。

                                                                  • n1

                                                                    シート名

                                                                • NO

                                                                  データ出力先のシート番号を指定します（1～）。

                                                                  • n2

                                                                    シート番号

                                                                • CELL

                                                                  データ出力先のセルIDを指定します。

                                                                  • n3

                                                                    セルID

                                                                • VAL

                                                                  出力する値を文字列で指定します。

                                                                  • n4

                                                                    値

                                                                戻り値

                                                                • 0

                                                                  成功

                                                                • 負数

                                                                  エラーコード

                                                                  エラーコードについては、「エラーコード」を参照してください。

                                                                説明

                                                                • NAMEとNOの両方を指定しない場合、すべてのシートに同じ値が出力されます。シートの出力順はExcel様式ファイルでの並び順に従います。

                                                                • NAMEとNOの両方を指定した場合、NOの指定は無視されます。

                                                                • NOに指定するシート番号は、Microsoft Excel上で非表示のシートもカウント対象です。

                                                                • 出力先のセルに値がある場合は上書きされます。

                                                                • CELLにR1C1参照形式のセルIDは指定できません。

                                                                • 項目値にスペースが含まれる場合、引数の前後を「\"」と「\"」で囲んでください。

                                                                使用例

                                                                • シート番号「1」のセル「A1」に「ウイングアーク１ｓｔ株式会社」というデータを出力する場合

                                                                  • Java/C#

                                                                    svf.VrComout("/{EX_CELLVALUE NO=1 CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_CELLVALUE NO=1 CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_CELLVALUE NO=1 CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_CELLVALUE NO=1 CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/")

                                                                • シート名にスペースが含まれる場合

                                                                  • Java/C#

                                                                    svf.VrComout("/{EX_CELLVALUE \"NAME=Sheet 1\" CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_CELLVALUE \"NAME=Sheet 1\" CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_CELLVALUE \"NAME=Sheet 1\" CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_CELLVALUE \"NAME=Sheet 1\" CELL=A1 VAL=ウイングアーク１ｓｔ株式会社}/")

                                                                VrComout("/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/")

                                                                機能

                                                                シートをコピーします。

                                                                書式

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/");

                                                                • ASP/VB

                                                                  Function instance.VrComout("/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/") As Long

                                                                • C

                                                                  int VrComout(HSVFRCLIENT instance, "/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/");

                                                                • VB.NET

                                                                  Function instance.VrComout("/{EX_COPYSHEET NAME=n1 NO=n2 COPYNAME=n3 INSERTNAME=n4 INSERTNO=n5}/") As Integer

                                                                引数

                                                                • NAME

                                                                  コピーするシートのシート名を指定します。

                                                                  • n1

                                                                    シート名

                                                                • NO

                                                                  コピーするシートのシート番号を指定します（1～）。

                                                                  • n2

                                                                    シート番号

                                                                • COPYNAME

                                                                  コピーしたシートのシート名を指定します。

                                                                  • n3

                                                                    コピー後のシート名

                                                                • INSERTNAME

                                                                  コピーしたシートの挿入先として、挿入先の直後のシート名を指定します。

                                                                  • n4

                                                                    挿入先のシート名

                                                                • INSERTNO

                                                                  コピーしたシートの挿入先として、挿入先の直後のシート番号を指定します。

                                                                  • n5

                                                                    挿入先のシート番号

                                                                戻り値

                                                                • 0

                                                                  成功

                                                                • 負数

                                                                  エラーコード

                                                                  エラーコードについては、「エラーコード」を参照してください。

                                                                説明

                                                                • 複数レコードのデータを出力する場合に使用します。2レコード目以降のデータを出力する際に、この関数を指定してください。指定しない場合、最終レコードのデータで上書きされて出力されます。

                                                                • コピーしたシートの再コピーには対応していません。Excel様式ファイルに存在するコピー元のシートをコピーしてください。

                                                                • NAMEとNOの両方を指定した場合、NOの指定は無視されます。

                                                                • NOおよびINSERTNOに指定するシート番号は、Microsoft Excel上で非表示のシートもカウント対象です。

                                                                • COPYNAMEを省略した場合、コピー後のシート名は「コピー元シート名 (n)」となります。

                                                                • INSERTNAMEとINSERTNOの両方を省略した場合、または存在しないシートを指定した場合、コピー元シートの直後に挿入されます。INSERTNAMEとINSERTNOの両方を指定した場合、INSERTNOの指定は無視されます。

                                                                • INSERTNOに0を指定すると、全シートの末尾に挿入されます。

                                                                • 項目値にスペースが含まれる場合、引数の前後を「\"」と「\"」で囲んでください。

                                                                使用例

                                                                • シート名「Sheet1」のシートを「Sheet1-1」としてコピーする場合

                                                                  • Java/C#

                                                                    int instance.VrComout("/{EX_COPYSHEET NAME=Sheet1 COPYNAME=Sheet1-1}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_COPYSHEET NAME=Sheet1 COPYNAME=Sheet1-1}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_COPYSHEET NAME=Sheet1 COPYNAME=Sheet1-1}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_COPYSHEET NAME=Sheet1 COPYNAME=Sheet1-1}/")

                                                                • シート名にスペースが含まれる場合

                                                                  • Java/C#

                                                                    svf.VrComout("/{EX_COPYSHEET \"NAME=Sheet 1\" \"COPYNAME=Sheet 1-1\"}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_COPYSHEET \"NAME=Sheet 1\" \"COPYNAME=Sheet 1-1\"}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_COPYSHEET \"NAME=Sheet 1\" \"COPYNAME=Sheet 1-1\"}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_COPYSHEET \"NAME=Sheet 1\" \"COPYNAME=Sheet 1-1\"}/")

                                                                VrComout("/{EX_COPY COUNT=n SORT=1}/")

                                                                機能

                                                                印刷部数を指定します。

                                                                書式

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_COPY COUNT=n SORT=1}/");

                                                                • ASP/VB

                                                                  Function instance.VrComout("/{EX_COPY COUNT=n SORT=1}/") As Long

                                                                • C

                                                                  int VrComout(HSVFRCLIENT instance, "/{EX_COPY COUNT=n SORT=1}/");

                                                                • VB.NET

                                                                  Function instance.VrComout("/{EX_COPY COUNT=n SORT=1}/") As Integer

                                                                引数

                                                                • COUNT

                                                                  部数を指定します。

                                                                  • n

                                                                    部数

                                                                • SORT

                                                                  部単位で出力するかどうかを指定します。

                                                                  • 1

                                                                    部単位で印刷する

                                                                戻り値

                                                                • 0

                                                                  成功

                                                                • 負数

                                                                  エラーコード

                                                                  エラーコードについては、「エラーコード」を参照してください。

                                                                説明

                                                                • 2部以上印刷する場合に、印刷部数、および部単位で印刷するかどうかを指定します。

                                                                • SORTを省略した場合、部単位では出力されません。

                                                                使用例

                                                                2部を部単位で出力します。

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_COPY COUNT=2 SORT=1}/");

                                                                • ASP/VB

                                                                  svf.VrComout("/{EX_COPY COUNT=2 SORT=1}/")

                                                                • C

                                                                  VrComout(svf, "/{EX_COPY COUNT=2 SORT=1}/");

                                                                • VB.NET

                                                                  svf.VrComout("/{EX_COPY COUNT=2 SORT=1}/")

                                                                VrComout("/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT＝n7}/")

                                                                機能

                                                                バーコードを出力します。Ver. 10.1以降で対応しています。

                                                                書式

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT=n7}/");

                                                                • ASP/VB

                                                                  Function instance.VrComout("/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT=n7}/") As Long

                                                                • C

                                                                  int VrComout(HSVFRCLIENT instance, "/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT=n7}/");

                                                                • VB.NET

                                                                  Function instance.VrComout("/{EX_BARCODE NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 VAL=n5 WITHCHECK=n6 POINT=n7}/") As Integer

                                                                引数

                                                                • NAME

                                                                  データを出力するシートのシート名を指定します。

                                                                  • n1

                                                                    シート名

                                                                • NO

                                                                  データを出力するシートのシート番号を指定します（1～）。

                                                                  • n2

                                                                    シート番号

                                                                • IMAGE

                                                                  バーコードを出力する画像の画像名を指定します。

                                                                  • n3

                                                                    画像名

                                                                    大文字/小文字は区別されます。

                                                                • TYPE

                                                                  バーコードの種類を文字列で指定します。

                                                                  • n4

                                                                    指定する値

                                                                    バーコードの種類

                                                                    説明

                                                                    NW7

                                                                    NW7

                                                                    CODE39

                                                                    Code39

                                                                    チェックディジットを付加する場合は、WITHCHECK=1を設定します。

                                                                    JAN

                                                                    JAN標準、JAN短縮、雑誌バーコード（JAN13＋アドオン）

                                                                    データの桁数によって、次のバーコードが出力されます。

                                                                    • 7桁の場合

                                                                      JAN短縮

                                                                    • 12桁の場合

                                                                      JAN標準

                                                                    • 17桁の場合

                                                                      雑誌バーコード（JAN13＋アドオン）

                                                                    CODE128

                                                                    Code128

                                                                    EAN128

                                                                    EAN128

                                                                    CVS-EAN128

                                                                    コンビニバーコード

                                                                    ITF

                                                                    ITF

                                                                    POSTALCODE

                                                                    郵便番号

                                                                • VAL

                                                                  出力する値を文字列で指定します。

                                                                  • n5

                                                                    値

                                                                    空文字を指定した場合、バーコードは出力されません。

                                                                    バーコードごとに指定できる値が異なります。

                                                                    バーコードの種類

                                                                    指定できる値

                                                                    NW7

                                                                    0～9、記号（-、$、:、/、.、+）

                                                                    Code39

                                                                    0～9、英大文字、記号（-、スペース、.、$、/、+、%）

                                                                    JAN

                                                                    0～9

                                                                    Code128

                                                                    コードセットBとCで表せる文字

                                                                    EAN128

                                                                    コードセットBとCで表せる文字

                                                                    コンビニバーコード

                                                                    0～9

                                                                    ITF

                                                                    0～9

                                                                    郵便番号

                                                                    0～9、英大文字、ハイフン（-）

                                                                • WITHCHECK

                                                                  TYPEにCODE39を指定している場合、CODE39チェック付きが出力されます。省略可能です。省略した場合は、チェックディジットを付加しません。

                                                                  • n6

                                                                    値

                                                                    内容

                                                                    0

                                                                    チェックディジットを付加しない

                                                                    1

                                                                    チェックディジットを付加する

                                                                • POINT

                                                                  TYPEでPOATALCODEを指定している場合、ポイントを指定します。省略可能です。省略時は、10.0となります。

                                                                  • n7

                                                                    ポイント

                                                                    8.0～11.5の値を指定します。

                                                                戻り値

                                                                • 0

                                                                  成功

                                                                • 負数

                                                                  エラーコード

                                                                  エラーコードについては、「エラーコード」を参照してください。

                                                                説明

                                                                • バーコードを出力します。

                                                                • NAMEとNOの両方を指定しない場合、すべてのシートの同名の画像に同じ値が出力されます。

                                                                • NAMEとNOの両方を指定した場合、NOの指定は無視されます。

                                                                • シートの順番はExcel様式ファイルでの並び順に従います。

                                                                • NOに指定するシート番号は、Microsoft Excel上で非表示のシートもカウント対象です。

                                                                • 項目値に半角スペース、カンマ、ダブルクォーテーションのいずれかが含まれる場合、項目値を「"」と「"」で囲み、項目値内の「"」は「""」としてください。

                                                                • POSTALCODEを指定した場合、設計時の大きさは無視され、POINTから算出された大きさで出力されます。印刷領域をはみ出す場合はバーコードの一部が切れて出力されます。

                                                                使用例

                                                                • シート番号「1」の画像「図1」にJAN標準で「123456789012」というデータを出力する場合

                                                                  • Java/C#

                                                                    svf.VrComout("/{EX_BARCODE NO=1 IMAGE=図1 TYPE=JAN VAL=123456789012}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_BARCODE NO=1 IMAGE=図1 TYPE=JAN VAL=123456789012}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_BARCODE NO=1 IMAGE=図1 TYPE=JAN VAL=123456789012}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_BARCODE NO=1 IMAGE=図1 TYPE=JAN VAL=123456789012}/")

                                                                VrComout("/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n5 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/")

                                                                機能

                                                                2次元バーコードを出力します。Ver. 10.1以降で対応しています。

                                                                書式

                                                                • Java/C#

                                                                  int instance.VrComout("/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n5 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/");

                                                                • ASP/VB

                                                                  Function instance.VrComout("/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n5 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/") As Long

                                                                • C

                                                                  int VrComout(HSVFRCLIENT instance, "/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n6 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/");

                                                                • VB.NET

                                                                  Function instance.VrComout("/{EX_BARCODE2D NAME=n1 NO=n2 IMAGE=n3 TYPE=n4 ERRORLEVEL=n5 MODEL=n6 VERSION=n7 GS1=n8 VAL=n9}/") As Integer

                                                                引数

                                                                • NAME

                                                                  データを出力するシートのシート名を指定します。

                                                                  • n1

                                                                    シート名

                                                                • NO

                                                                  データを出力するシートのシート番号を指定します（1～）。

                                                                  • n2

                                                                    シート番号

                                                                • IMAGE

                                                                  2次元バーコードを出力する画像の画像名を指定します。

                                                                  • n3

                                                                    画像名

                                                                    大文字/小文字は区別されます。

                                                                • TYPE

                                                                  2次元バーコードの種類を文字列で指定します。

                                                                  • n4

                                                                    指定する値

                                                                    バーコードの種類

                                                                    QR

                                                                    QRコード

                                                                    DATAMATRIX

                                                                    DataMatrix

                                                                • ERRORLEVEL

                                                                  エラーレベルを指定します。QRコードの場合のみ有効です。省略可能です。省略した場合は、M（15%）が指定されたとして動作します。

                                                                  • n5

                                                                    指定する値

                                                                    内容

                                                                    備考

                                                                    L

                                                                    ７%

                                                                    M

                                                                    15%

                                                                    Q

                                                                    25%

                                                                    H

                                                                    30%

                                                                    MODELでMICROQR（マイクロQR）を選択すると、「30%」は指定できません。

                                                                • MODEL

                                                                  モデル番号を指定します。QRコードの場合のみ有効です。省略可能です。省略時は、MODEL2（モデル2）が指定されたとして動作します。

                                                                  • n6

                                                                    値

                                                                    内容

                                                                    MODEL1

                                                                    モデル1

                                                                    MODEL2

                                                                    モデル2

                                                                    MICROQR

                                                                    マイクロQR

                                                                • VERSION

                                                                  QRコード、およびDataMatrixの型番を指定します。省略可能です。下記の表の「省略時」列に「○」のある値が省略時の値です。GS1規格で出力する場合、「0」を指定することを推奨します。

                                                                  • n7

                                                                    • QRコードモデル1

                                                                    値

                                                                    空文字を指定した場合、バーコードは出力されません。

                                                                    以下の文字を使用する場合は、「>」を使用してください。

                                                                    • タブ文字

                                                                      「>U0009」と指定します。

                                                                    • <CR>

                                                                      「>U000D」と指定します。

                                                                    • <LF>

                                                                      「>U000A」と指定します。

                                                                    • >

                                                                      「>>」と指定します。

                                                                    GS1データを使用する場合は、以下の文字が使用できます。

                                                                    • QRコードの場合

                                                                      • 数字（0～9）

                                                                      • 英字（A～Z、a～z）

                                                                      • 記号（!、"、%、&、'、*、+、,、-、/、.、:、;、<、>、=、?、_ ）

                                                                        「>」は「>>」、「%」は「%%」と指定します。

                                                                      • AIの可変長データの区切り（<FNC1>）

                                                                        「>1」または「%」で指定します。

                                                                    • DataMatrixの場合

                                                                      • 数字（0～9）

                                                                      • 英字（A～Z、a～z）

                                                                      • 記号（!、"、%、&、'、*、+、,、-、/、.、:、;、<、>、=、?、_ ）

                                                                        「>」は「>>」と指定します。

                                                                      • AIの可変長データの区切り（<FNC1>）

                                                                        「>1」または「@1」で指定します。

                                                                      • AIの可変長データの区切り（<GS>）

                                                                        「>U001D」と指定します。

                                                                説明

                                                                • 2次元バーコードを出力します。

                                                                • NAMEとNOの両方を指定しない場合、すべてのシートの同名の画像に同じ値が出力されます。

                                                                • NAMEとNOの両方を指定した場合、NOの指定は無視されます。

                                                                • シートの順番はExcel様式ファイルでの並び順に従います。

                                                                • NOに指定するシート番号は、Microsoft Excel上で非表示のシートもカウント対象です。

                                                                • 項目値に半角スペース、カンマ、ダブルクォーテーションのいずれかが含まれる場合、項目値を「"」と「"」で囲み、項目値内の「"」は「""」としてください。

                                                                使用例

                                                                • シート番号「1」の画像「図1」にQRコードで「ウイングアーク１ｓｔ株式会社」というデータを出力する場合

                                                                  • Java/C#

                                                                    svf.VrComout("/{EX_BARCODE2D NO=1 IMAGE=図1 TYPE=QR VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • ASP/VB

                                                                    svf.VrComout("/{EX_BARCODE2D NO=1 IMAGE=図1 TYPE=QR VAL=ウイングアーク１ｓｔ株式会社}/")

                                                                  • C

                                                                    VrComout(svf, "/{EX_BARCODE2D NO=1 IMAGE=図1 TYPE=QR VAL=ウイングアーク１ｓｔ株式会社}/");

                                                                  • VB.NET

                                                                    svf.VrComout("/{EX_BARCODE2D NO=1 IMAGE=図1 TYPE=QR VAL=ウイングアーク１ｓｔ株式会社}/")
