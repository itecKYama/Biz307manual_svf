                                                    4.1. エクスプローラーの画面構成と操作

                                                    システムの管理と帳票定義の操作は、エクスプローラーで行います。下図に、エクスプローラーの画面を示します。ここでは7つの区画に大別して、概要を説明します。

                                                    （1）ツールバー

                                                    帳票定義の保存先であるディレクトリの作成や編集、帳票定義の作成、様式ファイルのアップロード、各種項目の設定などを行います。

                                                    ツールバーに表示される操作ボタンは、ログインユーザーが所属するグループのロール（詳細は「グループの設定」を参照）が「管理者」か「一般ユーザー」かによって異なります。

                                                    注意

                                                    グループのロールが「一般ユーザー」の場合は、SVF Web Designerサーバーに関する設定や「管理者」向けの操作ボタンは表示されません。

                                                    「管理者」向けツールバー

                                                    項目

                                                    説明

                                                    （a）ディレクトリの作成

                                                    帳票定義を分類、整理するための保管場所（ディレクトリ）を作成します。

                                                    作成したディレクトリはディレクトリツリーに表示されます。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （b）ディレクトリの削除

                                                    作成済みのディレクトリを削除します。

                                                    削除対象のディレクトリに保管されている帳票定義やサブディレクトリも削除されます。

                                                    （c）ディレクトリのコピー（移動）

                                                    作成済みのディレクトリをコピー、または移動します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （d）名前変更

                                                    ディレクトリツリーで選択したディレクトリの名前を変更します。

                                                    （e）ディレクトリ権限設定

                                                    ディレクトリへのアクセス権限をグループごとに設定します。

                                                    詳細は「ディレクトリにアクセス権限を設定する」を参照してください。

                                                    なお、選択しているディレクトリのアクセス権限が、上図（6）の［ディレクトリ権限］に表示されます（ログインユーザーの所属グループのロールが「管理者」以外の場合のみ）。

                                                    （f）新しい帳票定義

                                                    新規に帳票定義を作成します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （g）新しい帳票定義（様式ファイルをアップロード）

                                                    ローカルディスクに保存されているXML様式ファイルやFRM様式ファイルをアップロードし、帳票定義として登録します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （h）様式の一括アップロード

                                                    複数のXML様式ファイルやFRM様式ファイルをまとめてアップロードし、帳票定義として登録します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （i）帳票定義の一括ダウンロード

                                                    選択したディレクトリ内の複数の帳票定義を一括でダウンロードします。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （j）クライアントバックアップから帳票定義を開く

                                                    フォームデザイナーを使用してクライアントマシンに保存したバックアップファイルから帳票定義を開きます。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （k）フォント設定

                                                    SVF Web Designerで使用するフォントを設定します。

                                                    詳細は「フォントの設定」を参照してください。

                                                    （l）システムのアイテム既定値設定

                                                    SVF Web Designerで使用するアイテムの既定値を設定します。

                                                    詳細は「既定値の設定」を参照してください。

                                                    （m）インポート/エクスポート

                                                    設計で使用する各種ファイルのSVF Web Designerサーバーへのアップロード、インポート、およびエクスポートをします。

                                                    詳細は「各種ファイルのアップロード」または「帳票定義のインポートとエクスポート」を参照してください。

                                                    （n）ユーザーとグループ

                                                    SVF Web Designerで作業するユーザーの登録、変更、および削除と、ユーザーが所属するグループの登録、変更、および削除をします。

                                                    グループの詳細は「グループの設定」を、ユーザーの詳細は「ユーザーの設定」参照してください。

                                                    （o）サーバー環境設定

                                                    帳票定義の同時編集、およびログに関する設定をします。

                                                    詳細は「サーバー環境の設定」を参照してください。

                                                    （p）SVF環境設定の起動

                                                    テスト印刷で使用するプリンターの登録や設定をします。

                                                    詳細は「SVF環境設定」を参照してください。

                                                    （q）セッション管理

                                                    ログインユーザーの表示とセッション切断をします。

                                                    詳細は「セッションの管理」を参照してください。

                                                    （r）ユーザープロファイル設定

                                                    ログインユーザーの表示言語や作業環境を設定します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （s）パスワードの変更

                                                    ログインユーザーのパスワードを変更します。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    （t）ユーザー名

                                                    ログインユーザーのユーザー名が表示されます。

                                                    （u）ログアウト

                                                    SVF Web Designerの使用を終了します。

                                                    （2）ディレクトリツリー

                                                    登録済みのディレクトリ、［最近使用した帳票定義］のディレクトリ、および［お気に入り］のディレクトリが表示されます。

                                                    （3）帳票定義リスト

                                                    ディレクトリツリーで選択したディレクトリに保管されている帳票定義のサムネイルが表示されます。

                                                    サムネイル上にマウスカーソルを移動すると、次の操作ボタンが表示されます。

                                                    項目

                                                    説明

                                                    帳票定義を開く

                                                    マウスカーソルで指定した帳票定義を開きます。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    参考

                                                    • 子フォームが埋め込まれた帳票定義の場合、サムネイルに子フォームは表示されません。

                                                      埋め込みフォームの詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    • 帳票イメージが読み込まれた帳票定義の場合、サムネイルに帳票イメージは表示されません。

                                                      帳票イメージの詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    • エラーや警告がある状態で保存された帳票定義、または詳細パネルの［様式の検証］でエラーや警告のメッセージが表示された帳票定義の場合は、そのサムネイルの左上にアイコンが付加されます。

                                                    （4）絞り込み機能

                                                    帳票定義リストに表示される帳票定義をキーワード（帳票定義名）で絞り込みます。

                                                    絞り込むためのキーワードは帳票定義名の一部または全部で、大文字と小文字の区別はありません。

                                                    （5）詳細パネル

                                                    帳票定義リストに表示されている帳票定義を選択すると、その帳票定義の詳細と各種操作ボタンが表示されます。

                                                    詳細は『SVF Web Designer帳票作成ガイド』を参照してください。

                                                    項目

                                                    説明

                                                    選択した帳票定義に対して各種操作を行います。

                                                    項目

                                                    説明

                                                    （a）帳票定義の削除

                                                    帳票定義を削除します。

                                                    （b）帳票定義のコピー（移動）

                                                    帳票定義をコピー、または移動します。

                                                    （c）名前変更

                                                    帳票定義の名前を変更します。

                                                    （d）帳票定義を開く（様式の言語を変更）

                                                    様式の言語を変更して帳票定義を開きます。

                                                    （e）帳票定義の変更履歴

                                                    指定した日時の状態に帳票定義を復元します。

                                                    （f）帳票定義のダウンロード

                                                    帳票定義をローカルディスクにダウンロードします。

                                                    （g）お気に入りの登録/解除

                                                    帳票定義を［お気に入り］に登録、または［お気に入り］から解除します。

                                                    参考

                                                    • ［最近使用した帳票定義］の帳票定義を選択した場合は、上記ボタンは表示されません。

                                                    • ［お気に入り］の帳票定義を選択した場合は、（d）～（g）の操作ボタンのみ表示されます。

                                                    詳細

                                                    選択した帳票定義のパス、［様式の言語］、［更新日時］、［更新者］、および［コメント］が表示されます。

                                                    様式の検証

                                                    選択した帳票定義の様式ファイルを検証します。

                                                    検証の結果、エラーや警告がある場合はメッセージが表示されます。

                                                    参考

                                                    ［最近使用した帳票定義］以外で表示される帳票定義リストでは、帳票定義の複数選択が可能です。

                                                    帳票定義を複数選択した場合、詳細パネルには最後に選択した帳票定義の詳細が表示されます。

                                                    （6）ディレクトリ権限

                                                    ログインユーザーが所属するグループのロールが「管理者」以外の場合に、ディレクトリツリーで選択したディレクトリへのアクセス権限が表示されます。

                                                    アクセス権限の詳細は「ディレクトリにアクセス権限を設定する」を参照してください。

                                                    参考

                                                    • ディレクトリツリーで次のディレクトリを選択すると、［ディレクトリ権限］には何も表示されません。

                                                      • ［最近使用した帳票定義］

                                                      • ［お気に入り］

                                                    • ロールが「管理者」以外の場合、［ディレクトリ権限］は次のダイアログにも表示されます。

                                                      • ［ディレクトリの選択］

                                                      • ［合成アイテムの選択］

                                                      • ［アイテムの合成］

                                                      • ［名前を付けて帳票定義を保存］

                                                      • ［開く］

                                                      • ［カラーパレットの読み込み］

                                                      • ［カラーパレットの保存］

                                                    （7）ステータスバー

                                                    選択しているディレクトリのパスが表示されます。
