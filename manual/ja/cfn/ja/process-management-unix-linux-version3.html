                                4.4. プロセスの管理（UNIX/Linux版）

                                プロセスの起動、終了方法には、単独で起動する方法と、SVF実行部製品と同時に起動する方法の2つがあります。

                                注意

                                すべてのコマンドはインストールしたユーザー（一般ユーザー）で実行してください。

                                単独での起動

                                プロセスの起動、終了などは、シェルスクリプトSvfJavaConnectServerに下表のような引数を付けて実行します。

                                動作

                                引数

                                コマンド例

                                起動

                                start

                                $FIT_PRODUCTS_BASE/bin/SvfJavaConnectServer start

                                終了

                                stop

                                $FIT_PRODUCTS_BASE/bin/SvfJavaConnectServer stop

                                再起動

                                restart

                                $FIT_PRODUCTS_BASE/bin/SvfJavaConnectServer restart

                                動作状態の表示

                                status

                                $FIT_PRODUCTS_BASE/bin/SvfJavaConnectServer status

                                SVF実行部製品との同時起動

                                SVF実行部製品の起動、終了に使用する以下のシェルスクリプトを使用して、SVF実行部製品と同時に起動、終了することができます。

                                動作

                                シェルスクリプト

                                コマンド例

                                起動

                                svf_startup.sh

                                $FIT_PRODUCTS_BASE/bin/svf_startup.sh

                                終了

                                svf_shutdown.sh

                                $FIT_PRODUCTS_BASE/bin/svf_shutdown.sh

                                「svf_startup.sh」と「svf_shutdown.sh」で起動、終了を行うには、同ディレクトリの「.startup_products」を以下のように編集します。

                                USE_SVF_JAVA_CONNECT_SERVER=1

                                設定を変更すると、以下のとおりの動作となります。

                                • svf_startup.shの実行で「SvfJavaConnectServer start」が実行されます。

                                • svf_shutdown.shの実行で「SvfJavaConnectServer stop」が実行されます。

                                参考

                                同一コンピューターにインストールされている以下の製品については、「svf_startup.sh」と「svf_shutdown.sh」で起動と終了を行うかを「.startup_products」を編集することで制御できます。

                                • SVF 実行部製品 Ver. 10

                                • Report Director Enterprise Ver. 10

                                • Universal Connect/X Ver. 10

                                • Java版SVF実行部接続用ランタイム

                                  • SVF Connect for Java API Ver. 10から接続

                                  • SVF Connect for .NET Framework API Ver. 10から接続

                                  • SVF Connect for ASP/COM API Ver. 10から接続

                                • SVF for Oracle E-Business Suite Ver. 10

                                以下のパラメーターの値を編集することで、各製品のプロセスの起動、終了を制御します。

                                • 0　「svf_startup.sh」と「svf_shutdown.sh」で起動、終了しない

                                • 1　「svf_startup.sh」と「svf_shutdown.sh」で起動、終了する
