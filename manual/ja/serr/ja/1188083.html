      コマンド関連エラーコード

      エラー内容および原因と対処方法について説明します。

      エラーコード

      エラー内容

      原因と対処方法

      -8000

      例外が発生しました。

      • 原因

        何らかの例外が発生しています。

      • 対処方法

        ログによる詳細確認が必要です。

      -8001

      ファイルの作成に失敗しました。

      • 原因

        プリンター情報、ユーザー情報、サーバー情報、または全文検索用フィールド名のエクスポート時にファイル作成に失敗しています。

      • 対処方法

        ディスク残量やディレクトリ、またはファイルの権限に注意してください。

      -8005

      グループ名に使用できない文字が含まれています。

      • 原因

        グループ名に使用できない文字「,（カンマ）」が使用されています。

      • 対処方法

        グループ名には「,（カンマ）」を使用しないでください。

      -8006

      パスワード桁数の制限を満たしていません。

      • 原因

        ［パスワード桁数の制限］で［最小桁数］より小さいか、［最大桁数］より大きい桁数のパスワードが設定されています。

      • 対処方法

        パスワードを「最小桁数」以上「最大桁数」以内にしてください。

      -8010

      サーバー名の指定がありません。

      • 原因

        サーバープリンターインポート時にサーバー名の指定がありません。

      • 対処方法

        サーバー名の指定を確認してください。

      -8011

      プリンター名が重複しています。

      • 対処方法

        プリンター名を確認してください。

      -8012

      指定プリンター機種が見つかりません。

      • 対処方法

        プリンター機種を確認してください。

      -8013

      ファイルの書き込みに失敗しました。

      • 対処方法

        ディスク残量やディレクトリ、またはファイルの権限に注意してください。

      -8014

      CSVデータの作成に失敗しました。

      • 対処方法

        ディスク残量やディレクトリ、またはファイルの権限に注意してください。

      -8015

      パラメーターファイルの出力に失敗しました。

      • 対処方法

        ディスク残量やディレクトリ、またはファイルの権限に注意してください。

      -8016

      パラメーターファイルの取得に失敗しました。

      • 対処方法

        ログによる詳細確認が必要です。

      -8017

      Schema.propertiesの読み込みに失敗しました。

      • 原因

        Schema.propertiesの読み込みに失敗しました。

      • 対処方法

        Schema.propertiesファイルの内容が正しいか確認してください。

      -8018

      RDサーバーへの接続に失敗しました。

      • 原因

        RDサーバーとの接続に失敗しました。

      • 対処方法

        RDサーバーが起動しているか確認してください。

      -8019

      RDサーバーと接続中にIOエラーが発生しました。

      • 原因

        RDサーバーとの通信中にエラーが発生しました。

      • 対処方法

        RDサーバーが起動しているか確認してください。

      -8020

      プリンターが動作中です。

      • 原因

        プリンターは動作中です。

      • 対処方法

        動作中のプリンターがあります。動作完了後にコマンドを再度実行してください。

      -8021

      プリンターグループ名の指定がありません。

      • 原因

        プリンターグループ名が指定されていません。

      • 対処方法

        プリンターグループの指定を確認してください。

      -8022

      プリンターグループ名が重複しています。

      • 原因

        プリンターグループ名が重複しています。

      • 対処方法

        プリンターグループ名を確認してください。

      -8023

      指定されたプリンターが存在しません。

      • 原因

        指定されたプリンターが存在しません。

      • 対処方法

        プリンターの指定を確認してください。

      -8024

      指定されたプリンターグループが存在しません。

      • 原因

        指定されたプリンターグループが存在しません。

      • 対処方法

        プリンターグループ名を確認してください。

      -8025

      プリンターの優先順位が重複しています。

      • 原因

        プリンターの優先順位が重複しています。

      • 対処方法

        プリンターグループ内のプリンターの優先順位を確認してください。

      -8031

      RDサーバーの振り分け方法が一致していません。

      • 原因

        RDサーバーの振り分け方法に異なる値を指定しています。

      • 対処方法

        RDサーバーの振り分け方法は同じ値を指定してください。

      -8032

      RDサーバーの振り分け順が重複しています。

      • 原因

        RDサーバーの振り分け順が重複しています。

      • 対処方法

        RDサーバーの振り分け順は連番となる様に指定してください。

      -8033

      RDサーバーの振り分け方法が不正です。

      • 原因

        RDサーバーの振り分け方法に0、1以外を指定しています。

      • 対処方法

        RDサーバーの振り分け方法には、0または1を指定してください。

      -8034

      RDサーバーのサーバーステータスが不正です。

      • 原因

        RDサーバーのサーバーステータスに0、1以外を指定しています。

      • 対処方法

        RDサーバーのサーバーステータスには、0または1を指定してください。

      -8051

      Active Directory連携のドメインにユーザーは追加できません。

      • 原因

        Active Directory連携ドメインにユーザーは追加できません。

      -8052

      Active Directory連携で取得したユーザーを更新するための入力データが不足しています。

      • 原因

        Active Directory連携で取得したユーザーに対するインポートで、「GroupName」キーの設定が含まれていません。

      • 対処方法

        「GroupName」キーを設定に含め、存在するグループ名を指定してください。

      -8053

      対象のドメインが同期処理中のためユーザーを登録することができません。

      • 原因

        インポート対象のユーザーが所属するドメインがActive Directoryに対する同期処理中のためユーザー情報を登録することはできません。

      • 対処方法

        Active Directoryに対する同期処理完了後、最新の情報を確認してから、ユーザー情報のインポートを行ってください。

      -8054

      対象のドメインが同期処理中のためグループを登録することができません。

      • 原因

        インポート対象のグループが所属するドメインがActive Directoryに対する同期処理中のためグループを登録することはできません。

      • 対処方法

        Active Directoryに対する同期処理完了後、最新の情報を確認してから、グループのインポートを行ってください。

      -8055

      Active Directoryから取得したユーザーは削除できません。

      • 原因

        Active Directory連携で取得したユーザーは削除できません。

      • 対処方法

        操作は無効です。

      -8056

      Active Directoryから取得したグループは削除できません。

      • 原因

        Active Directory連携で取得したグループは削除できません。

      • 対処方法

        操作は無効です。

      -8057

      指定されたドメインが同期処理中のため削除を実行することができませんでした。

      • 原因

        削除対象のグループが所属するドメインがActive Directoryに対する同期処理中のためグループを削除することはできません。

      • 対処方法

        Active Directoryに対する同期処理完了後、最新の情報を確認してから、グループの削除を行ってください。
