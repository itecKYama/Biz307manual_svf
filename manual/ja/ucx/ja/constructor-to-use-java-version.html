                                                                                                                              8.3.3. 使用するコンストラクター（Java版）

                                                                                                                              UCXSingleをJavaから実行する際に使用できるコンストラクターは次の3種類があります。

                                                                                                                              • UCXSingle()

                                                                                                                              • UCXSingle(String, int, String, String, String)

                                                                                                                              • UCXSingle(String, String, int, String, String, String)

                                                                                                                              UCXSingle()

                                                                                                                              機能

                                                                                                                              Universal Connect/Xサーバーに接続するためのインスタンスを構築します。

                                                                                                                              書式

                                                                                                                              public UCXSingle()

                                                                                                                              引数

                                                                                                                              なし。接続先には次の設定が適用されます。

                                                                                                                              • host

                                                                                                                                127.0.0.1

                                                                                                                              • port

                                                                                                                                44080

                                                                                                                              参考

                                                                                                                              接続先を変更するには、次の関数を使用してください。

                                                                                                                              • setUniConXServer(String, int)

                                                                                                                              • setUniConXServer(String, String, int)

                                                                                                                              • setUniConXServer(String, String, int, Properties)

                                                                                                                              UCXSingle(String, int, String, String, String)

                                                                                                                              機能

                                                                                                                              指定されたUniversal Connect/Xサーバーに接続するためのインスタンスを構築します。

                                                                                                                              書式

                                                                                                                              public UCXSingle(String host, int port, String settingName, String sourceName, String resultFileName)

                                                                                                                              引数

                                                                                                                              • host

                                                                                                                                Universal Connect/Xサーバーのホスト名またはIPアドレス

                                                                                                                              • port

                                                                                                                                Universal Connect/Xサーバーのポート番号

                                                                                                                              • settingName

                                                                                                                                動作設定のJob ID

                                                                                                                                動作設定で［サブ Job ID］を指定している場合は、親ジョブの動作設定のJobIDのみ指定します。［サブ Job ID］の指定については、「［ジョブ］の操作と設定」を参照してください。

                                                                                                                              • sourceName

                                                                                                                                データファイル名

                                                                                                                                動作設定で［サブ Job ID］を指定している場合は、親ジョブのデータファイル名の後に、［サブ Job ID］で指定したジョブのデータファイル名を、カンマで区切って指定します。［サブ Job ID］の指定については、「［ジョブ］の操作と設定」を参照してください。

                                                                                                                                空文字列を指定した場合、動作設定で指定したデータファイルが適用されます。

                                                                                                                              • resultFileName

                                                                                                                                SVF製品により生成される出力ファイルを、UCXSingleで指定したファイル名で受け取ります。

                                                                                                                                空文字列を指定した場合に、SVFファイル機種に出力するとUniversal Connect/Xサーバー側に出力ファイルが生成されます。

                                                                                                                              UCXSingle(String, String, int, String, String, String)

                                                                                                                              機能

                                                                                                                              Universal Connect/X中継サーバーに接続するためのインスタンスを構築します。

                                                                                                                              ポート番号にUniversal Connect/Xサーバーのポート番号を指定した場合は、doTransaction()関数においてプロトコルの例外が発生する場合があります。

                                                                                                                              この関数を使用する場合は、中継サーバーのポート番号を指定してください。

                                                                                                                              書式

                                                                                                                              public UCXSingle(String protocol, String host, int port, String settingName, String sourceName, String resultFileName)

                                                                                                                              引数

                                                                                                                              • protocol

                                                                                                                                通信プロトコル（httpまたはhttps）

                                                                                                                              • host

                                                                                                                                Universal Connect/X中継サーバー（Tomcat）のホスト名またはIPアドレス

                                                                                                                              • port

                                                                                                                                Universal Connect/X中継サーバー（Tomcat）のポート番号

                                                                                                                              • settingName

                                                                                                                                動作設定のJob ID

                                                                                                                                動作設定で［サブ Job ID］を指定している場合は、親ジョブの動作設定のJobIDのみ指定します。［サブ Job ID］の指定については、「［ジョブ］の操作と設定」を参照してください。

                                                                                                                              • sourceName

                                                                                                                                データファイル名

                                                                                                                                動作設定で［サブ Job ID］を指定している場合は、親ジョブのデータファイル名の後に、［サブ Job ID］で指定したジョブのデータファイル名を、カンマで区切って指定します。［サブ Job ID］の指定については、「［ジョブ］の操作と設定」を参照してください。

                                                                                                                                空文字列を指定した場合、動作設定で指定したデータファイルが適用されます。

                                                                                                                              • resultFileName

                                                                                                                                SVF製品により生成される出力ファイルを、UCXSingleで指定したファイル名で受け取ります。

                                                                                                                                空文字列を指定した場合に、SVFファイル機種に出力するとUniversal Connect/Xサーバー側に出力ファイルが生成されます。
