                                                                                                                              • XML

                                                                                                                                文書名

                                                                                                                              説明

                                                                                                                              スプールする文書データに文書名を指定します。

                                                                                                                              また、PDF機種で作成されたPDF文書のプロパティにタイトルを指定します。

                                                                                                                              • CSV

                                                                                                                                VrSetDocName2=仕訳日記帳

                                                                                                                                <document name="仕訳日記帳">

                                                                                                                              • XML

                                                                                                                                <document username="user">

                                                                                                                              引数

                                                                                                                              • user

                                                                                                                                ユーザー名

                                                                                                                              説明

                                                                                                                              スプールする文書データにユーザー名を指定します。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrSetUserName=Wingarc

                                                                                                                              • XML

                                                                                                                                <document username="Wingarc">

                                                                                                                              VrSetForm

                                                                                                                              機能

                                                                                                                              XML様式ファイルの指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrSetForm=XMLName,mode

                                                                                                                              • XML

                                                                                                                                <form file="XMLName" mode="mode">

                                                                                                                              引数

                                                                                                                              • XMLName

                                                                                                                                XML様式ファイル名（パス名は省略可）

                                                                                                                              • mode

                                                                                                                                • 4: ソートしない

                                                                                                                                • 5: ソートする

                                                                                                                              説明

                                                                                                                              実行時のXML様式ファイルを指定します。Ver.10.3以降では、SVF Cloudを使用して出力する場合は、SVF Cloud Excel Designerで作成したExcel様式ファイルおよび、SVF Cloud Word Designerで作成したWord様式ファイルも指定できます。

                                                                                                                              動作設定で指定されている様式ファイル名の設定ではなく、ここで指定されたXMLNameで実行します。SVF Cloud Excel Designerで作成したExcel様式ファイルを指定する場合、「<パス>/[<様式ファイル名>]<シート名>」の形式で指定する必要があります。

                                                                                                                              例 1. SVF Cloud Excel Designerで作成したExcel様式ファイルの指定例
                                                                                                                              form/Sample/[sample_ja.xlsx]Sheet1


                                                                                                                              パス名を省略する場合の参照先は、ジョブ設定の［実行様式ファイル検索パス］の設定に従います。［実行様式ファイル検索パス］の設定方法については、「［ジョブ］の操作と設定」の 「実行様式ファイル検索パス」を参照してください。

                                                                                                                              また、modeは動作設定画面の出力モードの設定で、4か5のどちらかを指定します。4の場合は「ソートしない」、5の場合は「ソートする」で設定されます。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrSetForm=c:¥svf¥sample_ja.xml,5

                                                                                                                              • XML

                                                                                                                                <form file="c:¥svf¥sample_ja.xml" mode="5">

                                                                                                                              VrSetPrinter

                                                                                                                              機能

                                                                                                                              出力先の指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrSetPrinter=printer,port

                                                                                                                              • XML

                                                                                                                                <document printer="printer" port="port">

                                                                                                                              引数

                                                                                                                              • printer

                                                                                                                                プリンター機種名

                                                                                                                              • port

                                                                                                                                プリンター名

                                                                                                                              説明

                                                                                                                              動作設定で指定されている出力先の設定ではなく、ここで指定されたprinter（プリンター機種名）とport（プリンター名）に出力します。「printer」は指定しなくても「port」から自動設定されますので、通常指定する必要はありません。Ver. 10.3以降、SVF Cloud接続設定を指定していないジョブでは、出力先を複数指定できます。複数の出力先を指定する場合は、セパレーター「|」で区切って指定してください。プリンター名は3つまで指定できます。SVF製品により生成される出力ファイルを、UCXSingleで指定したファイル名で受け取るように設定して出力する場合、ファイル出力のプリンターは1つのみ指定できます。

                                                                                                                              SVF Cloud Excel Designerで作成したExcel様式ファイルを使用して出力する場合は「EXCEL」を、SVF Cloud Word Designerで作成したWord様式ファイルを使用して出力する場合は「WORD」を指定してください。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrSetPrinter=,PDF

                                                                                                                              • XML

                                                                                                                                <document printer="" port="PDF">

                                                                                                                              注意

                                                                                                                              印刷実行とファイル出力をこの関数で切り替えて行う場合は、必ず「OutputSpoolMode（CSV）、outputspoolmode（XML）」を併用するか、動作設定で［スプールモード］を「環境設定に従う」に設定してください。また、ファイルを作成する場所やファイル名を指定したい場合は、「VrSetSpoolFileName2（CSV）、file（XML）」を併用してください。

                                                                                                                              VrAdjustd2

                                                                                                                              機能

                                                                                                                              印字位置調整（ドット単位）の設定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrAdjustd2=x,y

                                                                                                                              • XML

                                                                                                                                <form adjustd2="x,y">

                                                                                                                              引数

                                                                                                                              • x

                                                                                                                                左右調整値（正=右方向、負=左方向）

                                                                                                                              • y

                                                                                                                                上下調整値（正=下方向、負=上方向）

                                                                                                                              説明

                                                                                                                              印字位置をドット単位で移動します。設定値は、印刷実行処理の1ジョブの間で有効です。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrAdjustd2=10,15

                                                                                                                              • XML

                                                                                                                                <form adjustd2="10,15">

                                                                                                                              VrAdjustm2

                                                                                                                              機能

                                                                                                                              印字位置調整（1/10ミリ単位）の設定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrAdjustm2=x,y

                                                                                                                              • XML

                                                                                                                                <form adjustm2="x,y">

                                                                                                                              引数

                                                                                                                              • x

                                                                                                                                左右調整値（正=右方向、負=左方向）

                                                                                                                              • y

                                                                                                                                上下調整値（正=下方向、負=上方向）

                                                                                                                              説明

                                                                                                                              印字位置を1/10ミリ単位で移動します。設定値は、印刷実行処理の1ジョブの間で有効です。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrAdjustm2=10,15

                                                                                                                              • XML

                                                                                                                                <form adjustm2="10,15">

                                                                                                                              VrSetCalcMode

                                                                                                                              機能

                                                                                                                              10進演算ライブラリサポートの指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrSetCalcMode=mode

                                                                                                                              • XML

                                                                                                                                <form calc="mode">

                                                                                                                              引数

                                                                                                                              • mode

                                                                                                                                • 0: DOUBLE型演算（デフォルト）

                                                                                                                                • 1: 多倍精度10進浮動小数点型演算

                                                                                                                              説明

                                                                                                                              15桁以上の数値データを扱う場合に指定します。この関数を使用することで、最大33バイトの数値データを演算できます。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrSetCalcMode=1

                                                                                                                              • XML

                                                                                                                                <form calc="1">

                                                                                                                              OutputSpoolMode

                                                                                                                              機能

                                                                                                                              スプールモードの指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                OutputSpoolMode=mode

                                                                                                                              • XML

                                                                                                                                <document outputspoolmode="mode">

                                                                                                                              引数

                                                                                                                              • mode

                                                                                                                                • 1: 印刷を行う

                                                                                                                                • 2: ファイル出力を行う

                                                                                                                                • 3: 圧縮してファイル出力を行う

                                                                                                                                • 4: 環境設定に従う

                                                                                                                              説明

                                                                                                                              環境設定上で指定されているスプールモードの設定ではなく、ここで指定されたスプールモードに従って出力します。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                OutputSpoolMode=3

                                                                                                                              • XML

                                                                                                                                <document outputspoolmode="3">

                                                                                                                              注意

                                                                                                                              • SVF for Web/Clientを利用している場合は、この関数を指定してファイル圧縮をするか、動作設定で［スプールモード］を［ファイルを圧縮して出力する］に設定してください。

                                                                                                                              • ファイル出力するプリンター機種を選択している場合は、［印刷する］に指定をしても動作しません。

                                                                                                                              VrSetSpoolFileName2

                                                                                                                              機能

                                                                                                                              出力ファイル名の指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrSetSpoolFileName2=PDFFileName

                                                                                                                              • XML

                                                                                                                                <document file="PDFFileName">

                                                                                                                              引数

                                                                                                                              • PDFFileName

                                                                                                                                作成するファイル名およびパス

                                                                                                                              説明

                                                                                                                              動作設定で指定されている出力ファイル名ではなく、ここで指定されたPDFFileNameでファイルを作成します。Ver. 10.3以降、VrSetPrinter関数で複数の出力先を指定した場合は、セパレーター「|」で区切って出力先の指定と同じ順番で、ファイル名とその作成場所を指定します。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrSetSpoolFileName2=c:¥svf¥abc.pdf

                                                                                                                              • XML

                                                                                                                                <document file="c:¥svf¥abc.pdf">

                                                                                                                              注意

                                                                                                                              • パスを指定せず、ファイル名のみを指定した場合には、データファイルが存在しているディレクトリにファイルが作成されます。

                                                                                                                              • ファイル出力処理以外のJOBを実行する場合は、使用できません。

                                                                                                                              VrCopy

                                                                                                                              機能

                                                                                                                              出力部数の指定

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrCopy=n

                                                                                                                              • XML

                                                                                                                                <form copies="n">

                                                                                                                              引数

                                                                                                                              • n

                                                                                                                              VrComout=DVUN n

                                                                                                                              機能

                                                                                                                              ファイルを分割して出力する場合の、1ファイル分のページ数の指定（Ver. 10.1で対応）

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrComout=DVUN parameter

                                                                                                                              • XML

                                                                                                                                <document vrcomout="DVUN parameter">

                                                                                                                              引数

                                                                                                                              • n

                                                                                                                                分割するページ数を指定します。

                                                                                                                              説明

                                                                                                                              印刷データを分割してファイル出力する場合に、1ファイル分として出力するページ数を指定します。指定したページ数を超えると、別ファイルとして出力します。「0」を指定した場合、ファイルは分割されません。

                                                                                                                              プリンター機種「Adobe PostScript」と「PDF」で使用できます。SVF製品により生成される出力ファイルを、UCXSingleで指定したファイル名で受け取るように設定して出力する場合は、使用できません。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrComout=DVUN 10

                                                                                                                              • XML

                                                                                                                                <document vrcomout="DVUN 10">

                                                                                                                              VrComout=DVFX Postfix

                                                                                                                              機能

                                                                                                                              ファイルを分割して出力する場合に、ファイル名の末尾（拡張子の直前）にどのように番号を付加するかの指定（Ver. 10.1で対応）

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrComout=DVFX parameter

                                                                                                                              • XML

                                                                                                                                <document vrcomout="DVFX parameter">

                                                                                                                              引数

                                                                                                                              • n

                                                                                                                                ファイル名の末尾（拡張子の直前）にどのように番号を付加するかを指定します。

                                                                                                                                値

                                                                                                                                説明

                                                                                                                                <Z>

                                                                                                                                出力ファイルの分割順に0から連番を付加

                                                                                                                                <C>

                                                                                                                                出力ファイルの分割順に1から連番を付加

                                                                                                                                <P>

                                                                                                                                分割した時点のページ数を付加

                                                                                                                              説明

                                                                                                                              印刷データを分割してファイル出力する場合に、ファイル名が重複しないように、各ファイルのファイル名の末尾（拡張子の直前）に付加する文字を指定します。

                                                                                                                              VrComout=DVFX Postfix関数を指定しないでファイルを分割して出力した場合、自動的に引き数で「Z」が指定された状態となり、最初に出力されるファイルのファイル名の末尾に「0」を付加します。以降に出力されるファイルのファイル名の末尾には「1」からの連番が付加されます。

                                                                                                                              プリンター機種「Adobe PostScript」と「PDF」で使用できます。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrComout=DVFX <C>

                                                                                                                              • XML

                                                                                                                                <document vrcomout="DVFX &lt;C&gt;">

                                                                                                                              VrComout=BNFN FileName

                                                                                                                              機能

                                                                                                                              ファイルを分割して出力する場合に使用する、バナー様式ファイルの指定（Ver. 10.1で対応）

                                                                                                                              関数

                                                                                                                              • CSV

                                                                                                                                VrComout=BNFN parameter

                                                                                                                              • XML

                                                                                                                                <document vrcomout="BNFN parameter">

                                                                                                                              引数

                                                                                                                              • n

                                                                                                                                バナー様式ファイルを指定します。

                                                                                                                              説明

                                                                                                                              印刷データを分割してファイル出力するときに、各ファイルの先頭ページにバナーを出力できます。バナーを出力する場合は、SVF設計部で別途作成したバナー様式ファイルを指定します。

                                                                                                                              VrComout("/{BNFN FileName}/")関数を指定しない場合は、ファイルを分割して出力してもバナーは出力されません。

                                                                                                                              バナーとバナー様式ファイルについての詳細は『SVF帳票出力製品管理ガイド』の「バナーの出力について」を参照してください。

                                                                                                                              プリンター機種「Adobe PostScript」と「PDF」で使用できます。

                                                                                                                              使用例

                                                                                                                              • CSV

                                                                                                                                VrComout=BNFN C:\form\banner.xml

                                                                                                                              • XML

                                                                                                                                <document vrcomout="BNFN C:\\form\\banner.xml">
