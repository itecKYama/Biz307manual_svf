                                                                  5.1. 共通関数

                                                                  Word様式ファイル使用時に指定できる共通関数のうち、指定方法がWord様式ファイル固有である関数について説明します。

                                                                  • VrSetForm

                                                                  • VrEndPage

                                                                  • VrsOut

                                                                  VrSetForm

                                                                  機能

                                                                  印刷に用いるWord様式ファイルと出力のモードを指定します。

                                                                  書式

                                                                  • Java/C#

                                                                    int instance.VrSetForm(String FormName, int Mode);

                                                                  • ASP/VB

                                                                    Function instance.VrSetForm(FormName As String, Mode As Integer) As Long

                                                                  • C

                                                                    int VrSetForm(HSVFRCLIENT instance, char *FormName, int Mode);

                                                                  • VB.NET

                                                                    Function instance.VrSetForm(FormName As String, Mode As Integer) As Integer

                                                                  引数

                                                                  • FormName

                                                                    Word様式ファイル名

                                                                  • Mode

                                                                    出力モード

                                                                    • 21

                                                                      Word様式モード

                                                                  戻り値

                                                                  • 0

                                                                    成功

                                                                  • 負数

                                                                    エラーコード

                                                                    エラーコードについては、「エラーコード」を参照してください。

                                                                  説明

                                                                  • SVFで使用する関数のほとんどは、VrSetForm関数で指定されたWord様式ファイルに対して機能します。

                                                                  • Word様式ファイルは、基本的にフルパスで指定します。

                                                                  • Word様式ファイルを使用する場合、出力モードは「21」で固定です。

                                                                  • Word様式ファイルを使用する場合、VrSetForm関数は1回だけ指定できます。複数のWord様式ファイルを一度に処理することはできません。

                                                                  使用例

                                                                  • Word様式ファイル「sample.docx」を使用する場合

                                                                    • Java/C#

                                                                      svf.VrSetForm("sample.docx", 21);

                                                                    • ASP/VB

                                                                      svf.VrSetForm("sample.docx", 21)

                                                                    • C

                                                                      VrSetForm(svf, "sample.docx", 21);

                                                                    • VB.NET

                                                                      svf.VrSetForm("sample.docx", 21)

                                                                  • 関数使用例

                                                                    svf.VrInit();
svf.VrSetPrinter("", "PDF");
svf.VrSetSpoolFileName2("c:\\pdf\\sample.pdf");
svf.VrSetForm("C:\\word\\sample.docx", 21); //Word様式ファイルを指定
svf.VrsOut("会社名", "ウイングアーク株式会社");
svf.VrEndPage();
svf.VrQuit();

                                                                  VrEndPage

                                                                  機能

                                                                  データ出力の完了をSVFに指示します。

                                                                  書式

                                                                  • Java/C#

                                                                    int instance.VrEndPage();

                                                                  • ASP/VB

                                                                    Function instance.VrEndPage() As Long

                                                                  • C

                                                                    int VrEndPage(HSVFRCLIENT instance);

                                                                  • VB.NET

                                                                    Function instance.VrEndPage() As Integer

                                                                  引数

                                                                  なし

                                                                  戻り値

                                                                  • 0

                                                                    成功

                                                                  • 負数

                                                                    エラーコード

                                                                    エラーコードについては、「エラーコード」を参照してください。

                                                                  説明

                                                                  • Word様式モード（VrSetForm関数のモードが「21」）の場合にデータ出力の完了をSVFに指示します。

                                                                  • VrEndpageは複数指定できます。複数指定する場合のAPI関数の指定については「設計できる帳票」を参照してください。

                                                                  使用例

                                                                  • Java/C#

                                                                    svf.VrEndPage();

                                                                  • ASP/VB

                                                                    svf.VrEndPage()

                                                                  • C

                                                                    VrEndPage(svf);

                                                                  • VB.NET

                                                                    svf.VrEndPage()

                                                                  VrsOut

                                                                  機能

                                                                  出力するデータを指定します。

                                                                  書式

                                                                  • Java/C#

                                                                    int instance.VrsOut(String Field_Name, String data);

                                                                  • ASP/VB

                                                                    Function instance.VrsOut(Field_Name As String, data As String) As Long

                                                                  • C

                                                                    int VrsOut(HSVFRCLIENT instance, char *Field_Name, char *data);

                                                                  • VB.NET

                                                                    Function instance.VrsOut(Field_Name As String, data As String) As Integer

                                                                  引数

                                                                  • Field_Name

                                                                    Word様式ファイルに設定したMergefield名を指定します。

                                                                  • data

                                                                    出力するデータを指定します。

                                                                  戻り値

                                                                  • 0

                                                                    成功

                                                                  • 負数

                                                                    エラーコード

                                                                    エラーコードについては、「エラーコード」を参照してください。

                                                                  説明

                                                                  • データをMerge fieldに渡します。同一様式ファイル内に同じフィールド名のMerge fieldが存在する場合は、同一のデータを出力します。

                                                                  • Word様式ファイルでは、繰り返しフィールドに対応していないため、VrsOutnは指定できません。

                                                                  使用例

                                                                  • 「会社名」フィールドに「ウイングアーク株式会社」というデータを出力する場合

                                                                    • Java/C#

                                                                      svf.VrsOut("会社名", "ウイングアーク株式会社");

                                                                    • ASP/VB

                                                                      svf.VrsOut("会社名", "ウイングアーク株式会社")

                                                                    • C

                                                                      VrsOut(svf, "会社名", "ウイングアーク株式会社");

                                                                    • VB.NET

                                                                      svf.VrsOut("会社名", "ウイングアーク株式会社")
