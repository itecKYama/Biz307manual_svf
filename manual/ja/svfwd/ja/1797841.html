                                                                  3.4. フォントの設定

                                                                  Word様式ファイルでのフォント設定について説明します。

                                                                  使用できるフォント

                                                                  Word様式ファイルにはMicrosoft Wordで使用できるすべてのフォントを設定できますが、出力時に正しく表示するためにはSVF実行部製品で使用できるフォントである必要があります。SVF実行部製品で使用できるフォントの詳細については、『SVF帳票出力製品管理ガイド』のフォントの扱いについての説明を参照してください。

                                                                  フォント設定の優先順位

                                                                  Microsoft Wordでは、テーマ、スタイルおよび文字列にフォントを設定できます。その場合のフォントの設定の優先順位を次に示します。

                                                                  優先順位

                                                                  Microsoft Wordでの設定

                                                                  説明

                                                                  1

                                                                  文字列へのフォントの設定

                                                                  Microsoft Wordで文字列に直接設定するフォント情報です。

                                                                  2

                                                                  スタイルの設定

                                                                  Microsoft Wordのスタイルに設定するフォント情報です。スタイルを適用した段落に適用されます。

                                                                  3

                                                                  テーマの設定

                                                                  Microsoft Wordのテーマに設定するフォント情報です。文書全体に適用されます。

                                                                  フォントの設定

                                                                  Microsoft Wordのフォント設定について、Word様式ファイルでの使用可否は次のとおりです。

                                                                  Word様式ファイルで使用できるものには、使用可否欄に「○」を、制限事項があるものは「△」を、使用できないものには「×」を記しています。
