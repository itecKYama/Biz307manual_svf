                                                                  6. Universal Connect/Xの設定項目と関数

                                                                  Word様式ファイルを使用して帳票を出力する場合、Universal Connect/Xの設定項目やデータファイルで使用できる関数の一部に制限があります。また、Word様式ファイル使用時のみ使用できる設定項目や関数もあります。

                                                                  ここでは、Word様式ファイルを使用した帳票出力で使用できるUniversal Connect/Xの設定項目、およびデータファイルで使用できる関数を一覧で示します。

                                                                  参考

                                                                  Universal Connect/Xの設定項目における「フィールド」とは、Word様式ファイルでは「MergeField」を指します。

                                                                  • Universal Connect/Xの設定項目

                                                                  • データファイルで使用できる関数

                                                                  Universal Connect/Xの設定項目

                                                                  動作設定

                                                                  メニュー

                                                                  説明

                                                                  Wordでの使用可否

                                                                  ジョブ

                                                                  データファイルやWord様式ファイルの名称、出力先などの設定をします。

                                                                  Word様式ファイル固有の設定や制限があります。Word様式ファイルに関する設定項目については、「Word様式ファイルに関するUniversal Connect/Xの設定項目」を参照してください。

                                                                  △

                                                                  運用設定

                                                                  Universal Connect/Xサーバーで使用するデータファイルやWord様式ファイルなどに関する設定をします。印刷処理後のデータファイルの処理方法なども設定できます。

                                                                  ○

                                                                  入力設定

                                                                  Universal Connect/Xサーバーで使用するデータファイルのデフォルトパスやデフォルト拡張子、CSV形式やXML形式などのデータファイルに関する共通パラメーターを指定します。

                                                                  ○

                                                                  出力設定

                                                                  Universal Connect/Xサーバーの出力処理動作に関しての設定をします。

                                                                  制限

                                                                  Word様式ファイル使用時は、［SVF ロケール］に空白または［ja］以外のロケールを選択してジョブを実行するとエラーとなります。

                                                                  ○

                                                                  サーバーログ設定

                                                                  Universal Connect/Xサーバーの実行結果ログ、デバッグログについて、印刷処理されたファイル名、処理した時間、処理結果、保存期間やログファイルのローテーション頻度など、ログ出力内容を設定します。

                                                                  ○

                                                                  メール設定

                                                                  メール送信の設定に関するパラメーターを設定します。

                                                                  ○

                                                                  SVF Cloud接続設定

                                                                  Universal Connect/Xサーバーの印刷処理をSVF Cloudで行う場合に、接続するSVF Cloudの情報と使用するSVF Cloud上のプリンターを登録します。

                                                                  Word様式ファイルでは使用できません。

                                                                  ×

                                                                  ファイル書式定義

                                                                  データファイルの形式

                                                                  説明

                                                                  Word様式での使用可否

                                                                  CSV形式

                                                                  ［ファイル書式定義］ダイアログでCSV形式のデータファイルのフィールド定義を設定します。

                                                                  ○

                                                                  固定長

                                                                  ［固定長書式定義］画面上にデータを表示し、フィールド名と区切り位置を設定します。

                                                                  ○

                                                                  XML形式

                                                                  ［ファイル書式定義］ダイアログでXML形式のデータファイルのフィールド定義を設定します。

                                                                  ○

                                                                  置換マスター

                                                                  項目

                                                                  説明

                                                                  Word様式での使用可否

                                                                  置換マスター

                                                                  データファイル内のデータ内容により、帳票のWord様式ファイルなどを変更する場合の設定をします。

                                                                  Word様式ファイル固有の設定や制限があります。Word様式ファイルに関する設定項目については、「Word様式ファイルに関するUniversal Connect/Xの設定項目」を参照してください。

                                                                  ○

                                                                  処理結果一覧

                                                                  項目

                                                                  説明

                                                                  Word様式での使用可否

                                                                  保存データファイル

                                                                  Universal Connect/Xサーバーに保存データファイルを書き込む設定にした場合は、処理結果および処理したデータファイルが記録され、保存データファイルの表示ができます。

                                                                  ○

                                                                  エラーログ

                                                                  Universal Connect/Xサーバーで印刷処理中にエラーが発生した場合に、書き込まれたエラーログを表示します。
